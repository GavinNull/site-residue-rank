## 1. 数据文档：结合与表达量是怎么定义、归一的（Step 1）

来源：上游代码页面（本会话取回），`jbloomlab/SARS-CoV-2-RBD_DMS_Omicron` 的 `results/summary/`。**取回成功**的页面：`summary.md`、`compute_binding_Kd.md`、`collapse_scores.md`。**取回失败/被拒**：`tstarrlab/SARS-CoV-2-RBD_DMS_animal-ACE2` 与 PD-CoV 仓库首页（工具拒绝处理，我没有换措辞重试）；因此 animal-ACE2 与 PD-CoV 的结合/表达量定义是**按同一 Starr 实验室流程的假设**。

| 项 | 取回的内容 | 含义 |
|---|---|---|
| 响应变量 | 每个条形码、每个 ACE2 浓度的 **mean-bin**（分选箱编号按细胞数加权平均，bin1 未结合、bin4 高结合）；读数按每箱 reads/细胞比校正；某浓度总细胞数 ≤ 2 不用；双峰（两个不相邻箱各 > 40%）记 NA | 读出是 ACE2 荧光强度的分选箱，**不是**「ACE2 信号/RBD 信号」的比值 |
| 拟合 | `nls`：y = a·x/(x+Kd)+b，a ∈ [2,3]，b ∈ [1,1.5]，Kd ∈ [1e-15, 1e-5] M；log10 Ka = −log10 Kd | Kd 上界 1e-5 即 log10 Ka ≥ 5，这就是本仓库反复遇到的「硬下限 5」；拟合残差 nMSR 超过全局中位 40 倍的记 NA；终止密码子记 NA |
| 展示量归一 | **该笔记本不使用 RBD 表达量/展示量作协变量，也不按它门控**；分选箱边界只作参考，计算只用箱编号。「如有基于表达量的门控，发生在上游分选」 | **结合分数没有对展示量归一。分选时是否门控 RBD⁺ 细胞取回的页面没有说**——这决定了展示量能通过多大程度进入读数，我无法确定 |
| 变体层 | 变体分数 = 条形码均值（去 NA）；跨文库 = 文库均值的均值；`n_bc_*` 为条形码数；**无最小条形码/文库过滤**（代码里有，被注释，「Don't do this for now」）；没有对分数的下限/截断（图上的 5–11 只是色标范围） | 表达量低的变体照常保留，不会被过滤掉 |
| `expr` | Sort-seq 的 meanF（RBD 表达量荧光），同样是条形码均值再文库均值；`expr` 逐格等于两文库重复的均值（docs/46 核对，偏差 ≤ 5e-6） | 表达量与结合来自**同一批条码文库**（n_bc Spearman 0.79–0.98），测量是不同分选 |
| 重复的对应 | `bind_rep1/2/3` 与 `expr_rep1/2` 的编号与文库的对应**未文档化** | 重复差的噪声相关（−0.03…+0.08）只能当作估计上界，不能当作「结合与表达量噪声独立」的证明 |

**对解读的后果**：结合分数没有被展示量清洗，读数里表达量的成分是「设计上开着的」；这不等于它「很大」——大小要靠数据（§7–§8）。本文所有「校正」都是**事后在交互层用表达量矩阵去拟合**，不是重现上游没有做的归一。

## 3. 校正

公共掩码 K = 结合观测 ∧ 表达量观测；Rb、Re 为 K 上各自的双向去均值（`subspace_lib.dc_fast`）；未校正参照 = **同一掩码 K** 上的结合矩阵（K 比结合掩码少 0.1%–6%，所以与 docs/45–46 的全掩码数字差在小数点后第三位）。

| 校正 | 定义 | 假设 | 地位 |
|---|---|---|---|
| (i-a) | β = ΣRb·Re/ΣRe²（过原点）；Mb' = Mb − β·Re | 表达量对结合的影响在交互层是线性、残基与位点同一斜率、对**整个**Re 响应 | **主（锁定层）**；门不过 |
| (i-b) | 逐残基斜率 β_j | 同上但斜率依赖残基 | 次；门不过（过拟合） |
| (ii) | 位点逐行把 Rb 对表达量残基载荷子空间（秩规则：WH1_v1/v2、Eta 取 2，BA2、PDCoV 取 1）作最小二乘并取残差；分半时 V_e 来自另一半（交叉拟合） | 结合里与表达量共享的是**残基方向**，与位点载荷无关 | 次；仅用于 Q2(a)(b) 的敏感性；对 Q3 无信息（机械上界） |
| (i-c)（A1） | Re = Lr（秩 k 低秩部分，EM 硬填补）+ Rm（余项）；对 [Lr, Rm] 作两斜率最小二乘 | 结合对表达量的低秩部分与余项各有一个线性斜率 | **主（A1/A2 层）** |

## 4. 双向对照世界（Step 4）

### 4.1 构造

沿用 docs/46 的**残差重采样 RR 世界**（A1 判据下 12/15 忠实；**该判据的采纳仍是待人类裁定的决策**，本文按「用 RR、不视为已定」处理）；噪声用 docs/43 的 7 点路径（点 0、3、6），**不使用** `coup_sd_true = √(coup_sd_obs²−σ²)`、不用 bootstrap SE、不挑单个 σ；SAME-EXP 的 hACE2 矩阵没有 docs/43 路径，用其重复差估计的 σ_meas 生成同一类 7 点路径（`Geometry.path`）。协变量是**真实表达量矩阵本身**（避开表达量几何上 RR/REF 不忠实的问题）。结合侧只用 RR 忠实的矩阵；**排除**：WH1/bat、Eta/bat、BA2/human_monomer（RR 世界不忠实）、BA2/bat（无噪声路径）、hACE2(BA2)（本会话新测，RR 世界在 R1/R2 的 F3 = 0.42–0.48 > 0.40，不忠实；REF 过）。合格 15 个配对：11 个 S1 animal + 3 个 SAME-EXP + gAPN。

摘要：「**这条轴与蛋白折叠共用**」→「**这条轴是读出里的稳定性/展示结构，不是结合特异的残基方向**」；删掉「结合特异的残差约占方向方差 40%」整句与 F/Y/W vs I/L/V 句；§3.4 标题改为「3.4 结合第一轴是读出里的稳定性结构」，把「三条独立理由说明这不是假对齐」之后加「这排除的是文库假对齐；校正后与折叠的对齐崩塌到零分布以内（\|cos\| ≤ 0.443），说明共用由表达量介导」；§3.5 整节撤回；§10 第三段改为「我们没有预期到，酵母展示的结合第一轴大部分是稳定性读出，而不是结合特异方向；基于它的『普适结合轴』须重新定义」；**不得写**「普适结合方向」「结合特异」；**可写**「读出混杂」「稳定性方向」「校正后剩余」。**此判决本文未得出。**
