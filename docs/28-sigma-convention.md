## 0. 判决（先说结论）

| 问题 | 答案 |
|---|---|
| docs/15 的 σ 口径有问题吗？ | **有，而且不止一处。** 体外总 RMSE 确实偏大（本文档在 ddPCA 自己的数据上**实测**到 44.1% 的体外残差方差是逐位点系统差，p = 0.0005），**另外还有一处此前没人看的估计量偏差**：双向中心化消耗 (n_row + n_col − 1) 个自由度，使 `coup_sd_obs` 系统性偏低 **3.8%–6.7%**（六个矩阵的校正因子 1.0384–1.0665），而 `sqrt(coup_sd_obs² − σ²)` 把它在低 SNR 下放大成 **−43%**（coup/σ = 0.33），在 coup/σ = 0.17 处直接输出 **0.000**。两处偏差**方向相同，都偏向假阴性** |
| 那 docs/15 的「三个 binding 矩阵 coup_sd_true = 0」是 σ 的产物吗？ | **在 `coup_sd_true` 这个量上：是口径依赖的**（§4.5：按实测 44.1% 纠正，三个仍全部不过 1.1σ 判据；按另一个可测值 85.3% 纠正，三个全部过）。**所以这个量不能定案** |
| 有独立测量能把它定下来吗？ | **有，而且 docs/15 当年漏掉了它。** ddPCA 两个 assay 各有 **三次独立的生物学重复**（`fitness{1,2,3}_uncorr`，来自 `count_e{1,2,3}_s{0,1}`，**不是** bootstrap 重拟合）。三次独立选择实验在**双向中心化之后**的交互残差上相关 r = **0.856–0.994**，三条**独立**第一轴 \|cos\| = **0.946–0.996**（Haar p95 = 0.445，打乱配对后塌到 0.15–0.19）。**所以「全部耦合方差都是测量误差」这个读法被直接否证** |
| 那结论变了吗？ | **headline 没变，理由全变了。** 三个 binding 矩阵仍然不能进证据集，但**不是**因为「没有可定秩的方差」（那是口径产物），而是因为两道**与 σ 无关**的闸：**D-036 方向自身可复现**（GB1/binding **0.215**、PSD95/binding **0.309**，对 Haar p95 0.445 —— 在碰巧水平**以下**）与**秩 2 可分辨闸**（GRB2/binding 0.486 对下限 p95 0.539、PSD95/binding 0.527 对 0.557，都不过） |
| GB1 binding 该重新纳入吗？ | **本文档的立场是不该，而且这次有四条互相独立的理由**（§7）。**决定权在人类（§9.1），判决标注为待定** |
| 如果纳入，证据宽度会是什么？ | 三组而不是两组：λ1 0.839 → **0.760**（零分布 p95 0.423 → 0.491，余量 +0.416 → **+0.269**）；λ2 条件 p 0.2787 → **0.0833**（**第二轴仍拿不出来** —— 不是靠 p 值，而是靠「观测 λ2 只有『只共享一维』负对照的 **1.18 倍**」，而 docs/27 折叠一侧那个能读的间距是 4.3–6.5 倍）；留一最小 \|cos\| 0.911 → **0.932**；**代表退化显著修好**（穷举 15 种单代表组合，最小 \|cos\| 0.003 → **0.499**、中位 0.714 → **0.917**）。**但**跨家族 冠状病毒 × GB1 的 cos θ1 中位只有 **0.536**，**5 对里只有 1 对**超随机 p95 |
| 配对的 folding–binding 对照能做成了吗？ | **不能。** ΔΔG 层：GRB2-SH3 两条方向都过 D-036（0.522 / 0.481），配对主张**允许**提，而它给的是**阴性** —— \|cos(折叠轴, 结合轴)\| = **0.016**（衰减校正 0.032、位点内置换 p = 0.945，若两轴相同应看到 ≈ 0.50）。fitness 层看起来很漂亮（PSD95 \|cos\| = 0.952, p = 0.0000），但**那一层按构造就是混的**：binding-PCA 的表型同时依赖折叠与结合两个性状，正是 mochi 要解卷的东西（§8.2） |
| 反解锚点 C 能从 docs/27 搬过来吗？ | **不能，而且失败原因已归因。** **4/6 个矩阵**上反解给出 σ_C > σ_B（体外上界），判据 A ≤ C ≤ B **不通过**；通过的两格（GRB2/binding、PSD95/binding）在它们自己反解出的 σ_C 上**判决仍然是「没有可定秩的信号」**（0.41σ / 0.26σ，远低于 1.1σ）。归因诊断（§4.4）：**不是秩假设的问题** —— 即使把真结构换成秩 2 / 秩 3，合成可复现度仍是 0.82–0.99，而实测是 0.21–0.79。ddPCA 的交互项比**任何**低秩生成模型都更不可位点对半复现 |

**一句话主张**

> **docs/15 对三个 ddPCA binding 矩阵的判决是对的，但它给的理由是错的 ——
> 而且错在两个都偏向假阴性的方向上。**
>
> `coup_sd_true = sqrt(coup_sd_obs² − σ²)` 在这批数据上有两处偏差：
> (1) **σ 偏大**（D-042 的机制，本文档在 ddPCA 上**实测**：GB1/folding 的
> 体外残差有 **44.1%** 的方差在逐位点层，置换零分布中位 0.000，p = 0.0005；
> 六个矩阵的 `row_sd / coup_sd_obs` = **0.99–2.01**，与 docs/27 的 1.5 同档）；
> (2) **`coup_sd_obs` 偏小**（新发现，§3.3）：双向中心化消耗
> (n_row + n_col − 1) 个自由度，SD 上只差 3.84%–6.65%，但减去 σ² 之后在
> coup/σ = 0.33 处变成 **−44%**、在 coup/σ = 0.17 处变成 **−100%**（输出 0.000）。
> **两处都把有信号说成没信号。**
>
> 但本文档没有靠纠正这两处来翻案，因为 §4.5 显示纠正幅度本身是搬运来的、
> 跨度足以翻转判决（0.441 → 三个全不过；0.853 → 三个全过）。
> **翻案与不翻案都不能建立在一个口径依赖的量上。**
>
> 于是本文档找 docs/27 用过的那一招：**不论证 σ，直接测。**
> ddPCA 的两个 assay 各自带 **三次独立的生物学重复**
> （`fitness{1,2,3}_uncorr` ← `count_e{1,2,3}_s{0,1}`，与 D-028 禁用的
> bootstrap SE **完全不是一回事**）。在双向中心化之后的交互项上：
> 三对重复的残差相关 **r = 0.856–0.994**，三条独立第一轴
> \|cos\| = **0.946–0.996**（Haar p95 0.445；mask 内打乱格子↔重复配对后
> 塌到 r ≈ 0、\|cos\| ≈ 0.15–0.19）。
> **「观测到的全部 site×residue 耦合方差都能被测量误差解释」这句话，
> 在三个 binding 矩阵上都是假的。**
>
> **然而三个 binding 矩阵仍然一个都进不来**，理由换成两道与 σ 无关的闸：
> - **D-036**（任何对齐主张的前置）：GB1/binding 位点对半第一轴
>   \|cos\| = **0.215**、PSD95/binding **0.309**，对 d = 20 的 Haar p95
>   **0.445** —— 在碰巧水平**以下**。GRB2/binding 0.472 勉强过闸（余量 +0.027）。
> - **秩 2 可分辨闸**（docs/24，门槛逐几何下限 **p95**，D-046）：
>   GRB2/binding 实测 stab cos2 **0.486** 对下限 p95 **0.539**（不过），
>   PSD95/binding **0.527** 对 **0.557**（不过），两者判别力 gap 都 ≥ 0.10
>   所以判词是**「是噪声」而不是「不可读」**。GB1/binding 过这道闸
>   （0.813 对 0.557）**但不过 D-036** —— 两道闸在它身上给出相反的读数，
>   原因是 `stab_boot` 用的是**同一批位点**的重抽，不是 D-036 要的
>   互斥两半（§6.3）。
>
> **所以那个「GB1 binding 从跨家族证据剔除」的人类决定（**D-029**，
> 不是 D-034 —— 见 §0.1 的号码更正）不被推翻，而且
> 这次它有四条互相独立的支撑**（§7）：D-036 不过（0.215）；
> fitness 层的高可复现度被判定主要来自**饱和连接函数**
> （交互第一轴 vs 残基主效应 \|cos\| = **0.767**；GB1/folding 是同一组观测，
> 同样高，0.658；而**另外四个矩阵只有 0.12–0.21**）；
> 它**没有独立的 abundance assay**（docs/15 §6.1）；
> 跨家族 冠状病毒 × GB1 的 cos θ1 中位只有 **0.536**，5 对里 1 对超随机 p95。
> 而 docs/27 §2.7 在另一个平台上独立测到的「1PGA 野生型自己 ΔG > 5」
> 是**第五条**，机制不同但同向。

**不要把这条读成什么**

- **不是「docs/15 错了」。** 它的六个 `coup_sd_obs` 本文档**逐位复现**
  （0.995 / 0.525 / 0.857 / 0.758 / 1.023 / 0.620，§3.1），它的判决也没变。
  变的是**理由**，而理由变了意味着**引用方式必须变**：
  「没有可定秩的方差」这句话不能再用。
- **不是「binding 一侧有秩 2」。** 本文档**没有**重跑定秩；
  三个 binding 矩阵过不了可分辨闸或 D-036，所以它们的秩仍然无法判定。
- **不是「σ 的问题解决了」。** ddPCA 的 σ 夹不住：下界 A（三重复的计数噪声）
  只有 **0.02–0.27 kcal/mol**，落在 D-028 判为「低估一个量级」的
  bootstrap SE 同一档；上界 B 是 0.46–1.22；反解锚点 C **不可用**（§4.4）。
  **区间跨两个数量级，所以 `coup_sd_true` 这个量在 ddPCA 上就是定不了案的。**
  这不是本文档偷懒，是 ΔΔG 在这里是**模型系数**而不是直接测量的后果。
- **不是「配对对照做成了」。** 见 §8。
- **没有开封任何 holdout**，没有访问 `labels/`。

| 项 | 预先写定的内容 |
|---|---|
| 要减的是什么 | **双向中心化之后**交互项里剩下的噪声，**不是**原始 ΔΔG 的总误差（docs/27 §4.1 的机制） |
| 锚点 **A**（下界） | 三次独立生物学重复，在**中心化之后、逐格子**：`SD(R_i − R_j)/√2` 给单重复，`/√3` 给三重复合并；比例法换算到 kcal/mol |

| headline 规则 | 主用 σ_C；四个锚点全报。「有可定秩的信号」的充要条件：σ_C 下 `coup_sd_true/σ ≥ 1.1`（docs/15 §2.4 实测的检出阈值，P ≈ 0.8）**且** §10.3 还原诊断在该 σ、该矩阵自己的几何上检出率 ≥ 80% |

## 2. Step 3 的工具：ddPCA 的生物学重复把手（先验证，再用）

### 2.1 把手是什么，以及它为什么不是 bootstrap

zip 内 `Data/fitness/<domain>/{Binding,Abundance}/*_fitness_replicates.RData`
的 `all_variants` 表带着：

| 列 | 含义 |
|---|---|
| `count_e1_s0 … count_e3_s1` | **三次独立选择实验** × 两个时间点的读数 |
| `fitness{1,2,3}_uncorr` / `sigma{1,2,3}_uncorr` | 逐重复的 fitness 与其标准误 |
| `fitness` / `sigma` | 合并值 |

**与 D-028 禁用的那一列的区别必须写清**：bootstrap SE 是**同一批数据**
重拟合 10 次的离散度（0.009–0.199 kcal/mol，比体外 RMSE 低一个量级）；
这里是**三次独立的生物学重复**。docs/15 §6.4 用 bootstrap SE 做了排除规则，
但**没有用过这三个重复**，所以 docs/15 §2.2 那个「没有独立测量可以反驳」的
处境其实是可以打破的 —— 这是本文档相对 docs/15 的主要新输入。

可得性：

| GB1/binding | `Olson2014_GB1_dimsum128_fitness_replicates.RData` | 400 047 |

### 2.3 σ 分解机器的双向自检（§10.2：既测能命中，也测不误伤）

### 5.1 这一节到底否证了什么

docs/15 §2.2 的原话是：三个 binding 矩阵
「**观测到的全部 site×residue 耦合方差都能被独立校准的测量误差解释**」。

**这句话被直接测量否证。** 三次**独立的生物学重复**（不是重抽）在
**双向中心化之后**的交互项上相关 r = **0.856–0.994**，三条独立抽出的
第一轴 \|cos\| = **0.946–0.996**（随机水平 0.445，打乱后 0.15–0.19）。
如果交互项全是测量误差，r 会是 0，\|cos\| 会是 0.15 左右。

这与 docs/27 §4.1 的那一步**完全同型**（两条独立蛋白酶读出 r = 0.904、
\|cos\| = 0.983），而 ddPCA 这边是**三次**独立选择实验而不是两次读出。

### 5.2 但有一条限定足以改变读法，而且它对 GB1 咬

**fitness 不是 ΔΔG。** ddPCA 的三态模型连接函数是**饱和**的：
一个纯可加的 additive trait 过饱和连接，会在 fitness 上产生
**完全可复现**的**表观** site×residue 交互 —— 而 mochi 的解卷正是为了
去掉它。所以 (1)(2) 的高数值不能直接读成「ΔΔG 的交互是真的」。

判别指标（第 (5) 列）：**交互第一轴有多像残基主效应方向**。

| 矩阵 | vs ΔΔG 残基主效应 | vs fitness 自己的残基主效应 | 判读 |
|---|---|---|---|
| **GB1 / binding** | **0.767** | **0.795** | **交互轴基本就是主效应方向 → (1) 的 r = 0.994 主要是连接函数** |
| **GB1 / folding** | **0.658** | **0.795** | 同上（同一组观测） |
| GRB2-SH3 / folding | 0.207 | 0.185 | 低 → 不是连接函数 |
| GRB2-SH3 / binding | 0.124 | 0.488 | 低 → 不是连接函数 |
| PSD95-PDZ3 / folding | 0.213 | 0.048 | 低 → 不是连接函数 |
| PSD95-PDZ3 / binding | 0.163 | 0.192 | 低 → 不是连接函数 |

**GB1 那两行（它们是同一组观测）是六个里唯一落在「高」那一侧的，
而且 GB1 恰好是唯一没有独立 abundance assay 的那个域。** 这与 docs/15 §6.1 对 GB1 的担心
**方向完全一致**，而且是一次独立确认。

**所以 §5.1 的否证对 GRB2-SH3/binding 与 PSD95-PDZ3/binding 成立，
对 GB1/binding 不成立。**

### 5.3 答案是「有独立测量」还是「口径依赖」？—— 两个都要说

- **在「交互项里有没有真结构」这一问上：有独立测量，答案是「有真结构」**
  （GRB2/binding、PSD95/binding；GB1/binding 的那份被 §5.2 判为连接函数）。
- **在「`coup_sd_true` 是多少」这一问上：口径依赖，定不了案**（§4.5）。
  原因不是我没找把手，是 ddPCA 的 ΔΔG 是**模型系数**：
  三个重复能界定选择计数噪声（σ_A ≈ 0.02–0.27），但**界定不了 mochi
  的模型误差**，而后者恰是体外 RMSE 里的主要部分。
- **在「这些矩阵能不能进证据集」这一问上：不依赖 σ**（§6）。

**GRB2-SH3/binding 的「过」只有 +0.027 的余量，必须这么写。**
轻量配置（`nsplit` = 40 / 100）给 0.578 / 0.541，同判但更高 ——
`nsplit` 越大中位越低，所以 400 这一档是三者里最保守的。
它过 D-036 但**不过**秩 2 可分辨闸（§6.2），两件事不矛盾：
D-036 问的是第一轴，可分辨闸问的是第二轴（`cos θ2`）。

> **GB1/binding 身上两道闸给出相反读数，这件事本身要写明。**
> 它**过**秩 2 可分辨闸（stab cos2 0.813 对下限 p95 0.557）却**不过**
> D-036（0.215 对 0.445）。
> 原因是两个量测的不是一回事：`stab_boot` 比的是
> 「**同一批位点**有放回重抽出来的子空间」与全数据子空间的对齐
> —— 位点是复用的；D-036 比的是**互斥两半**各自独立抽出来的方向。
> docs/13 §6.2 已记过 bootstrap 口径的系统性偏差，docs/24 §6 也声明
> `stab_boot` 的下界**不是**置信下界。
> **对齐主张的正确前置是 D-036，不是 `stab_boot`**（D-036 原文就是
> 「每个方向**自身**可复现」）。所以 GB1/binding 过了可分辨闸
> **不足以**让它参与任何对齐主张。

≈ √(0.522 × 0.481) = **0.50**；实测 0.016。所以这不是一个无功效的阴性，
