# 判别集纳入判据（硬规则）

这份判据决定整个项目的有效性。修改它属于人类决策点，agent 不得自行放宽。

## 必要条件（全部满足才纳入）

### C1 形状相似
- 口袋骨架（第一壳层残基主链原子）叠合 RMSD ≤ 1.0 Å
- 口袋体积差 ≤ 15%（fpocket 或等效工具，同一版本同一参数）
- 形状相似度：USR 或球谐展开系数相似度 ≥ 0.85

> 注意：形状相似度的度量必须**独立于任何候选代理量**。
> 若某个候选量与形状判据相关，结论即循环。见 `docs/03-validation.md` 的形状对照。

### C2 差异在核心
- 残基身份差异的位点，侧链重原子到配体最近距离 ≤ 4.5 Å（第一壳层）
- 非接触区（> 8 Å）残基差异数 ≤ 核心差异数（否则无法归因）
- 差异位点数 1–3 个。≥ 4 个单独标 `multi` 子集，不进主集

### C3 实验可比
- 同一配体（严格同一化学结构，非类似物）
- 同一 assay 类型（ITC / SPR / 竞争结合三者不得混比）
- 温度差 ≤ 5 K
- Kd 或 Ki；**IC50 不进主集**（依赖底物浓度，标 `ic50` 子集）
- **|ΔΔG| 阈值已按 M2-T1 修正。** 原写 0.5 kcal/mol，那是占位值。
  实测的成对 ΔΔG 误差是 0.91（混合）到 1.10（跨文献生物物理 assay）kcal/mol，
  所以 0.5 以下的对不是「勉强可分辨」而是**在噪声以下**。
  - 同一来源内（`same_source: true`）：阈值 ≥ 0.8 kcal/mol（σ≈0.4 的 2 倍）
  - 跨来源拼接：阈值 ≥ **1.8** kcal/mol（σ≈0.9 的 2 倍）
  - 不满足者标 `indistinguishable`，按 M2.3 以软权重处理而非硬剔除
  **这一改动大幅压缩可用对的数量，与 C6 需要约 320 个测点正面冲突。
  见 `state/gates.md` 的可行性问题。**

### C4 结构来源统一
**这条最容易被忽略，违反则所有相关性作废。**
- 同一对的两个口袋，结构必须来自同一流程：
  要么都是晶体复合物，要么都是统一同源建模 + 统一 minimize
- 禁止一侧晶体、一侧建模
- 禁止混用不同分辨率档（≤ 2.0 Å 与 > 2.5 Å 不同对）
- 全集最好统一从同一 docking/建模流程出发。晶体结构已被强结合优化过，
  结构质量本身与亲和力相关，直接用会让代理量读到这个伪影

### C5 同源不泄露
- 同一蛋白家族（Pfam 级）的对，不得同时出现在开发集与 holdout
- 家族标注写入 `facts.family`，切分由 `analysis/split.py` 按家族分组执行

### C6 矩阵覆盖（阶段 M 新增，规格已按 M5.4 修正）

**来源**：`docs/05-mathematical-structure.md` M1.2 的不可识别性结论
与 M5.4 的规模分析。

判别集不是散对的集合，而是一个有意安排的不完整矩阵：
行 = 口袋家族（或家族内成员），列 = 取代 / 残基差异类型。

#### 规模要求（无量纲判据，由参数计数 + 模拟标定）

秩 r 的双因素模型参数数 `n_par = r(n_r+n_c) − r² + n_r+n_c − 1`。
控制变量是无量纲比

$$\rho=\frac{\text{观测数}}{n_{\mathrm{par}}}=\frac{f\,n_r n_c}{n_{\mathrm{par}}}$$

| 目标 | 判据 | 示例形状 | 测点数 |
|---|---|---|---|
| 判定 r = 1 还是 r ≥ 2 | **ρ ≥ 2.8**（按 r=2 的参数数算） | 20×20，填充 0.8 | ≈ 320 |
| 进一步分辨 r = 2 还是 3 | ρ ≥ 2.8 **且** BBP 余量 | 远大于 20×30 | ≳ 800 |

**首要目标是上面那一行。** 480 个测点对 r=3 只给 0.40 定对率，
后一行很可能需要前瞻性数据。见 `docs/05` M5.4「后果二」。

#### 方法要求（不是实现细节）

定秩必须用 **K 折交叉验证 + 多次 ALS 重启**。单次留出严重欠功效：
同样 320 个观测，单次留出给 0.82，K 折给 1.00。
这一条写进判据是因为用错方法会把容量够的情形误判为「无低秩结构」。

#### 历史记录：原规格是错的

本条原写「约 5 行 × 8 列、填充率 ≥ 40%」= 16 个观测。
秩 2 需要 34 个参数，观测数少于参数数，**无论估计器多好都定不出秩**。
少了一到两个数量级。保留这段记录是因为这正是
`docs/05` 那条「先定数学结构」的纪律所抓到的东西。

#### 结构要求

- 同一列（同一取代）必须跨 ≥3 行出现
- 同一行（同一家族）必须跨 ≥3 列出现

C1–C5 管单个对的质量，C6 管集合的结构。两者都要满足。

不满足 C6 的对仍可纳入，标 `subset: scatter`——
它们可用于 G2 基线墙与 G3 盲预测，但**不进 M5 的秩估计**。

## 必填标注

| 字段 | 用途 |
|---|---|
| `water` | 核心区保守水的位置/数量是否变化（晶体结构保守水位判定） |
| `protonation_ambiguity` | 差异位点是否涉及可能的质子化态不确定（His/Asp/Glu/Cys/Tyr） |
| `provenance.same_source` | **必填**。两侧数值是否来自同一篇/同一实验室。决定该对的 σ（同源 0.3–0.4 vs 跨源 0.9–1.1），见 M2.4 |
| `comparability` | 这一对为什么可比，哪里存疑 |
| `gaps` | 缺失信息 |

`water` 字段是 G5 分层报告的依据：片段截断 + 隐式溶剂抓不住结构水，
必须能把"涉及水变化"与"不涉及"两组分开报告。

## 数据来源候选

- 突变 ΔΔG：SKEMPI 2.0（蛋白-蛋白，需筛小配体界面）
- PDBbind 的突变子集 / BindingDB 同配体多靶点记录
- 激酶家族选择性谱（同一抑制剂对近缘激酶，天然的"形状像、残基不像"）
- 原始文献的定点突变表（最可靠，但需逐篇读）

来源可靠性递增，工作量也递增。主集优先用原始文献表。
