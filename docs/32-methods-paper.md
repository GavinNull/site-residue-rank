# 深度突变扫描数据的低秩分解：七个会把真结构读成「无结构」的陷阱

**状态：独立成稿的骨架。2026-10-13。**
本文不依赖本项目任何生物学主张是否成立。
**数字正在接受逐条溯源审计（docs/31）；审计完成前本文的数字按「待核」对待。**

## 0. 这篇为什么该单独存在

把 DMS 数据摆成「位点 × 残基」的矩阵、扣掉双向主效应、对剩下的交互项做低秩分解，
是一个正在被广泛使用的套路（Rosace-AA 已用在 >500 个 domain 上）。
我们在做一个具体的生物学问题时，**在同一个分析里撞了八次工具事故，其中三次完全静默，
两次以「发现了漂亮结构」而不是「什么都没发现」的形式出现**。

这些陷阱的共同点是**它们都把真结构读成「无结构」，或者把无结构读成结构，
而两种误读在报告里看起来都完全合理**。
它们不是某个实现的 bug，而是这类分解的结构性特征，
所以任何沿这条路走的人都会撞上同一批。

本文按「每条都对应一次有记录、可复现的实际事故」组织。

## 1. 截尾摧毁低秩可检出性，而信噪比不是判据

**现象。** DMS 的检测下限会把非结合变体堆在一起。
堆积会**同时**压低信号与噪声，所以它不表现为信噪比变差。

`facts:` 秩 0 / 1 / 2 三层的截尾比例中位分别是 **43.2% / 10.9% / 0.1%**，
相邻层差 32pp 与 11pp。这个单调分层在**三代截尾检测器下都不变**，
是我们唯一敢引用的形式（见 §2 与 §7）。

`facts:` **信噪比方向相反。** PD-CoV RBD 的三个配体：
截尾 **0.7 / 45.7 / 47.9%** 对应检出秩 **2 / 0 / 不可判**（顺序一致）；
而信噪比 **1.56 / 3.57 / 3.04** 顺序**完全相反**——
信噪比最好的那个矩阵给出秩 0。

**后果。** 若用信噪比筛矩阵，会恰好留下最不该留的那些。
而若不筛，一个 60% 截尾矩阵上的「测不出结构」什么也不说明。

**可引用的形式与不可引用的形式。**
`facts:` 我们一度报出「截尾 ≥25% 时 7/7 个体系给秩 0」，后改成「8/9」，
再后来第三代检测器又让它回到「7/7」。**三者我们现在全部撤回。**
理由不是哪个计数算错了，而是**切点这个形式本身由画线位置决定**：
三代给出的 ≥25% 组大小是 **7 / 9 / 7**，线两侧 ±5pp 内三个单元的秩是 **0、1、0**
（毫无锐度），而这些间距**全部小于检测器自身的分辨率**；
把线挪到 30% 或 40% 也找不到三代一致的切点。
**相关系数本身反而稳健**：三代给 −0.786 / −0.777 / −0.786，
加五种最坏情形替换共十一个口径值**全距 0.029**，
而单个 bootstrap 区间宽 **0.18–0.36**——小一个数量级。
所以该报的是区间（|r| 在 0.70–0.88，n = 34）与单调分层，**不是三位小数、不是切点**。

## 2. 截尾有四种机制，没有一个统计量能同时量对

这是本文最实用的一条。我们先后遇到四种**物理上不同**的「越界」行为：

| 机制 | 数据长什么样 | 该用的量 | 遇到它的地方 |
|---|---|---|---|
| **硬赋值原子** | 越界值被赋成同一个数（如 5.000/6.000） | 精确并列计数 | Starr ACE2 系列 |
| **噪声摊开的堆积** | 堆积被测量噪声摊成一个峰 | 密度/众数型混合模型 | PD-CoV（σ ≈ 0.07） |
| **有界但不裁剪** | 拟合有界却返回内插外推值 → **平滑斜坡而非堆积** | **f_out**（可信窗口外比例） | Tite-seq（CR9114） |
| **越界替换成标记并扣留** | 越界被写成字面标记，导出量不给 | **直接计数** | Tsuboyama cDNA 蛋白酶解 |

**三代检测器全都曾静默失效，而且失效模式各不相同：**

`facts:` **第一代（精确并列计数）**：PD-CoV 的 hAPN/pAPN 下限堆积被噪声摊开，
精确并列只占 0.04%，于是它报 **0.0% 截尾**，而真值是 **40.7% / 36.5%**。
不报错、不抛异常。更坏的是，它当时等于在说「两个零截尾的矩阵给出秩 0」，
与「截尾才是判据」这句话**直接矛盾**——这句话是被检测器修正救出来的。

`facts:` **第二代（固定窗口 max(精确并列, min+0.25 内比例)）**：
**固定窗口两端不可能同时正确**。σ ≈ 0 时偏高 **+7…+10pp**（多吃下限上方的真实连续质量）；
σ ≳ w/3.5 ≈ 0.07 时窗口整段落在堆积下方，**静默塌回 ~0**。
在真值 10%–50% 的盲区网格上它给出 **0.5%–9.4%**。

`facts:` **第三代（密度型混合模型）**：通过了盲区标定（σ ∈ [0.07, 0.20]，σ=0 偏差 0.0pp），
但有**两个新盲区**：(a) 纯摊开在 q ≳ 0.5 时在所有 σ 档上塌陷
（机制：上尺度参考的 Q55–Q95 分位在 q > 0.5 后被污染）；
(b) **在偏态但未截尾的分布上假阳性**——合成 skewnorm、**真值恒 0** 时
报到 **26.4%**，而**三道存在性闸全部放行、两个独立估计量残差 1e-4**
（它们一致地在拟合分布自己的众数）。判别指标是 (ĉ−min)/s_up，
我们一度登记为 ≲1.2，后在真实偏态数据上测到 1.28–1.40 而放宽到 ≈1.4。

**结论与建议。**
不要问「这个矩阵截尾多少」，先问「**这份数据的越界机制是哪一种**」——
读该 assay 的拟合代码，而不是看数据的直方图。
机制决定该用哪个量；用错了量，检测器会在它自己的假设之外给出一个
看起来合理的数，且不会告警。
并且：**每个截尾值都应带子抽样区间**。我们的第三代检测器之所以能发现
自己的假阳性，只因为报了区间——3/12 个子抽样报 75–88% 而点估计是 0.1%，
塌掉因此看得见而不是静默。

## 3. 「两个方向对齐」的主张，必须先证明每个方向自身可复现

**这是我们认为最该被别人抄走的一条。**

**事故。** 我们用某数据集自带的表达量列算出
|cos(结合第一轴, 展示第一轴)| = **0.891 / 0.582 / 0.546 / 0.525**，
对 Haar 零分布 p95 **0.442**，**全部 p < 0.02，四个矩阵一致，机制上也完全讲得通**
（展示量混进结合读出是这类实验的已知问题）。
我们差一步就报出「展示方向与第一轴不可分离，普适性可能是假的」。

**真相。** 上游代码里六重复取中位那一行**被注释掉了**（`exp_score = exp_score_rep1`），
那一列是**单次未重复的分选**。六个表达量重复彼此只相关 **r = −0.003 到 0.144**
（同一批表格里结合读出的重复间相关是 0.941–0.986）。

**判别签名（可直接复用）：**
**同实验配对给 0.023–0.046（碰巧水平），跨实验配对给 0.44–0.58
——与真实共享方向的次序正好相反。**
真实共享方向满足「同源 ≥ 跨源同表型 ≥ 跨源跨表型」；
我们后来确认的那条真信号正是这个次序（**0.942 ≥ 0.877 ≥ 0.845**）。

**规则。** 任何「两个方向对齐」的主张，必须先报告**每个方向自身的可复现性**
（不相交半分，或独立重复），并把同来源配对与跨来源配对分开报。
**Haar 零分布的显著性检验完全不检查这件事。** 不可复现的方向不能与任何东西对齐。

`facts:` 这条规则在登记当天就砍掉了两个漂亮数字：一个 |cos| = **0.962**（p < 0.0001），
其方向自身的半分可复现度是 **0.311**，低于随机 p95 **0.438**；
另一个 r² = **0.652**，**超过了该轮搜索的置换天花板 0.593**
（即按常规判据它就该被当成发现），而它与另两个域只相关 r = 0.173。

**一个容易犯的替换错误：** bootstrap 稳定性统计量**不能**替代这条前置，
因为它复用同一批位点，而这条前置要求**不相交的半分**。
我们见过一个矩阵**通过**了 bootstrap 稳定性闸（0.813 对阈值 0.557）
却**不通过**半分可复现（0.215，低于碰巧水平）。

## 4. 从观测耦合里减掉噪声（`coup_sd_true`）在模型系数数据上不是可判定量

**套路。** 用 `coup_sd_true = sqrt(coup_sd_obs² − σ²)` 判断一个矩阵
是否还剩可定秩的信号。看起来无害。

**两个独立偏倚，方向相同，都制造假阴性：**

`facts:` **(a) σ 取错了层。** 从体外文献比对得到的总 RMSE **含逐位点系统差**，
而双向中心化**已经把那部分整条吸收进行主效应**（实测 row_sd = 0.99–2.01 × coup_sd_obs，
另一数据集上 1.5×；某域的体外残差方差有 **44.1%** 落在逐位点层，
ICC 置换零分布中位 0.000，**p = 0.0005**）。
减掉总 RMSE 等于**重复扣除已经被去掉的误差**。
用 σ = 0.70 判，**149/162 个域**被判「没有可定秩的信号」——
而这被**直接测量**否证：两条**独立蛋白酶**读出的中心化残差相关 **r = 0.904**，
两条轴 |cos| 中位 **0.983**。

`facts:` **(b) 自由度消耗，经 sqrt 放大。** 双向中心化消耗 (n_row + n_col − 1) 自由度，
把 `coup_sd_obs` 压低 **3.8–6.7%**；而 sqrt 把这个小偏差放大成
coup/σ = 0.33 时 **−43%**、coup/σ = 0.17 时 **−100%（一个干净的 0.000）**。
**完全静默。**

`facts:` **对称的反面也成立。** 我们此前只防了 σ 太小那一侧：
某数据集的 bootstrap SE 中位 0.009–0.199，而同批值与体外文献的 RMSE 是 0.46–0.89
——**低估一个数量级**；用 SE 做功效分析会把真实秩 1/秩 2 判成 3/4（实测 50/50）。
**所以 σ 两侧都会出事，而仓库此前只防了一侧。**

**建议。** 在 ΔΔG 本身是**模型拟合系数**（而非直接测量）的数据上，
`coup_sd_true` 不应单独作为纳入判据。
若必须用 σ，**用三锚点把它夹住并预先写死判据**
（技术重复 ≤ 反解 ≤ 体外总 RMSE），夹不住就宣布夹不住、报告失败，**不要挑一个值**。
更好的做法是换成不含 σ 的闸：方向自身可复现（§3）+ 按几何标定的可分辨性（§5）。

## 5. 可分辨性闸必须按几何、按秩标定，而判别力在上限不在下限

**现象。** 「这个矩阵能不能单独辨识出自己的轴」通常用一个稳定性统计量加固定阈值来判。
固定阈值是不可靠的。

`facts:` 纯噪声在 10–43 个位点上就能给出 **0.65–0.80** 的秩 1 稳定性；
而常用的 0.60 阈值**低于秩 1 的噪声中位（0.605–0.622）**。
但闸通常跑在**秩 2** 上，而秩 2 的下限低约 **0.145**——
所以 0.60 在秩 2 上是**碰巧可用，不是验证过可用**。

`facts:` **下限对几何不单调。** 120 位点的秩 1 下限 p95 是 0.759–0.772，
而 10 位点的同口径值是 **0.828–0.838**——更高。
跨几何的真实散布是 **0.145**，与**跨秩**的差（+0.145）同量级，
所以**按秩标定要先做，但按矩阵标定不是可选的**。

`facts:` **判别力由上限主导**：r(gap, 上限) = **+0.922**，r(gap, 下限) = **−0.615**。
上限由矩阵自身的秩 r 解释率决定。
这条改了一个判据：「上限 − 下限**中位** ≥ 0.10」应为「上限 − 下限 **p95**」；
14 个矩阵里有一个因此翻转——旧值 +0.132（「有功效」）变成 **−0.041**，
即它的上限 **0.607** 低于自身下限 p95 **0.647**，
**一个完美的秩 2 信号在那个几何上也过不去**。

**后果（真实的）。** 按几何标定后，我们证据集里一个成员以 **−0.029** 不过闸而被剔除，
而它在宽一档的分位数上以 **+0.002** 通过——**分位数的选择本身就是一条纳入判据**，
必须在看结果之前定。
而另一个本会被当成「确认」的数字（0.568）被三重取消资格，
其中第一条就是它所在块的方向自身不过 §3 的前置。
**若不把 §3 设为前置，那个 0.568 会被当成正面结果报出去。**

**措辞纪律。** 一个不过闸的矩阵，若它的上限边距也 < 0.10，
应判**「不可读」而不是「是噪声」**——两者对读者的含义完全不同。

## 6. 欠功效会伪装成结果，而窄区间不是精度的证据

`facts:` 本项目中「欠功效看起来像一个结果」出现了**四次**。
最典型的一次：一个定秩估计器在理想条件（无噪声完备矩阵）下能精确还原秩 1/2/3，
但它在真实数据上报「无低秩结构」——**失败在选择程序的功效，不在信息**。
加上 K 折与多次重启后，秩 2 的检出率从 0.82 升到 1.00。

**规则（本仓库写成硬规则）：** 任何「测不出结构」的结论，
**必须先过一次理想条件下的还原性诊断**，否则无法区分
「现象无结构」与「我的方法不够」。
诊断要在**该矩阵自己的几何、缺失模式、主效应结构与标定后的 σ** 下做，
不是在一个通用尺寸上做。

`facts:` 两个具体案例说明这条有多必要：
一个 20 位点矩阵的分半统计量**理想上限只有 0.230**，
而一维零分布的 p95 是 **0.446**——**哪怕信号是一条完美的轴也测不出来**，
所以它的实测值什么也不说明。
另一个候选的纯噪声下限 0.647 / 已知真方向上限 0.660，**上下限只差 +0.014**，
而对照矩阵的同一差值是 **+0.257 / +0.393**——闸在对照上有效，
**所以不是闸坏了，是候选的数据量落在闸的分辨率以下**。

**一条反直觉的推论。** `facts:` 我们见过三个单元的子抽样区间很窄（±0.3pp）
而它们恰好落在检测器的失效区。
**窄区间在这里不是精度的证据——一个一致失效的闸给出的区间同样是窄的。**
区间要和「这个几何上该统计量的上限」一起读。

**还有一类：零分布自己退化。** `facts:` 在 d = 8 上我们的置换零分布
**中位 = p95 = 0.216**；若不注意「中位等于 p95」这件事，
那个 p = 0.000 读起来就是一个强正面结果。

**以及：零分布必须在自己的维度上生成。** `facts:` 一维零分布的 p95
在 d = 20 是 **0.446**、在 d = 10 是 **0.634**。
我们犯过用 d=20 的零分布去判 d=10 比较的错，
**而这个错两个方向都会出，不是单向保守的**。
同理，一个参与率统计量在 k 上算出来，**绝不能和在另一个 k 上建的零分布比**。

## 7. 过滤之后的中位移动不是证据

`facts:` 把「第二维更可分辨」的那一半配对筛出来，会把 cos θ2 的中位
从 **0.327 抬到 0.477**（另一处独立复现：**0.678 → 0.818**），
而**条件零分布下的 p 值一动不动**。

这是选择效应：筛选条件与被测量相关，所以中位必然上移。
**筛选后的中位移动不能当成「这个量其实更一致」。**
判决要放在不随筛选而动的统计量上（本例是标定后条件零分布的 p 值）。

同类纪律：**条件零分布本身要标定。** `facts:` 我们的第一版条件零分布
强制让每个子空间精确包含共享方向，于是 λ1 恒为 1.000，
而观测只有 0.79–0.88，剩下的 1.12–1.21 都被分给其余方向
——**那个零分布结构性地偏向阳性**。
改用二分法把模拟 λ1 调到等于观测 λ1（标定误差 ≤ 0.001）后，
合成的「只共享一维」负对照给 p = 0.45–0.52，**不再误报**。
`facts:` 另外我们标定出该检验的**实际大小是 0.08–0.12 而不是 0.05**
（24 种子 × 6 个 k），即它在所有 k 上轻度反保守；
结论在标定后仍成立（与负对照的间距 6.5 倍），**但那个 p 值不能按 0.05 读**。

## 8. 八次事故的分布本身是一条结论

`facts:` 八次工具事故里 **三次完全静默**（不报错、不抛异常、输出看起来完全合理），
**两次以「发现了漂亮结构」的形式出现**而不是以「什么都没发现」的形式。

`assessment:` 后一类更危险，理由是可计算的：
前六次的失败方向都是**保守的**（把真结构读成无结构），
所以它们只会让人错过东西；而「发现漂亮结构」那一类会让人**报出一个假阳性**，
而且因为它机制上讲得通、统计上显著、还跨矩阵一致，
**它比真结果更像真结果**。confidence: 高。
basis: 两次的具体形态都在 §3 与 §2 记录，各自都差一步就进了结论。

`facts:` 还有两件值得单独记的：
**(a) 自检本身会错。** 有一次我们植入的「错误」其实不是错误
（断言的约定与数据的约定不同，错的是判据不是数据）；
另有一次负对照的参数化**永远到不了各向同性**
（σ=π/2 时 E[cos²] ≈ 0.504，而 18 维里真各向同性是 1/18 ≈ 0.056），
于是拒绝率 0.787 而不是 ≈0.05。
**所以自检要测两个方向：既测能命中，也测不误伤。**
**(b) 救场的常常是量级核对，不是读代码。** 一次差点丢掉真结论的事故
是靠注意到「RMSE 从 0.3–3.3 跳到 10–12，而 10 恰好是主效应的尺度」发现的；
另一次是靠注意到一个修正会把某物理量推到**超过每个碳一个 π 电子**。
**规矩：任何指标在加严后变化超过一个数量级，先怀疑实现，不要先解释。**

## 9. 建议的最小协议（给要走这条路的人）

1. **先读 assay 的拟合代码，判定越界机制属于 §2 四种中的哪一种**，再选截尾量。
2. 每个截尾值**带子抽样区间**；点估计与区间同时报。
3. 任何「无结构」结论前，在**该矩阵自己的几何**上做理想条件还原性诊断（§6）。
4. 任何「两方向对齐」结论前，先报**每个方向自身的可复现性**（不相交半分），
   并分开报同来源与跨来源配对（§3）。不要用 bootstrap 稳定性替代它。
5. 可分辨性阈值**按几何、按秩**标定；分位数在看结果前定死（§5）。
6. 零分布在**自己的 d / 自己的 k** 上生成；条件零分布要标定到观测量（§6、§7）。
7. 不用 `coup_sd_true` 做单独判据；若用 σ，三锚点夹住并预先写死判据（§4）。
8. 报**单调分层**而不是切点；报**区间**而不是三位小数（§1）。
9. 筛选后的中位移动不入判决（§7）。
10. 任何指标在加严后变化超过一个数量级，**先怀疑实现**（§8）。

## 10. 这篇不说什么

`assessment:` 本文不声称这些陷阱**穷尽**了这类分解的失败模式——
它们是我们在一个具体问题上撞到的那些，样本是一个项目、八次事故。
第三代截尾检测器的两个新盲区（§2）说明每修一层都会露出下一层。
`assessment:` 本文也不声称我们的修法是最优的；
多数情况下我们选的是**能被诚实标定的简单估计量**，
而不是标不清的精巧估计量——绝对标度只在声明的区间内可信、
并把区间报出来，是可用结果；看起来处处精确而在某一段静默出错，
正是本文每一节要防的那种失败。
