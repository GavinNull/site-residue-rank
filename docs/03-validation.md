# 验证协议：0–3 级 + 三组对照

每一级都能单独把一个候选判死。顺序不能调——第 3 级（梯度）刷掉的
往往正是前面表现最好的那批，所以不能放到最后才做。

## 第 0 级：量本身是否稳定

常被跳过，但它决定后面所有数字有没有意义。

**做法**：取 10–15 个体系，每个生成 20 个扰动结构（侧链 rotamer 重采样 +
轻微 minimize + 质子化态替代指认 + 水模型替换），算候选量的标准差。

**判据**：体系内波动必须比判别集典型对间差异小**至少一个量级**。
附加判据：若该量只在精细优化过的结构上稳定，则它不满足"便宜"，同样出局。

**隐蔽陷阱 —— 结构来源泄露**：晶体复合物结构本身是高亲和力结合的产物，
侧链已摆到最优、水已排好。强结合与弱结合的对，结构优化程度本来就不同，
候选量可能只是在读这个。防护写在 `docs/02-pair-criteria.md` 的 C4。

## 第 1 级：机理探针——它是否在做它声称在做的事

不用任何实验数据，纯构造体系。每个候选在提出时附带的
`falsifiable_claim` 在这里做成扫描。签名表见 `schema/factor-vocabulary.md`。

**判据是定性的符号与单调性，不是数值。** 一个声称对残基电性敏感的量，
若对 Hammett 序列无响应，它在判别集上的任何相关性都是伪的。

探针库建成后可复用，比判别集稳定，**优先于判别集建**（G0）。

## 第 2 级：判别集排序

**主指标 pairwise accuracy**，不用 Spearman——任务本身是成对定序，
pairwise 对异常值不敏感且可解释。

剔除 |ΔΔG| < 0.5 kcal/mol 的对。

**必须分层报告**，按残基差异类型切：
极性↔非极性 / 电荷引入或移除 / 芳香性改变 / 体积改变（可能混入形状效应，单列）。
只在某一层好的量不是失败，是有明确适用域的发现——但你得知道它是这个。

**holdout 只开一次**。不是规范要求，是因为在开发集上跑几百个候选之后
那些分数不再携带信息。holdout 的意义是让你结束时知道自己到底拿到了什么。

## 第 3 级：梯度是否真的能用

可微 ≠ 梯度有用。

**3a 数值一致性**：解析梯度 vs 有限差分，多个体系。不一致说明实现有 bug
或藏着不连续点。

**3b 功能性测试**（更重要）：取一批有已知有利/不利突变的口袋，
对侧链身份做松弛（残基类型连续插值，或直接对侧链构象与部分电荷求梯度），
看梯度指向的方向是否富集已知有利突变，用 recall@k 衡量。

很多量排序还行但梯度全是噪声——因为它们的敏感性来自某个几近不连续的
几何条件。这一级要早做。

## 三组对照——这部分决定你信不信自己的结果

### 形状对照
只用形状相关特征（口袋体积、形状互补、buried SASA）训一个同复杂度打分，
看它在判别集上多少分。若不低，说明"形状相近"筛选没做干净，C1 判据要收紧。

### 标签置换
把 ΔΔG 标签在集合内打乱，整条流程重跑，看最好的候选能拿到多少。
**这个数就是运气天花板**，真实候选必须明显高过它。
天花板随候选数上升，所以置换对照必须在**实际搜索的候选量级**下做。

### 残基置换安慰剂
保持结构不变，只换非接触残基（> 8 Å），候选量应几乎不变。
变了说明它在读全局性质，不是口袋核心。

## 基线墙（G2）

现有方法在判别集上的表现，先立墙再谈新模块：
Vina / GNINA / MM-GB(PB)SA / 2–3 个预训练亲和力模型。

- 若基线 pairwise accuracy 已 > 0.75，**说明判别集没选对**（没真正卡在形状相似），
  回去收紧 C1
- 若普遍掉到 0.55 以下而随机是 0.50，这堵墙就是后续所有工作的立足点，
  也是论文里最值钱的东西

失败案例要按残基差异类型分类，这张**失败分类表**直接告诉你新模块需要补什么物理。
它是本项目的零号实验产出。

## 最后一级：前瞻性验证（投稿前）

两条路：
1. 锁定一个活跃靶点家族 + 一个时间点，等该时间点之后新发表的突变数据
2. 用代理量挑一组预测，交给能做 ITC/SPR 的合作者测

前面所有级别都只在**排除错误**，只有这一步提供正面证据。
