### 2.1 一个必须先讲清的口径事实：统计量在 k = 8，零分布在 k_eff = 2

`analysis/gate_consequences.py:154` 写的是 `keff = max(2, len(fam))`。
场景 A 有**两个家族**，所以：

- **观测 λ2 = 0.627** 是 `P̄ = ½(P̄_冠状病毒 + P̄_OMTKY3)` 的第二特征值，
  其中每个 `P̄_家族` 先在**5 个 / 3 个**矩阵上取平均 —— 即它是 **8 个矩阵**的量；
- **它要比的那个条件零分布是在 k_eff = 2 上建的** ——
  两个**纯**秩 2 投影算子的平均，没有任何家族内平均。

这不是本文新引入的口径，是现有主证据脚本的口径。
但它有一个直接后果，§5 与 §7 会量化：**家族内平均会把 λ2 压低，
而 k_eff = 2 的零分布里没有这一步，所以零分布的 λ2 比统计量自己的
零假设分布高得多。** 二分法只把 **λ1** 标定住了（残差 0.0035），
**λ2 的分布形状没有也无法被这一步标定。**

> **因此「k = 8 上的大小/功效」这个说法必须拆成两句**：
> 证据集是 8 个矩阵，而**检验的零分布运行在 k_eff = 2**。
> docs/27 §6.2 标定的 k = 9…90 与 docs/28 §7 讨论的 k_eff = 3
> **都不覆盖这一格**。本文测的是这个**具体操作点**
> （8 个矩阵 / 2 个家族 / k_eff = 2 / λ1 标到 0.839）。

## 4. 理想条件还原性诊断（CLAUDE.md §10.3）—— 在看任何功效数字之前

把全部共享度设为 **ρ = 1**（第一轴、第二轴、家族内、跨家族全部完全共享），
走**同一条** `extract_subspace` → `align` → 家族平均管线，60 次重复。
这回答的是「若真的完全共享，这条管线会测出多少」—— 即**噪声地板**。

| 配对集合 | 完全共享下 cos θ1 | 观测 cos θ1 | 完全共享下 cos θ2 | 观测 cos θ2 |
|---|---|---|---|---|
| 冠状病毒内（10 对） | 0.992 | 0.965 | **0.981** | 0.872 |
| OMTKY3 内（3 对） | 0.945 | 0.839 | **0.821** | **0.146** |
| 跨家族（15 对） | 0.974 | 0.884 | **0.901** | **0.105** |

完全共享下的 **λ 中位 = [0.970, 0.918, 0.048]**，观测 **[0.839, 0.627, 0.305]**。

**两条读法，都重要：**

1. **这条管线在这些几何上有充足的命中能力。** 若第二轴真的跨家族共享，
   跨家族成对 cos θ2 会测到 **0.901**，而实测是 **0.105**。
   **所以「测不到第二轴共享」不是抽取噪声造成的** ——
   10 位点的 OMTKY3 矩阵也不例外（家族内地板 0.821）。
   这是 §10.3 要求的那次还原性诊断，**它通过了**。
2. **OMTKY3 家族内实测 cos θ2 = 0.146 远低于它自己的 0.821 地板。**
   所以那三个第二轴**确实彼此不同**，不是「同一条轴被噪声打散」。
   （docs/33 §0 的结论在此获得一个独立的、量化的支撑：
   它原本只能对 0.165 的各向同性基线比，现在有了 0.821 的「若共享会是多少」。）

> **注意这一节证明的是「管线有能力」，不是「那个 λ2 检验有功效」。**
> 两者不是一回事：成对 cos θ2 的信噪比很好，而 §6 会显示
> **λ2 条件检验这个特定统计量把这份信噪比大部分丢掉了**。
> 不把这两件事分开，就会犯 CLAUDE.md §10 末尾那条错
> （把工具自身的能力与被检查对象的性质记混）。

## 5. 合成模型与参数标定

ρ2（**本文的自变量**）定义为**跨家族的家族级第二轴共享度**：
`v_家族 = ρ2 · v_全局 + sqrt(1 − ρ2²) · w_家族`。
ρ2 = 0 就是「只共享一维」（本检验的 H0），ρ2 = 1 就是第二轴完全普适。

层级结构：全局轴 → 家族级轴（共享度 `a_c` / `b_c = ρ2`）→
矩阵级轴（家族内共享度 `a_w` / `b_w`）。

**标定次序必须是「先第二轴、再第一轴」，第一版在这里错了。**
`align` 返回的是两个 2 维子空间的**两个主角余弦**（cos θ1 ≥ cos θ2），
不是「第一轴对第一轴、第二轴对第二轴」。于是 cos θ1 由两条方向里**更共享**
的那一条决定。第一版先用 cos θ1 标第一轴而把第二轴留在 `b_w = 1`，
cos θ1 就恒等于 1、与第一轴参数无关，二分法把 `a_w(cov)` 推到 **0.000**，
λ1 掉到 **0.55**（观测 0.839）。**这个错误不是静默的**：
它在 §5 的标定核对行上立刻露出来。改为「先用 cos θ2 标第二轴、
再用 cos θ1 标第一轴、交替一轮」后复现观测。

标定目标（全部取自观测，与 λ2 的判决无关）：

| 目标量 | 观测值 |
|---|---|
| 冠状病毒内 cos θ1 / cos θ2 中位 | 0.965 / 0.872 |
| OMTKY3 内 cos θ1 / cos θ2 中位 | 0.839 / 0.146 |
| 跨家族 cos θ1 中位 | 0.884 |

跨家族 cos θ2（观测 **0.105**）**不作标定目标** —— 它是 ρ2 的可观测后果，
每一格都报出来，供把 ρ2 换算成可观测量。

### 5.1 三个模型（摆出来，不只报一个）

第一轴的标定结果（三个模型共用）：
`a_w(cov) = 0.984`、`a_w(omt) = 0.946`、`a_c = 0.985`。

| 模型 | `b_w`（第二轴家族内共享度） | 含义 |
|---|---|---|
| **F** | `cov` = 1.000、`omt` = 1.000 | 家族级第二轴**完全锐利**。这是检验**最有利**的情形，给的是功效的**上界**。 |
| **H** | `cov` = 0.941、`omt` = **0.033**（标定到观测） | 实测的家族内离散度。 |
| **H2** | `cov` = 0.941、`omt` = **0.380** | **敏感性**：`b_w(omt)` 弱可识别（见下），把区间另一端也跑出来。 |

### 5.2 三个模型在 ρ2 = 0 的标定核对（40 次重复）

| 模型 | 冠状病毒内 cos θ1 / cos θ2 | OMTKY3 内 | 跨家族 | λ 中位 |
|---|---|---|---|---|
| **观测** | **0.965 / 0.872** | **0.839 / 0.146** | **0.884 / 0.105** | **[0.839, 0.627, 0.305]** |
| F | 0.984 / 0.960 | 0.898 / 0.777 | 0.868 / 0.131 | [0.900, 0.546, 0.390] |
| H | 0.964 / 0.866 | 0.850 / 0.147 | 0.879 / 0.175 | [0.898, 0.485, 0.224] |
| H2 | 0.964 / 0.866 | 0.839 / 0.194 | 0.875 / 0.150 | [0.899, 0.482, 0.222] |

**H 与 H2 的成对量逐项对得上观测**（最大偏差 0.05，在 OMTKY3 的 cos θ2 上）。
**F 按定义对不上** OMTKY3 内的 cos θ2（0.777 vs 观测 0.146）——
它不是观测几何的模型，是**功效上界**的模型，这一点在 §9 的判词里要讲清。

两个必须讲出来的偏差：
- **三个模型的合成 λ1 都是 0.90 左右，观测 0.839** —— 合成比真实略干净
  （与 §3 的 expl 同向）。**这把功效估高**，对「功效不足」的结论是保守的。
- **模型 H 在 ρ2 = 0 的 λ2 = 0.485，而观测 λ2 = 0.627。**
  观测值比「只共享一维」的实测几何构造**高 0.14**。§6 会看它落在哪一格。

**`b_w(omt)` 弱可识别，必须如实记录**：交替标定两轮分别收到
**0.376** 与 **0.033**，而两端给出的**可观测量**（OMTKY3 家族内 cos θ2 中位）
都对得上观测 0.146。所以这个参数在 0.03–0.38 内由数据定不住 ——
**这正是为什么判词不能只靠模型 H，必须以模型 F 的上界为准**（§9）。

## 6. 功效曲线（§10.3 的命中方向）

脚本 `analysis/lambda2_power.py`（`cell` / `merge` 两种调用），
产物 `cache/lambda2_power.json` 与 `cache/cells/lambda2_cell_{模型}_{ρ2}.json`。
每格 **200 次重复**，λ2 条件零分布每次 **4000 次**、**k_eff = 2**、
**逐次二分法标定到该次合成自己的 λ1**（即与真实数据上做的事完全一样）。
30 个格子是并行跑的；**并行与串行逐位相同**（每格的 rng 只由
(模型种子, ρ2) 决定），已核对：模型 F / ρ2 = 0 串行给检出率 **0.020**、
λ2 中位 **0.562**，单格并行给**同一组数**。

**读表注意**：
- 「检出率」= 200 次里 λ2 条件 p < 0.05 的比例，**后面一列是它的
  95% 二项区间**（CLAUDE.md §5：点估计不单独汇报）。
- 「跨家族 cos θ2 中位」把 ρ2 换算成**可观测量**，便于和实测 **0.105** 对比。
- 「含观测 p?」/「含观测 λ2?」= 观测值 0.2787 / 0.627 是否落在该格的
  2.5%–97.5% 区间内（docs/27 §5.5 判 ρ 相容性用的同一判据）。

### 6.1 模型 F（家族级第二轴完全锐利 —— **功效上界**）

四条理由（每一条单独都够推翻「主证据」这个地位）：

1. **功效不足**（§6）。即使在对检验**最有利**的模型 F 下，80% 功效也要

   **在这一格不成立** —— 一个保守的检验本来就不容易拒绝。
3. **判决完全由 `k_eff = 2` 这个实现选择决定**（§7.2）。
   同一份数据、同样标定到观测 λ1，k_eff = 3 / 5 / 8 给
   p = 0.0063 / 0.0000 / 0.0000 —— **相反的判决。**
4. **把零分布换成与统计量结构匹配的版本（仍标定到观测 λ1），
   观测 λ2 反而超出**（§7.3：p = 0.0025 / 0.0000，在数据允许的

`assessment:`（confidence: 高）**必须同时说清这四条不支持什么。**
它们**不**支持「第二轴其实是普适的」：
