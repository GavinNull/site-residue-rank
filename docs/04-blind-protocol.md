# 盲预测协议（G3）

G3 是整个项目的第一个生死门。它检验的命题是：
**在不看答案的前提下，对口袋对做物理有机层面的论证，能否给出优于基线的排序。**

## 为什么必须盲

对任何给定排序都能构造一套专业且真实的物理解释——给 A>B 讲盐桥，
给 B>A 讲去溶剂化，两套都对，只是权重随结论调整。这种污染读起来和
干净论证完全一样，而且**没有置换对照之类的事后检验能查出来**。
数值过拟合可查，论证污染不可查。所以隔离必须是机制性的，不是自律性的。

## 流程

1. `pairs/<id>.yaml` 的 `status` 为 `ready`（通过 `check_pair.py`）
2. 预测者只读该 yaml。不读 `labels/`，不读该体系的原始文献全文
   （文献表里有数字），不读任何讨论该突变效应的二手资料
3. 写 `predictions/<id>.<predictor>.yaml`，字段见下
4. 文件写入即锁定。`analysis/lock.py` 记录内容 SHA256 到 `predictions/LOCK.jsonl`
5. 全批预测完成后，`analysis/score_blind.py` 一次性揭晓并输出聚合统计

## 预测文件字段

```yaml
pair_id: ""
predictor: ""            # 模型名 + 版本，或人名
predicted_on: ""
direction: ""            # A_stronger | B_stronger
confidence: 0.0          # 0.5–1.0，0.5 = 等于抛硬币
dominant_factor: ""      # 必须来自 schema/factor-vocabulary.md
secondary_factors: []    # 最多 2 个
magnitude_bin: ""        # small(0.5-1) | medium(1-2) | large(>2) kcal/mol
reasoning: ""            # 自由文本论证，揭晓后不得修改
falsifiable_claim: ""    # 一条具体的、可在 probes 上检验的陈述
```

`magnitude_bin` 不计入主指标，但它是量级直觉的直接测量——
物理有机化学家的核心能力是对效应量级有校准过的表。
若方向准而量级全错，说明推理层抓到了符号但没抓到权重，
这对 G4 的因子选择有直接影响。

## 主指标

1. **方向准确率**，带 bootstrap 区间，对比基线墙（见 `docs/03-validation.md`）
2. **按 `dominant_factor` 分层的准确率**。这是最有价值的产出：
   某因子上显著高于随机 → 该情形下推理抓到了真结构，进 G4 候选；
   某因子上接近随机 → 那是幻觉出口，不进 G4
3. **置信度校准曲线**。按 confidence 分箱画实际准确率。
   不校准则整个推理层不可用，无论平均准确率多高

## 关键设计：F00 (mixed) 的作用

允许预测者选 `F00 = mixed` 表示"无单一主导因子"。这一类单独报告。
若 `F00` 组的准确率明显低于其他组，说明预测者**知道自己什么时候不知道**，
校准是真的。若 `F00` 组准确率和高置信组差不多，说明 `F00` 只是在偷懒，
整套因子归因的可信度要打折。

## 样本量

首轮 100 对。在 100 对上，方向准确率的 95% bootstrap 区间半宽约 ±0.10，
所以只有准确率 ≥ 0.65 才能和 0.5 分开。基线墙若在 0.55–0.60，
需要 ≥ 0.72 才算显著优于基线。**这个数字在开跑前就要写死，不能事后调。**

预注册门槛：
- 方向准确率下界（区间下限）> 基线上界 → 通过
- 至少 2 个因子层（n ≥ 15）准确率下界 > 0.6 → 因子归因可用
- 校准曲线单调且高置信箱准确率 > 平均 → 校准可用

三条全不满足 → G3 不通过，项目停在这里，不建 G4。

## 泄露口径：什么算看过标签（2026-10-12 人类裁定，来源 docs/25 §2.1 / Q-008b）

CLAUDE.md §1 规定标签隔离，但没有规定**粒度**。CR9114 这件事把粒度问题逼出来了：
docs/25 §2.1 把 CR9114 的 18 个 SHM 位点及每个位点的两个状态写进了文档
（来源是 CR9114_DMS 仓库自己的 `CR9114_SHMheatmap.tsv`，**不是** Phillips/Desai），
而 Phillips/Desai 的组合完备景观正是一个潜在 holdout。

**裁定（人类）：位点身份不算泄露。**

- **不算标签**：哪些位点在变、每个位点有哪两个状态、位点编号、野生型序列、
  SHM 数目。这些是公开文献信息，且从被研究对象的结构/序列本身就能得到。
- **算标签**：**哪个组合给多少亲和力**。即基因型→表型的映射值，
  以及任何由它导出的排序、分层、或「哪条上山路径可行」之类的陈述。
- **因此**：Phillips/Desai 的 CR9114 组合完备景观**仍可用作 holdout**，
  docs/23 §7.2 第 4 条保留。
- **边界**：一旦对某个具体组合（而非单位点）做出亲和力方向的预测、
  或读取任何组合层面的表型值，该 holdout 即作废。
  本次没有做任何预测、没有做逐位点分析，故未作废。

`assessment:` 这个口径的理由是「位点身份不含可被事后合理化的信息」——
知道 18 个位点在变，不会让任何关于组合景观形状的论证变得更容易编。
而亲和力值会。confidence: 中高。basis: §1 要防的是「被污染的论证读起来和
干净的论证完全一样」，而位点清单无法支撑那种论证。
**这个口径一旦写下，对后续全部 holdout 一体适用，不得按个案放宽。**
