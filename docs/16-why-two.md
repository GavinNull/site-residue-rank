# 为什么是 2：多极展开 + 取向平均给出的通道计数

**状态：预注册推导。写于 2026-10-11，在 docs/14（位点载荷结构可预测性）跑完之前落盘。**
按 CLAUDE.md §4，本文件的预测在结果揭晓后**不得修改**；要补充另开 postmortem。

本文件回答一个此前没问的问题：rank-2 这个数字本身能不能被导出来？
如果能，秩 2 就不只是一个拟合事实，而是一个有物理来源的通道计数，
并且它会对「成分 2 是什么」给出带符号的、可falsify的预测。

---

## 1. 事实基础（已验证，来自 docs/09、docs/12）

- `facts:` 双向中心化后的 site×residue 交互项秩为 2。无泄露嵌套 CV，
  15 子集中 14 支持秩 2（符号检验 p=0.00049），秩 1→2 中位增益 +4.53%，
  秩 2→3 为 −5.54%（真正的内部极小）。
- `facts:` 成分 1 残基载荷与疏水性 r=−0.75、与体积 r=−0.74；位点载荷与埋藏 r=+0.42。
- `facts:` 成分 2 残基载荷与平面 sp² 指示变量 r=−0.768（成分 1 对同一变量仅 −0.131）。
  最正：Ile +7.95、Val +7.43、Thr +4.72、Cys +4.19。
  最负：Glu −6.30、Trp −6.07、Asp −5.65。
- `facts:` 臂长无法解释成分 2（Ile 2.56/+7.95 vs Leu 2.52/+0.29 vs Asp 2.40/−5.65）。
- `facts:` 疏水性无法解释成分 2（Phe、Trp 落在负端，而它们疏水）。
- `facts:` MP-1 多极分解中偶极通道的耦合占比恰好为 50%，即该通道不可辨识（已撤回，docs/07）。
- `facts:` 转子构象熵与成分 2 无关，r = −0.049。

## 2. 推导

把位点 s 上换成残基 r 的静电贡献写成侧链电荷密度与环境势的重叠积分。
环境（蛋白 + 配体，扣掉被突变的那条侧链）在位点附近给出势 φ_s(x)；
侧链电荷密度 ρ_r(x) 在以侧链质心 x₀ 为原点的局部坐标系里。

    W = ∫ ρ_r(x) φ_s(x) dx

把 φ_s 在 x₀ 处展开（E = −∇φ）：

    W = q_r φ_s(x₀) − μ_r · E_s − ½ Q_r : ∇E_s + …

**每一项都是「残基侧张量 × 位点侧同阶张量」的缩并。** 这是关键的结构观察：
缩并展开后，每一项都给出若干个（残基标量）×（位点标量）的外积，
也就是说**多极展开天然地把 ΔΔG 写成一个低秩双线性和**，
而秩等于存活下来的独立通道数。

### 2.1 朴素计数给出的秩远大于 2

单极 1 个分量、偶极 3 个、四极 5 个独立分量（无迹对称）。
如果取向是一个自由标签，朴素的秩上界是 1+3+5 = 9。观测是 2。
所以**必须有一个坍缩机制**，而这个机制就是推导的全部内容。

### 2.2 取向平均把张量通道压成旋转不变量

侧链的取向不是自由标签：它按 Boltzmann 权重在转子集合上松弛。
对取向做平均后，一阶的取向依赖项在取向近自由时消失，
留下的是**旋转不变量**——按 docs/05 §M3 已经写下的线性响应关系

    ΔΔG = ⟨ΔH⟩₀ − (β/2) Var₀(ΔH)

二阶项把每一阶多极压成「残基不变量 × 位点不变量」的单个标量积：

    偶极通道  →  |μ_r|² · |E_s|²
    四极通道  →  ‖Q_r‖² · ‖∇E_s‖²

于是每一阶多极**只贡献秩 1**，不是 3 或 5。加上非静电的空腔项，
候选通道表变成：

| 通道 | 残基侧不变量 | 位点侧不变量 |
|---|---|---|
| A 空腔／去溶剂化 | 体积、疏水面积 | 埋藏度 |
| B 单极 | 净电荷 q | 势 φ₀ |
| C 偶极 | \|μ\|² | \|E\|² |
| D 四极 | ‖Q‖² | ‖∇E‖² |

**秩 2 意味着这四个通道里恰好两个可辨识。**

### 2.3 哪两个

- `assessment:` 成分 1 = 通道 A。依据：残基载荷与体积 r=−0.74、与疏水性 r=−0.75，
  位点载荷与埋藏 r=+0.42。confidence: 高（三个独立相关都对上，且方向正确）。
- `assessment:` 成分 2 = 通道 D（四极）。依据链条：
  1. 成分 2 与电荷、偶极都不相关 → 排除 B、C；
  2. 与平面 sp² r=−0.768 → 而 ‖Q‖² 恰好在平面 π 体系（吲哚、苯环）
     和羧基／酰胺上大，在烷基上小；
  3. 逐残基核对：Trp（吲哚大 π）、Glu／Asp（羧基，四极大）落负端；
     Ile、Val（纯烷基）、Thr（小，主要是偶极而非四极）、Cys（SH 小）落正端。
     符号与 −½ Q:∇E 中的负号一致。
  4. 该解释同时**躲过了已有的两个反证**：它不依赖臂长（Ile 和 Asp 臂长相近
     但 ‖Q‖² 差一个量级），也不依赖疏水性（Phe、Trp 疏水但四极大）。
  confidence: 中。basis: 载荷与 ‖Q‖² 的定性对应 + 躲过两个反证。
  **尚未定量验证**——下一节就是为了把它变成一个可以被否掉的数字。
- `assessment:` 通道 C（偶极）不出现，最可能是被成分 1 吸收：在 20 种氨基酸上
  |μ| 与体积高度共线。这是一个**可测的共线性断言**，不是辩解。
  confidence: 低。basis: 与 MP-1 偶极通道恰好 50%（不可辨识）的观测一致。

## 3. 预注册预测（结果揭晓前落盘，不得修改）

这组预测的价值在于它们**互相排斥**：四极解释和「形状／堆积各向异性」解释
对位点侧预言不同的量，一个是静电的，一个是几何的。

**P1（主预测，四极通道）** 固定规范后，u₂(site) 与**电场梯度张量**的
Frobenius 范数平方 ‖∇E_s‖² 相关，而与场强 |E_s| 不相关或弱相关。
∇E 是环境点电荷库仑和的二阶导，解析、便宜、可微。
判据：u₂ ~ ‖∇E‖² 的样本外 R² 的 bootstrap 区间不与 WCN 基线重叠，
且 u₂ ~ |E|² 的区间与零重叠。

**P2（竞争假说，堆积各向异性）** u₂ 与位点自由体积的**各向异性**相关
（CB 周围 ~6 Å 内未占据空间的惯量张量特征值比），而与自由体积的**大小**不相关。
理由：平面基团需要板状空隙，β 分支基团需要各向同性空隙。
cache/flatness.npy、cache/n_lobes.npy 已有相关量。
P1 与 P2 可以同时成立（都是真实物理），但**必须分别报告**；
如果只有 P2 成立，则成分 2 是几何通道而非四极通道，§2.3 的判断要撤回。

**P3（正交性）** u₁ 与 u₂ 跨位点近似不相关。不同物理来源的通道不该共线。
如果 r(u₁,u₂) 显著非零，说明规范固定有问题，或通道分解不对。

**P4（残基侧定量）** 用实测侧链几何（cache/sidechain_geometry.json +
analysis/rotamer_build.py 重建，中位误差 0.179 Å）配上部分电荷算出的
‖Q_r‖²，与成分 2 的残基载荷的相关应当强于已有的二值平面 sp² 指示变量
（r=−0.768）。这是最直接的一条：**一个连续的物理量应当打败一个二值标签。**
如果打不败，四极解释就只是把「平面」改了个名字，应当如实这么说。

**P5（否证条件）** 如果 u₂ 与 ‖∇E‖²、与自由体积各向异性**都**不相关，
且 ‖Q‖² 也打不败二值平面标签，则成分 2 在当前描述子体系下不可归因，
应当按 docs/11 的先例如实记为「存在但未归因」，不再搜函数（CLAUDE.md §6）。

## 4. 这段推导本身的价值与它不保证的事

`assessment:` 即使 P1 被否掉，§2.2 的那一步仍然独立成立并且是本项目最该写下来的
数学内容：**多极展开天然给出双线性低秩形式，而取向平均把每一阶多极从
3/5 个分量压成 1 个旋转不变量。** 这解释了为什么秩这么小——
朴素计数给 9，观测给 2——并且把「秩是多少」变成「几个通道可辨识」，
是一个有内容的、可以被别的体系检验的陈述。
confidence: 中高。basis: 线性响应（docs/05 §M3）+ 多极缩并，两步都是标准结果；
风险在于取向是否真的近自由，这一点在埋藏位点上是可疑的。

`assessment:` 它不保证秩在所有体系里都是 2。通道能否辨识取决于数据：
截尾会摧毁可检测性（r = −0.786，≥25% 截尾时 7/7 给秩 0），
而共线性会把通道合并（如 §2.3 里偶极被体积吸收的猜测）。
所以「秩 2」应当读作**在这批数据的信噪与覆盖下，恰好两个通道可辨识**，
而不是「物理上只有两个通道」。这两句话的区别很重要，写作时不能含混。
