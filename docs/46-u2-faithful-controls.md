## 2. 对照世界

沿用 docs/43/45 的几何与 7 点噪声路径（σ ∈ [σ_meas, σ_fit(k)]，s 由 cso 匹配）；**不使用** `coup_sd_true`、bootstrap SE、σ 减法，不挑单点。两个世界植入**相同**的结构（真实秩 k 拟合 P_k），只有噪声模型不同。（对任务书「植入 K1 拟合」的偏离，如实记录：用的是 docs/43/45 一直用的标准拟合，使本轮与 docs/45 之间只有噪声模型/截断一项变化。）

- **G（无截断高斯，主）**：r + c + I(k,s) + N(0,σ²)，`clip=False`。
- **RR（残差重采样，次）**：r + c + I(k,s) + (σ/σ_fit(k))·E，E = 矩阵自己的秩 k 拟合残差在位点（行）内置换。边缘分布（重尾、异方差）按构造等于真实残差。
- R0 无结构：G-R0 = r + c + N(0,σ0²)；RR-R0 = r + c + 整个残差行内置换。
- 旧截断世界 GCLIP（G 的 clip=True）与 REF（真实矩阵的秩 k 拟合 + 它自己的残差行内置换，σ=σ_fit，尺度 1，**已知忠实的参照**）仅用于保真检验的牙齿。

## 3. 保真判据及其双向检验

### 3.1 判据（原预先登记 §3，数值先于数据）

对每个 (矩阵, 世界, 路径点)，20 个新鲜实例的均值；R = 双向去均值残差（观测格），cso = 真实 R 的 SD：

- F1 = 观测格里在值域端点**或之外**的比例 ≤ 1.0%（真实 ≈ 0.06%）
- F2 = Wasserstein-1(R_世界, R_真实)/cso ≤ 0.10
- F3 = 七个分位 (0.01 … 0.99) 上 |Q_世界 − Q_真实|/cso 的最大值 ≤ 0.40

「忠实」= 全部 14 个路径点同时通过（全有或全无）。

### 3.2 牙齿（`python3 analysis/d46_run.py fidelity`；`cache/d46/fidelity_*.json`）

| FT2 不误伤 | 被截比例 < 0.5% 的点不被判 F | 通过（14 点 0 误判） | 通过 |

**FT3 失败按预先登记的字面是「判据与已知忠实不符（过严），中止并交人，不放宽」。这个中止本身就是预先登记层的结果：** 在锁定判据下 G 世界 0/15、RR 世界 1/15、REF 3/15、截断世界 0/15 个矩阵忠实，没有任何世界可用，Part A 的预先登记层判决是 **CANNOT BE ASSESSED（无忠实对照）**。

**诊断（工具的错，不是被检查对象的错，CLAUDE.md §10）：** F1 数「越界」，而真实矩阵的值域就是它自己的极值，任何「结构 + 独立残差」的可加世界——包括边缘分布与真实残差完全相同的 REF——都会让一部分格子越过真实极值。真实数据里结构大的格子残差小（最可能是接近仪器上下限的饱和式依赖，**未单独检验**），行内打乱就破坏了它。F1 因此抓不到截断堆积特有的缺陷，反而抓住了所有可加世界共有的越界。FT3 的设计目的就是发现这种过严的护栏，它做到了。

**修订 A1（事后）：** F1 → F1a（恰在端点的比例，≤ 1%；对不截断世界恒 ≈ 0，只检验「截断堆积」这一个缺陷），F1b（越界）只报告，F2/F3 不变。**我写 A1 时已看到 G、RR 的 F2/F3 逐点结果**，所以 A1 的实际后果（G 全不忠实、RR 大多忠实）我是知道的；A1 的 F1→F1a 由 REF 失败的机制推出，F2/F3 未动。

## 8. 能做出的陈述与人类决策点

1. **保真**：旧截断世界的缺陷可被量化抓住（7/14 矩阵，7%–22%）；但「不截断的高斯世界」并非忠实世界——它在值的形状上失配（0/15 过 F2/F3）。docs/45 的事后 11/14、12/14 因此建立在一个不满足保真判据的世界上；用残差重采样世界（12/15 忠实）重做，同一规则给出 10/11（EM 与 K1）。
2. **Part A 的两层判决并列**（§0），不择一。**人类决策点（§9 第 1 类）：是否采纳 A1 的 F1a 判据**；采纳则修订层结论成立，不采纳则预先登记层结论成立（无法评估）。
3. **Part B**：表达量方向在 WH1 与 Eta 上可复现，BA2 与 PDCoV 上第二方向不可复现；在可评估的三个源上，探索层描述性证据指向「结合第二子空间与同一文库的表达量交互子空间重合到各自复现性的天花板」，预先登记的分类失灵、判决层无法评估。
4. **仍未回答**：(a) 重合究竟是稳定性/展示结构，还是同一文库的条码构成与酵母展示对残基的偏好（两个读出共享条码构成）；(b) 结合特异成分在表达量三维及以上子空间中仍可存在；(c) BA2 与 S2；(d) 修订判据下 G 不忠实是否可由别的噪声模型修复（本轮未试）。
