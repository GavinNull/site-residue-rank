# 论文级叙述：结合 ΔΔG 的 site×residue 交互是秩 2，其第一轴与折叠共用

**状态：叙述骨架 + 定稿数字。2026-10-13。**
每个数字的出处见对应 docs 与 `state/decisions.md`（62 条）。
本文件**不产生新数字**；它只决定哪些数字进正文、以什么顺序、带什么限定。

## 0. 一句话

把蛋白突变影响配体结合的数据摆成「位点 × 换成哪种残基」的矩阵，
扣掉两个方向的主效应，剩下的交互项是**秩 2**；
两个成分里**第一条跨蛋白家族普适、而且与折叠共用**，
**第二条是界面自己的属性**——而判别口袋差异的信号恰好全在第二条上。

## 1. 核心结果：秩是 2

`facts:`（docs/12）无泄露嵌套 CV 下，秩 2 优于秩 1 在 **14/15** 个子集成立
（符号检验 **p = 0.00049**），秩 1→2 中位改善 **+4.53%**，相对可加模型 **+11.39%**，
而**秩 2→3 为 −5.54%**——曲线有真正的内部极小，底在 2。
覆盖 7 个骨架、9 个配体、约 8 万观测。

这个「内部极小」是整篇的第一块地基：它把主张从「至少两个成分」
收紧成「**恰好两个**」，而后者才是可证伪的。

**新意定位**（文献校准，docs/12）：领域现有工具 Rosace-AA（>500 domain）
**假设**该交互是秩 1（`φ_p + ν_a·ρ_p`，标量位点敏感度）；
Husain & Murugan 定过秩，但索引是 site×site。
**没有人定过 site×residue 交互的秩。**

## 2. 第一轴：跨家族普适，化学身份不是经典疏水性

`facts:`（docs/13、docs/24 §6 重标定后）跨家族共识 **λ1 = 0.839**
对同结构零分布 p95 **0.423**；跨家族 20 个配对 cos θ1 中位 **0.900**，**20/20 超 p95**；
留一 |cos(u,u')| 最小 **0.911**。

化学身份（docs/13、docs/21 §5，两组证据下）：

| 标度 | r | r² |
|---|---|---|
| sheet propensity | +0.779 | **0.607** |
| 侧链极化率（本地实测，折射度换算） | +0.754 | 0.568 |
| 摩尔折射度 | +0.720 | 0.518 |
| Rose 埋藏 ASA | +0.656 | 0.430 |
| **Kyte-Doolittle 疏水性** | **+0.472** | **0.223** |

**主干是 sheet propensity + 侧链体积/极化率/埋藏 ASA；经典疏水性是 22% 的次要相关量。**
单体系内测到的「与疏水 r = −0.75」是因为疏水与体积在那里共线；
跨家族取共识后留下的是体积/极化率那一支。

## 3. 第一轴与折叠共用（本项目最意外、也最硬的一条）

`facts:`（docs/27，Tsuboyama 2023 cDNA 蛋白酶解，**144 个独立天然结构域**）
|cos(折叠第一轴, 结合普适轴)| 中位 **0.755**，域级 bootstrap **[0.720, 0.775]**；
**136/144 = 94.4%** 超各自 d 的零分布 p95；**符号检验 p = 2.9e-165**；
共识层面 **0.845**（对 docs/26 单矩阵时的 0.842）；**ρ ≈ 0.78 [0.75, 0.80]**。
结合特异残差上界 **~40% [36%, 44%]**。

三条支撑它不是假对齐：
- 同源 ≥ 跨源同表型 ≥ 跨源跨表型 = **0.942 ≥ 0.877 ≥ 0.845**，
  与 docs/25 记录的假对齐签名**次序相反**；
- ddPCA 与 cDNA 蛋白酶解**两个平台**在同一条折叠轴上一致到 **0.978**；
- 折叠轴自身跨域普适且比结合侧更稳：λ1 **0.895** 对零分布 p95 **0.174**，
  留一簇 |cos| 最小 **0.9998**。

**那 ~40% 残差的化学身份已经定位**（docs/27 §6）：
折叠侧 sheet propensity r² 升到 **0.786**，但**极化率从 0.568 掉到 0.257**、
Kyte-Doolittle 从 0.223 **升到 0.619**。载荷给出原因——
**u_binding 正端是 F/Y/W（芳香），u_fold 正端是 I/L/V（β-分支脂肪族），负端几乎相同。**
所以：共用的是「sheet propensity + 大疏水侧链」，
**芳香/可极化是结合侧偏置，β-分支脂肪族是折叠侧偏置。**

### 3.1 唯一的同系统配对测量，以及它为什么不构成反例

`facts:`（docs/28、docs/29）GRB2-SH3 的 ddPCA 配对数据给出
|cos(折叠轴, 结合轴)| = **0.016**（置换零分布中位 0.155，p = 0.945）。
这**曾是**本项目最后一个真矛盾。它由同 619 格上的三角测量化解，**全程不含 σ**：

| | \|cos\| |
|---|---|
| 折叠臂 × u | **0.764**（过 p95，落在 144 域四分位 [0.645, 0.822] 正中） |
| 结合臂 × u | **0.250**（不过） |
| 结合臂（全掩码）× u | 0.249 ← 故配对缺失不是原因 |
| 配对对两条轴的稳定性 | 0.948 / **0.999** |

几何硬界（4000 随机三元组、0 次违反）给 **−0.434 = 无约束**：
**结合臂既然在碰巧水平，0.016 不需要任何额外机制。**
若结合臂也是 ~0.76，硬界会是 +0.155，0.016 便不可能出现。

第二条签名：细胞级**有符号** r（折叠交互残差, 结合交互残差）= **−0.246**
[−0.333, −0.157]；主效应从 `fitness` 层的 0.770 掉到 ΔΔG 层的 **0.141**
——与「三状态解卷过度校正」一致。
`assessment:` 「解卷真的减掉了共享成分」与「联合拟合系数按构造误差反相关」
**在这份数据上分不开**，两者操作结论相同，故例外条款按较弱的措辞写（见 §7）。

同折叠层面的独立核对（docs/29，n = 22）：144 里有 **22 个 SH3 折叠域**，
|cos| 中位 **0.763**、范围 [0.598, 0.917]，**无一落在 docs/27 那条 10 域 <0.45 的尾巴里，
那 10 个里也没有一个是 SH3**。
**结论：ddPCA 的折叠轴不特殊，这个域也不特殊，只有结合臂特殊。**

## 4. 第二轴：不普适，是界面自己的属性

`facts:`（docs/13 §6.3，决定性对照）OMTKY3 **同一抑制剂骨架、同一批实验、
10 位点 × 20 残基完整测全、各自第二维可分辨、截尾 0.5–1.6%**，
换四个结构无关的蛋白酶给出**四个不同的第二轴**：
cos θ2 = **0.761 / 0.290 / 0.055 / 0.026**。
残差方向参与率 PR **2.71**，单尾 **p = 0.0045**（清楚在零分布之外；
注意 18 维里各向异性基线是 |cos| ≈ 0.17 而不是 0，所以准确说法是
**「彼此不同，但也不各向同性」**）。

`facts:`（docs/24 §6）两组证据下 λ2 = **0.627**，标定后的条件零分布 **p = 0.2787**
——**第二轴不成立**。原先那个弱版本（「受约束但由界面决定」）在两组证据下
**被撤回而非削弱**。

`facts:` 冠状病毒家族**内部**第二轴确实一致（PR 1.24，planar sp² r = +0.81），
但那是**家族效应，不是氨基酸层面的定律**。

**对原始问题而言，这一条才是要害。** 用户要的是能区分核心残基不同、
形状相近的口袋的代理量。普适轴**原则上不能**区分口袋——它对所有界面都一样；
带判别力的信号正是这条界面特异的方向。

## 5. 代理量：做成了普适那一半，判别那一半做不成

`facts:`（docs/14）固定规范后：
- **u₁ 可从结构算出来**：空间分组 10 折 CV 样本外 R² = **0.408 [0.281, 0.506]**，
  复现信度天花板 **0.988**；**WCN 基线 0.010 [−0.111, 0.103]**、
  埋藏基线 0.106 [−0.014, 0.193]，**区间不重叠**。
  起作用的是近端自由体积与侧链半球自由体积（球面采样、光滑、可微）。
  裸 WCN 在分组 CV 下一文不值。
- **u₂ 算不出来**：复现信度 **0.983**（200 次随机半分，差 ≤0.001），
  却从 **27 个描述子 / 3303 个子集**预测不出来（R² = 0.171，下界几乎触零）。
  27 描述子池的置换天花板中位 0.019 / p95 0.050。
- 量级校准：耦合 SD 0.918 kcal/mol；oracle 秩 2 RMSE 0.682（−25.8%）；
  **纯结构秩 2（两个标量都来自 6M0J）0.857（−6.7%）**。

`assessment:` 所以闭式、可微、只读一个野生型结构的代理量**存在，但只覆盖普适成分**。
u₁ 与 u₂ 跨位点近似正交（r = **+0.059 [−0.125, +0.238]**，这同时是规范固定的独立诊断），
所以这不是「还没找到那个描述子」，而是**野生型单结构里没有 u₂ 的信息**；
最可能的原因是 u₂ 依赖突变后的局部重排。confidence: 中。
唯一非零的 u₂ 相关量是**转子层面的芳香可容纳性**
（log nall_PHE，r = +0.284 [0.147, 0.406]）——起作用的不是抽象几何不变量，
而是**拿一个真实芳香探针去试**。

## 6. 被排除的替代解释（每一条都是具名的、可证伪的）

这一节的价值在于它们都是**先被点名、再被测**的，不是事后补的。

1. **一般性取代破坏性**（docs/26）。最强的替代解释：若「普遍有害的取代在
   结构敏感位点更有害」，就会产生形式相同的秩 1 交互而完全不涉及配体。
   五条**无配体**标度给 r² = **0.001–0.192**，而 15 条标度的置换天花板是 **p95 = 0.593**，
   **没有一条超过**，极化率与 sheet 都超过。
   判决在不对称性：把破坏性加进 span{极化率}，**cos θ1 一动不动**（0.860→0.860–0.881）；
   反方向增量 **+0.645…+0.771，五条全部 p ≤ 0.001**。
   且预期的高共线**没有出现**（r = +0.14…+0.20，VIF 1.02–1.13），
   因为破坏性在体积上是 **U 形**（P/G/D 与 W/F 同在最去稳定端）而极化率单调。
   **它确实存在，但住在第二轴上**（|cos(u₂)| = 0.430/0.576/0.431 vs |cos(u₁)| ≤ 0.266）。
2. **四极通道**（docs/16 预注册 → docs/17、docs/18 postmortem）。
   多极展开 + 取向平均给出的通道计数预言成分 2 是四极通道。
   **否**：‖Q‖² 对二值平面基线 0.308 [0.269, 0.345] vs 0.680 [0.607, 0.740]，区间不重叠；
   规范不变子空间版同样输；置换零分布下 p = 0.39。
   更要紧的是**检验对象本身不良定**：四极张量只在净电荷与净偶极皆为零时良定，
   而 Asp/Glu/Lys/Arg 净电荷 ±1，换原点相关从 0.308 掉到 0.074。
3. **场梯度与自由体积各向异性**（docs/16 P1/P2 → docs/14）。
   u₂ 与 ‖∇E‖² 的 r = −0.016 [−0.132, +0.106]；flatness/elongation/sphericity/n_lobes
   区间全盖零。**两条预注册预测都否。**
4. **流程自动产物**（docs/15）。同一实现在两个有功效的折叠矩阵给秩 0 和 1，
   虚警率 0，正控制给 2——**排除「秩 2 是双因素矩阵在这个流程下的自动产物」**。
5. **跨数据集的共同偏差**（docs/29 H5）。纯噪声过 144 个域各自的几何给中位 0.166、
   8.3% 超自身 p95（观测是 0.755 / 94.4%）。
   缺失偏倚一度**触发**判据（|cos(u, 逐残基缺失率)| = 0.673 ≥ 0.6），
   但按预先指定的后续从**两侧**投掉该方向后中位仍 **0.682 [0.660, 0.716]**、92.4% 超 p95
   → **共线而非因果**。

## 7. 必须与主张同行的限定（不是免责声明，是主张的一部分）

**(a) 跨家族证据只有两组，且质量不对等。**
一个非病毒抑制剂骨架（OMTKY3 对 3 个蛋白酶）+ 一个病毒 RBD 家族（对 ACE2 同源物）。
存活的三个 OMTKY3 矩阵只以 **0.051–0.105** 超自身几何的纯噪声 p95，
而冠状病毒侧是 **0.342–0.391**。写「两组」时必须连这个不对称一起写。
**且证据集的一部分此前从未被正确把闸**：平坦阈值 0.60 从未在闸实际运行的秩上标定过
（docs/24），标定后 3SGB 以 −0.029 不过，判为**不可读**而非「是噪声」。

**(b) 两组时共识轴本身可能不可辨识。**
穷举全部 15 种「每家族一代表」组合，两组时成对 |cos(u,u')| 最小 **0.003**、中位 0.714；
三组时是 0.499 / 中位 0.917（docs/28）。**k=2 退化比最初记录的严重。**

**(c)「结合」指直接测量的亲和力，带否证条件。**
本文的「结合」= Starr 的 Kd / OMTKY3 的 Ka 等**直接测量**值，
**不包括** ddPCA binding-PCA 经三状态解卷得到的 binding ΔΔG：
在 GRB2-SH3 上该层对 u 处于碰巧水平（0.250）且与折叠在细胞级反相关（−0.246）。
所以仓库唯一可用的同系统配对比较**不与本文主张矛盾——它的结合臂不是本文所说的「结合」**。
**否证条件**：若出现一个同构建体、两种表型各自独立测量、配对缺失 < 10% 的面板，
而其结合臂通过 D-036 与秩 2 可分辨闸后仍与折叠轴在碰巧水平，则 §3 的共用主张应被撤回。

**(d) 折叠侧宽、结合侧窄。** 折叠侧 n = 144 个域、22 个 SH3 折叠；
结合侧的「配对臂不可用」这一判断**宽度是 n = 1 个域**，
它靠机制（docs/15 §3.1/§7.1、docs/29）而不是靠宽度——
PSD95 两个方向都不过 D-036，GB1 没有独立丰度 assay。

**(e) 第三个独立家族在已知候选下取不到。**
本地穷尽（307 个矩阵进数值筛查；SKEMPI 两种全新判据各自独立重现「只有 OMTKY3 一个可用」；
PafA 是 Gly/Val 扫，全数据只有 4 种残基）。
唯一合格的外部候选 CR9114 四个矩阵里三个因滴定范围覆盖不到而不过截尾闸
（f_out 27.5 / 36.6 / 74.5%），唯一过闸的 WT_H1 恰在多抗原轴与多骨架轴之外。
**所以议程是「去建第三个家族」而不是「去找」**：同骨架 × 多配体，且滴定范围覆盖全部变体。

**(f) 切点不要引用，引用单调分层。**
「≥25% 截尾 → 全给秩 0」在三代检测器下组大小是 7/9/7，线两侧 ±5pp 内的秩是 0、1、0，
30% 与 40% 处也不存在三代一致的切点。
**跨全部口径不动的只有单调性**：秩 0/1/2 的截尾中位 **43.2% / 10.9% / 0.1%**，
相邻层差 32pp 与 11pp，远大于一切口径差（docs/22、D-029）。

## 8. 方法学产出（独立于上面任何一条生物学主张）

这一节可能比主结果更有转引价值，因为每一条都是**被真实事故逼出来的**。

1. **截尾摧毁低秩可检出性**，而 DMS 数据里截尾普遍（本批最高 83%）。
   任何做同类分解的人都会撞上，且会把真结构读成「无结构」。
   **信噪比不是判据**（PD-CoV 三行：截尾 0.7/45.7/47.9% 与秩 2/0/不可判顺序一致，
   而信噪比 1.56/3.57/3.04 顺序**完全相反**）。
2. **截尾检测器有四种机制，不能用一个量**：硬赋值原子、噪声摊开的堆积、
   有界但不裁剪的平滑斜坡（Tite-seq，须用 f_out 而非 q）、
   越界替换成字面标记并扣留（Tsuboyama，可直接计数）。
   三代检测器都曾静默失效；**固定窗口两端不可能同时正确**。
3. **「两个方向对齐」的主张必须先证明每个方向自身可复现**（D-036）。
   Haar 零分布的显著性检验**完全不检查这件事**。
   这条规则在登记当天就砍掉了两个漂亮数字（|cos| = 0.962、r² = 0.652 且超过搜索天花板）。
4. **`coup_sd_true = sqrt(coup_sd_obs² − σ²)` 在 ΔΔG 为模型系数的数据上不是可判定量**。
   两个独立偏倚同向制造假阴性：体外总 RMSE 含逐位点系统差而双向中心化已把它
   吸收进行主效应（D-042）；双向中心化消耗自由度使 coup_sd_obs 低 3.8–6.7%，
   而 sqrt 把它放大到 **−100%（一个干净的 0.000）**（D-055，全静默）。
   **此前仓库只防了 σ 太小那一侧（D-028）。**
5. **可分辨性闸必须按几何、按秩标定**；判别力由**上限**（矩阵自身的秩 r 解释率）
   主导而非下限（r(gap, 上限) = +0.922，r(gap, 下限) = −0.615）。
   平坦阈值可能「碰巧可用」而非验证过可用。
6. **「欠功效」会伪装成结果，本项目出现四次**。任何「测不出结构」的结论
   必须先过理想条件还原性诊断；而**窄的子抽样区间不是精度的证据**——
   一个一致失效的闸给出的区间同样是窄的。
7. **过滤后的中位移动不是证据**：剔掉最不可分辨的第二维会把 cos θ2 中位
   从 0.327 抬到 0.477 而条件 p 不动（两处独立复现）。
8. **八次工具事故中三次全静默，两次以「发现了漂亮结构」的形式出现**
   （而非「什么都没发现」）。后者更危险，因为前六次的失败方向都是保守的。

## 9. 写作时的叙述顺序（建议）

1. 秩 2 本身（§1）——因为它是唯一不依赖任何轴解释的事实，且有内部极小。
2. 第二轴界面特异（§4）——先给坏消息，而且它直接回答「为什么便宜描述子排不出口袋」。
3. 第一轴普适 + 化学身份（§2）。
4. 第一轴与折叠共用（§3）——最意外的一条，放在读者已经接受前三节之后。
5. 具名替代解释的排除（§6）——这一节决定审稿人信不信前四节。
