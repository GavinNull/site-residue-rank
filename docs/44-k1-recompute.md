## 1. 生产模块 `analysis/rank_k1.py` 及其双向自检

接口与 `rank_core.cv_rank_noleak` 相同（参数名、默认值、返回 `{rank: (rmse_full, rmse_trim95, rmse_median)}`），所以可直接传给 `rank_core.best_rank`。
每折：训练格子上**联合**拟合 r_i + c_j + UVᵀ（偏置不受岭惩罚）；偏置初值只看训练格子；训练误差只在训练格子上算；留出格子的真值只在最后一步算误差时出现。
度量 trim95。**不含任何 σ 的估计，不使用 `coup_sd_true`。**

**一处偏离任务书，如实记录**：任务书要求「复用 `als_guarded`」。K1 的模型（偏置列不受岭惩罚、与因子联合更新）不是 `als_guarded` 能表达的——后者拟合已去中心化的残差上的纯低秩项。所以生产模块没有字面调用它，而是用一个**保护语义相同**的联合版本 `als_joint`：训练观测数 < rank+2 的行/列（比 `als_guarded` 的 rank+1 多一个，因为偏置多一个参数），因子置 0、偏置取其观测均值，即退化为加性预测。该保护由自检 K-guard 直接验证；`als_joint` 与 docs/43 原型 `overshoot_lib.als_joint` 逐位一致（K-proto）。**未使用** `als_complete`。

`python3 analysis/rank_k1.py` 的自检（约 60 s；`k1_recompute.py` 与 `k1_reproduce.py` 每次入口强制运行，不过即中止）：

| 项 | 已知事实 | 结果 |
|---|---|---|
| K-fact | 无噪声完备矩阵，联合拟合精确还原主效应 + 秩 0/1/2 | rel < 1e-4 |
| K-add | 秩 0 的联合拟合 == 缺失下收敛的加性最小二乘 | max\|Δ\| = 4.0e-09 |
| K-guard | 整行/整列缺失、仅 2 个观测的行：有限、量级同数据；欠定行的预测 = 加性预测（`P[7]−P[4]` 在所有列上是同一常数） | 通过 |
| K-leak | 改变一个格子的值，该格子被留出时的预测不变（3 个格子 × 秩 1,2） | 通过 |
| K-proto | 生产 K1 == docs/43 原型；现行程序逐格版 == `rank_core.cv_rank_noleak`（D-023 式「新实现 == 旧实现」） | trim95 曲线与逐格误差 < 1e-12 |
| K-trim | trim95 已知值 | 通过 |
| K-hit（命中） | 植入秩 2，σ = 0.64（中等）与 0.15（高），各 3 个种子 | K1 = 2，6/6 |

§2.4 的「相关系数本身反而稳健……全距只有 0.029」是三代检测器 × 现行定秩的结果，**在 K1 下只重算了第一代（等于第三代）与第二代**：现行 −0.80 / −0.78，K1 −0.60 / −0.63（Spearman）。写法：「相关系数对检测器代际稳健（K1 下两代的 Spearman 为 −0.60 与 −0.63），但它依赖定秩程序：从现行程序换到去偏程序，Spearman 从 −0.80 降到 −0.60」。「全距 0.029」「十一个口径值」这句话**不得保留**——它没有在 K1 下重算。

### 8.9 §7（限定）里的 CR9114 一句（docs/35 §7.5 已有，建议微调）

> **CR9114 不在 §2.1 的体系表里。** 它不过截尾闸（三个矩阵的滴定窗外比例 27.5% / 36.6% / 74.5%），人类裁定不将其纳入证据集；在去偏程序下它的唯一可判读矩阵（WT_H1）为秩 1（出自 docs/43，本文未重算）。早期版本曾把它列为「同向支持秩 2」，那个读法既依赖已知向上偏的程序，又依赖一个不过闸的矩阵。

## 9. 影响：哪些主张在「种类」上变了，而不只是数字
