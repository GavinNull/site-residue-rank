# 配对 n=1 的阴性 vs 跨数据集 n=144 的阳性：追到底是哪一个错（2026-10-13）

> 人类指令：「追，这是最后一个真矛盾」。
>
> **判决（先说）：不是矛盾。两个测量不是在测同一个对象，而且这一点是测出来的、
> 不是论出来的。** 在 GRB2-SH3 **自己的 619 个配对格子上**，折叠轴与
> binding 共识普适轴 u 的 \|cos\| = **0.764**（d = 20 的 Haar p95 = 0.441），
> 与 n = 144 的中位 **0.755** 几乎逐位重合 —— **n = 144 的结果在配对设计的

> ΔΔG 第一轴对同一条 u 只有 **0.250**（碰巧水平），而且这与配对 mask 无关

> 所以 docs/28 §8.2 那个 0.016 **不是**「折叠与结合不共享方向」的证据，
> 它是「ddPCA 的 binding ΔΔG 交互项不是一个能当结合轴用的量」的证据。

> **headline 的那句话存活，但必须加一条写明的例外**（§8）。

## 3. H6 / H3 的三角化：**本文档最强的一个观测，而且它与 σ 无关**

脚本 `analysis/paired_conflict.py` 的 `h3_h6()`，产物 `cache/docs29_paired.json`。
u = binding 共识普适轴，取自 `cache/generic_folding_axis.json` 的 `u`
（与 docs/26 / docs/27 用的**同一条**；残基顺序对 `AA20` 做了硬断言，
D-023 同型防护）。零分布 d = 20：Haar 一维 \|cos\| 中位 **0.162**、p95 **0.441**。

| 比较 | \|cos\| | 带符号 cos | 超 p95 |
|---|---|---|---|
| **折叠轴_paired × 结合轴_paired** | **0.016** | −0.016 | 否 |
| **折叠轴_paired × u** | **0.764** | +0.764 | **是** |
| **结合轴_paired × u** | **0.250** | +0.250 | **否** |
| 折叠轴_paired × 折叠轴_full | **0.948** | +0.948 | 是 |
| 结合轴_paired × 结合轴_full | **0.999** | +0.999 | 是 |
| 折叠轴_full × u | **0.842** | +0.842 | 是 |
| **结合轴_full × u** | **0.249** | +0.249 | **否** |
| 折叠轴_full × docs/26 §7.3 登记的那一条轴 | **1.000** | +1.000 | 是 |

最后一行是一次**逐位复现核对**：本文档从原始数据重抽的 GRB2-SH3/folding
第一轴与 docs/26 登记在 `cache/generic_folding_axis.json` 里的那一条
\|cos\| = 1.000，而它对 u 是 0.842 —— 与 docs/26 §7.3 的 **0.842** 逐位一致。
所以本文档和 docs/26 用的是同一个对象，没有换口径。

**三件事必须一起读：**

1. **折叠臂在配对 mask 上活着，而且它复现 n = 144。**
   配对后的折叠轴对 u 是 **0.764** —— n = 144 的中位是 **0.755**，
   四分位 [0.645, 0.822]。**0.764 落在那个四分位的正中间。**
   并且配对前后的折叠轴 \|cos\| = 0.948，即 41.8% 的配对缺失**没有**毁掉折叠轴。
2. **结合臂对 u 在碰巧水平，而且这与配对 mask 无关。**
   结合轴_paired × u = 0.250、结合轴_full × u = 0.249，两条结合轴彼此 0.999。
   **配对 mask 不是结合臂失败的原因** —— 它在自己的 mask 上就已经不对 u。
3. **三角化的硬几何下界在这里不构成约束，而这正是结论。**
   若 \|cos(a,u)\| = c₁、\|cos(b,u)\| = c₂，则
   \|cos(a,b)\| ≥ c₁c₂ − √(1−c₁²)√(1−c₂²)（工具 `tri_bound`，4000 次随机三元组
   零违反，§7 自检 S2）。代入 0.764 与 0.250 得下界 **−0.434** —— 负数，
   即**无约束**。
   **换句话说：只要结合臂对 u 本身在碰巧水平，0.016 在几何上就是允许的，
   不需要任何额外机制去解释它。**
   反过来说，如果结合臂也像折叠臂那样对 u 有 0.76，那么下界会是
   0.76×0.76 − 0.65×0.65 = **+0.155**，0.016 就**不可能**出现。
   docs/28 §8.2 的「若两轴相同应见 ≈ 0.50」那个功效论证是对的，
   它缺的是**先问结合臂在测什么**。

> **这一条与 σ 无关、与噪声模型无关、与 ρ 扫描无关。**
> 它只用了四个 \|cos\| 和一条几何不等式。本仓库在 σ 口径上栽过两次
> （D-042、D-055），所以一条不含 σ 的判别观测量在这里的价值要单独写明。

### 3.1 H3 第一条：主效应层的落差

配对 mask 上，**ΔΔG 层**两个表型的残基主效应 \|cos\| = **0.141**（带符号 **+0.141**）。
对读 **fitness 层**（docs/28 §8.2 限定 2）：**0.770**。

**这是一个 0.770 → 0.141 的落差。** 它说明 mochi 的三态解卷在主效应层
**几乎把共享成分全部扣掉了**。方向本身**不为负**（+0.141），所以按预先登记，
单看这一条**不支持**「过度校正」，只支持「校正很彻底」。

### 3.2 H3 第二条：格子层的带符号相关 —— **过度校正签名开火**

| 量 | 值 |
|---|---|
| r(折叠交互残差, 结合交互残差)，619 个配对格子 | **−0.246** |
| 位点层 bootstrap 95%（已知偏低，照 docs/13 §6.2 记） | **[−0.333, −0.157]** |
| 位点内置换零分布：中位 / 5% 分位 / 95% 分位 | −0.002 / **−0.096** / +0.092 |
| 预先登记判读 | r < 置换 5% 分位 → **过度校正（H3）** |

**−0.246 低于置换零分布的 5% 分位 −0.096，区间 [−0.333, −0.157] 整段在零以下。
按预先写定的判据，这是「过度校正」那一档，不是「本来没有共享成分」那一档。**

**但这一条的因果归属必须限定，而且限定是实质性的。** 一个负相关至少有两条
互不排斥的来源：
(a) 解卷真的把一份共享的折叠成分从 binding ΔΔG 里扣过头，于是残差带上反号；
(b) 两个系数是从**同一组** binding-PCA 观测里**联合**拟合出来的，
    于是它们的**估计误差**按构造负相关（一份观测里多归给折叠的，就少归给结合）。
**本文档不能把 (a) 与 (b) 分开**（要分开需要一组独立测定的 binding ΔΔG，
而那正是 docs/15 §7.1 缺的东西）。
**但对本文档要回答的问题，(a) 与 (b) 给出同一个操作性结论**：
**ddPCA 的 binding ΔΔG 交互项不能当作配对比较的结合臂用。**
所以 §8 的 headline 例外按这个较弱、也较稳的措辞写，而不按「mochi 过度校正」写。

## 5. H2：衰减校正化解不了，而 ρ 扫描说这个阴性**确实有功效**

### 5.1 衰减校正（含区间）

| 量 | 值 |
|---|---|
| 实测 \|cos\| | **0.016** |
| D-036 折叠 / 结合（`nsplit = 400`，seed 12 / 11） | **0.504 / 0.477**（Haar p95 0.441，两条都过） |

> 不同种子 / `nsplit` 报 0.504 / 0.477。**两档判读完全相同**（都过 0.441，

**docs/28 用未校正的 0.016 去比未校正的期望 0.490，是同口径的正确比较。**
人类在任务里提的那一问（「未校正的比较是对的吗」）—— **是对的。**

### 5.2 ρ 扫描（功效的正确检验）

在配对 mask **自己的**几何 / 缺失模式 / 主效应尺度下，把结合矩阵的真方向
植入为 `ρ·(折叠轴) + √(1−ρ²)·(与之正交的随机方向)`，走**完全相同**的流程。

**σ 标定（强制报残差）**：让合成的结合轴位点对半可复现度贴住实测 **0.477**
→ **σ\* = 0.4**，合成可复现度 **0.505**，**残差 0.028**。
脚本在残差 ≥ 0.08 时**断言中止**（那就是 docs/28 §4.4 的「生成模型错」），

预先登记 §2.H2 的两条判据逐字是：

实测对账：

| 判据的分句 | 实测 | 满足？ |
|---|---|---|
| 支持：最小 ρ ≥ 0.78 | 0.70 | **否** |

| 否证：ρ = 0.78 格的区间不含 0.016 | 不含 | **是** |

**所以严格按预先登记，H2 的"支持"两条都不成立，而"否证"的第二个分句
差一格没走到**（0.70 vs 门槛 0.60）。**本文档不把它写成干净的"否证"，
也不改判据去迎合结果（§4）。** 准确的措辞是：

> **H2 被排除为对 0.016 的解释，但它附带的那条功效声明要降一档。**
> 衰减校正那条路**算术上就不通**（乘数 2.04，0.016 → 0.033）；
> ρ 扫描说这个阴性**确实能**把 ρ ≈ 0.78 排除掉
> （0.78 那一格的 95% 区间 [0.415, 0.791] 整段在实测 0.016 之上，检出率 0.95）
> —— 所以 docs/28 §8.2 的功效说明站得住。
> **但它只能排除到 ρ ≈ 0.70 这一档，排不到预先登记希望的 0.60。**
> 即：这批数据无法把「结合臂与折叠臂真实一致度 ρ ≤ 0.6」与
> 「ρ = 0」区分开（ρ = 0.6 的检出率 0.68、ρ = 0.4 只有 0.27、
> **ρ = 0 那一格的区间 [0.008, 0.445] 包含实测 0.016**）。

这个降档**不改变本文档的主结论**，因为主结论不依赖 ρ 扫描：
§3 的三角化已经与 σ 无关地说明了结合臂在测什么。
但它改变一句话的写法：**docs/28 §8.2 那个阴性「能把相同与正交分开」
应读成「能把 ρ ≳ 0.7 与 ρ ≲ 0.6 分开」，不是「能把任何非零一致度排除」。**

**关键限定（这是 §3 之所以必要的原因）**：
**ρ 扫描回答的是「结合臂与折叠臂一致吗」，答案是"不一致，而且这不是没功效"。
它不回答「结合臂在测什么」。** §3 回答了后者：结合臂对 u 本身只有 0.250。
**ρ = 0 那一格的区间 [0.008, 0.445] 包含实测 0.016 —— 即这批数据与
「GRB2 的 binding ΔΔG 交互轴与折叠轴真实一致度为 0」相容。**
把 §3 与这一格放在一起读：
**结合臂既不像折叠轴，也不像 u。它不像任何一条已经建立起来的方向。**

## 6. H1 与 H5

### 6.1 H1 信息性缺失：**人类点名的那个直接检验在这批数据上做不成，而"做不成"本身是一个结果**

脚本 `analysis/paired_conflict.py` 的 `h1()` 与
`analysis/paired_conflict_followup.py` 的 `partA()` / `partA2()`。

完全观测块的定义在预先登记里写定（贪心剔除观测最少的行/列直到块全满，
**只有一个定义，不扫阈值**）。实测：

一维 Haar \|cos\| 的 p95 已经在 0.8 附近 —— **这个块抽不出可比较的方向，
所以 H1 的直接检验按预先登记判为「不可判定」，而不是「仍是 0.016」。**

> **"做不成"是一个实质结果，不是一句推托。**
> 41.8% 的配对缺失**不是**集中在少数行列上，而是**弥散**的
> —— 弥散到剔不出一个 10×10 的完整块。
> 这正是 docs/15 §3.1 那条机制的直接后果：被切掉的格子是
> 「该变体解折叠了，于是它的 binding ΔΔG 没有被数据约束」，
> 而解折叠的变体散落在**所有**位点上，不集中在某几个。
> **所以在 ddPCA 的 GRB2-SH3 上，"在完全观测子矩阵上复核"这件事
> 原理上就不可行。** 这一条补进 docs/15 §3.1 该说的话（§9）。

**放松口径的那一次：数字动得很大，而闸不让用。**
在「每行每列 ≤ 2 洞」的 16 位点 × 8 残基（残基 F G I L N S T Y）块上：

| 量 | 值 |
|---|---|
| 块内 D-036：折叠 / 结合 | **0.759 过 / 0.142 不过**（d = 8 的 Haar p95 **0.713**） |

**这个 0.568 不进任何判决，三条独立的理由，每一条单独就够：**
(1) 结合臂在块内不过 D-036（0.142 对 0.713）—— 按 D-036 的前置，
    配对主张**不允许**提；
(2) σ 标定残差 0.103 ≥ 预先写定的 0.08 门槛 —— 还原诊断自己不成立；
(3) 置换零分布的中位与 p95 都是 0.216（退化），p 值无意义。

> **但它必须被报出来，因为它是对本文档结论的一处反向证据。**
> 诚实的读法是：**H1 在这批数据上不可判定，而且有一个不可采信的迹象
> 表明它可能不是零。** 把它写成「H1 已排除」是过度声明；
> 写成「0.568 说明缺失是主因」是拿一个三重违规的数字当证据。
> **H1 的处置是「不可判定，待一组缺失率 < 10% 的配对数据」**（§8.3）。

**H1 与 H3/H6 不是两个独立机制，这一点要写明。**
GRB2-SH3 binding 自己的 mask 就有 41.6% 缺失、其中 **28.9% 是结构性 NA**
（docs/15 §3 的分解）。这些 NA 的来源与 §3.2 那个负相关的来源**是同一个**：
三态模型在变体解折叠之后对 binding ΔΔG 既失去约束（→ NA），
又在还有约束的格子上把共享成分归给折叠（→ 负相关）。
**所以 H1 与 H3 是同一个机制的两个面，不是两个竞争解释。**

### 8.2 一句话的判决

**矛盾不成立，因为它不是同一个比较。**

n = 144 比的是「折叠交互轴 vs **直接 Kd 测定**（Starr / OMTKY3）建出的
binding 共识轴 u」。配对 n = 1 比的是「折叠交互轴 vs **mochi 从同一组
binding-PCA 观测里解卷出来的** binding ΔΔG 交互轴」。

**在 GRB2-SH3 自己的 619 个配对格子上，第一个比较的结果原地复现了
（0.764，144 的中位是 0.755）。第二个比较的结合臂对 u 只有 0.250 —— 碰巧水平。
而只要结合臂对 u 在碰巧水平，0.016 在几何上就不需要任何额外机制。**

**所以 docs/28 §8.2 的 0.016 要改读**：它不是「折叠与结合的残基方向不共享」的
证据（它没有功效去说这件事 —— 它的结合臂不在测那条方向），
它是「**ddPCA 的 binding ΔΔG 交互项不能当配对比较的结合臂用**」的证据，
而这一条现在有两条独立签名支撑：
(i) 它对一条已独立建立、且在同一个域的折叠臂上被复现的方向 u 处于碰巧水平；
(ii) 它与折叠交互残差在格子层**负相关** −0.246，低于置换零分布的 5% 分位。

**docs/28 §8.2 的结论（"配对的 folding–binding 对照仍然没有做成"）不变，
但理由从"精度不足 + 信息性缺失"升级为"结合臂被测到不在测那条方向"。**
这是一个更强、而且**可证伪**的理由（证伪条件见 §8.3）。

### 8.3 headline 的 scope 句现在该说什么

> **旧（docs/27 §7 的 headline 第 1 条）**：
> 「一条**折叠与结合共用**的残基方向，ρ ≈ 0.78 [0.75, 0.80]，
> 结合特异残差 ~40%」。

**判决：存活，但必须加一条写明的例外与一条新增的正向证据。本体不动。**

> **新**：

> —— 其中「结合」指的是直接测定的结合亲和力（Starr RBD/ACE2 的 Kd、
> OMTKY3 的 Ka），不包括 ddPCA binding-PCA 经三态解卷得到的 binding ΔΔG。**

3. **n = 1 仍然是 n = 1。** 本文档的三角化只在 GRB2-SH3 上做成
   （PSD95-PDZ3 的两条方向在 docs/28 §8.2 都不过 D-036，配对主张不允许提；
   GB1 没有独立 abundance assay）。

   —— 后者需要同一个结构域的直接结合测定，本仓库没有。
