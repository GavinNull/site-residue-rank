## 2. 检测器的设计

脚本：`analysis/censor_density.py`。自检：`analysis/censor_density_check.py`。

### 2.1 机制 → 估计量（设计的全部依据）

真实机制（docs/19 §2.2 的合成网格就是按它写的，本模块**逐字复用**
那个 `_synth_censored`，并由自检项 [0] 用同一种子逐元素核对）：
真值低于检测下限 `c` 的格子被**压平到 c**，再叠一层 SD = σ 的测量噪声。
于是观测分布是一个两成分混合：

- **堆积**：质量 q，分布 ≈ `N(c, σ)`；
- **连续成分**：质量 1−q，**在 c 以下几乎没有质量**（只有被噪声漏下去的
  `O(0.4·σ·f(c))`）。

这给出两个**互相独立**的 q 估计量，它们必须一致 —— 这一点本身就是自检：

**(I) 反射法。** c 以下几乎只有堆积，而堆积关于 c 对称，所以

```
q ≈ 2·P(X < c) + P(X = c) − (c 以下的硬赋原子质量)
```

第二项处理 σ = 0 的原子（Starr 的 ACE2 系列把非结合变体硬赋成 5.000/6.000）；
第三项防止「原子被当成对称堆积的下半」而**双计**（不减这一项，σ = 0 时
会把 q 测成 2q）。**两端由同一个公式覆盖**，这正是固定窗口做不到的事。

**(II) 截断拟合法。** 取最低 m 个观测，它们是 `N(c, σ)` **右截断**在
`T = x_(m)` 的样本。右截断正态的前两阶矩只依赖 `t = (T−c)/σ` 与 σ：

```
E[T−X] = σ(t+λ),  Var[T−X] = σ²(1 − tλ − λ²),  λ = φ(t)/Φ(t)
```

所以 `CV² = Var/E²` **只是 t 的单调函数**（自检项 [1] 核对单调性，
并用已知事实 `CV²(0) = π/2 − 1` 核对实现）。一次反演得 `t̂`，继而
`σ̂ = m̂₁/(t̂+λ)`、`ĉ = T − σ̂t̂`、`q ≈ m/(n·Φ(t̂))`。
这是**矩估计，没有优化器**；先试过的右截断正态 MLE 在这类数据上
数值发散（见 §2.4）。

**选 m 的判据不是调参，是 (I) 与 (II) 的一致性。** 扫 m，取
`resid = |q_II − q_I| / q_I` 最小的那些。
**残差并列必须取中位数，不能取 argmin**：实测里常有一个小 m 的
「部分堆积」拟合与正确的大 m 拟合残差几乎相等（0.0018 vs 0.0026），
argmin 于是变成抛硬币 —— 合成网格上约 1/8 的重复因此塌到真值的 1/4 以下。
那正是本检测器要修掉的失效模式。所以最终口径是
**对 `resid ≤ 2·min + 0.01` 的全部候选取中位数**。

### 2.2 三道存在性闸（既要命中也要不误伤，CLAUDE.md §10.2）

| 闸 | 判据 | 它挡住什么 |
|---|---|---|
| 1 宽度 | `σ̂ ≤ γ·s_up`，γ = 0.35 | `s_up` 是**上半分布**的鲁棒尺度（压平只压低端，上半是唯一干净的参照）。无截尾的单峰分布拟合出来的「堆积」就是分布本体，`σ̂/s_up ≈ 1`；真堆积在本项目里是 0.02–0.31。 |
| 2 量级常识 | `σ̂ ≤ 0.7·IQR/1.349` | 堆积不可能比分布自己的中心尺度还宽。 |
| 3 极值一致性 | `(ĉ−min)/σ̂ ∈ [0.6, 1.35]·z*`，`z* = Φ⁻¹(1 − 1/(q̂n+1))` | 若堆积真有 `q̂n` 个点、宽 σ̂，样本最小值就应落在 ĉ 以下约 z* 个 σ̂ 处。**这是把「尖峰 + 长尾的分布本体」从「下限堆积」里分出来的关键**：GB1 与 PSD95-PDZ3 的比值高达 5.0，真堆积是 2.3–3.4。少了这一条，**GB1 会被误判成 67%–79% 截尾**（已知事实：ddPCA 推出的 ΔΔG，无下限赋值）。 |

`s_up` 取**三对上分位各自给出尺度的最小值**，不是最大值：取最大会被右侧
长尾撑大（PSD95-PDZ3 的 `(Q95−Q75)/0.971 = 8.9`，而它的中心尺度只有 0.94），
闸 1 形同虚设，实测中 PSD95-PDZ3 正是因此被误判成 10.8%。
取最小使这道闸**更难**通过，偏向不误伤那一侧。

最终报的是 `max(原子比例, 混合模型给的 q_I)`，并带 **80% 不放回子抽样
（12 次）的 10–90% 区间**（CLAUDE.md §5：点估计不单独汇报）。
不放回而不是有放回 bootstrap，因为有放回会制造人工并列、污染原子分支。

### 2.3 假设（不满足就不适用，必须随数字带着）

1. 机制是「压平到下限 + 叠噪声」，所以堆积关于 c 近似对称、近似高斯。
   若机制是「下限以下直接记成 NA」，数值里根本没有堆积，本检测器
   正确地报 ~0 —— 那种截尾要用**缺失率**度量（docs/15 的口径），
   是另一个量，**不能与本量混用**。
2. 连续成分在 c 以下没有实质质量。
3. `σ ≪ s_up`。σ ~ s_up 时堆积与分布本体不可分，本检测器报 ~0，
   而且**应该**报 ~0：那时「截尾比例」本身没有定义。
4. `n ≥ 200` 且堆积质量 ≳ 2%（最低 m 个点要够估两个矩）。

### 2.4 搜索量（CLAUDE.md §5）

到定稿这个形式之前试过的**估计量族 4 个**：
(i) 核密度 + 最低局部极大 + 宽度/凹陷闸（3 种带宽规则：低 25% / 10% / 5% 的
Silverman）；(ii) 下尾半正态 KS 拟合（3 种选择规则 × κ ∈ {0.8, 1.0, 1.3}）；
(iii) 右截断正态 MLE（Nelder-Mead，**数值发散，丢弃**）；
(iv) **右截断正态矩估计（采用）**。

在 (iv) 上试过的**选择规则 6 种**：min-resid（argmin）、前 K 个取中位、
`resid ≤ 0.30` 取中位、`resid ≤ τ` 取最大 q（τ ∈ {0.03, 0.05, 0.10}）、
`J = resid + |ev/z*−1|` 取最小、σ̂ 平台法（ε ∈ {0.3, 0.5, 0.8}），
最后采用**残差并列取中位**。
标度定义 2 种（上分位取 max / 取 min），γ ∈ {0.20, 0.25, 0.30, 0.35, 0.45, 0.50}，
中心尺度系数 ∈ {0.6, 0.7, 1.0}，极值带上界 ∈ {1.25, 1.35, 1.4, 1.6}，
`m_min` ∈ {25, 40, 60, 100}，`n_m` ∈ {30, 60, 80, 120, 160, 240}。

**诚实记录**：这个搜索量不小，而且中间有几个版本是先看到「真实锚点不对」
才改的（PSD95 的 10.8% 误伤促成了 `s_up` 取 min；GB1 的 67% 误伤促成了
极值闸）。这**不是**按合成网格的结果调参 —— 改动都是被**已知事实的锚点**
逼出来的，而且每次改动都要重跑整张网格，不许只看锚点。
`[S]` 扫描（§2.6）给出结论对剩下参数的不敏感性。

### 2.5 适用域声明（必须随每个数字一起读）

- **σ = 0（硬赋原子）**：精确，偏 ≤ 0.0pp（第二版在这里偏高 +7..+10pp）。
- **0 < σ ≤ 0.05**：|测 − q| ≤ 4.2pp。
- **σ = 0.07–0.20（盲区）**：偏 +0.2 到 +14.4pp，**系统性偏高**，
  且在 σ = 0.20 / q = 0.40 一格最大。绝对数值在这一带只能读到 ±15pp。
- **逐矩阵方差大**：单次拟合的跨度可达 ±15pp，所以**必须看子抽样区间**。
  `lehner/GB1/IgG-Fc` 的点估计 0.1% 而子抽样区间 [0.1%, 76.6%] ——
  它正好压在极值闸的边界上，**本检测器对 GB1 这类「尖峰 + 长右尾」
  形状不可靠**。这不影响本文档的任何结论（GB1 已按人类决定剔除），
  但必须写出来。
- σ ~ s_up 时报 ~0 是**定义上正确**而不是失效（假设 3）。

要求「由标定过的仪器而不是由哪边有利来决定」的直接满足。

**两条互相独立的理由，指向同一结论：**

1. **检测器**：扫遍 m 都找不到同时满足三道闸的拟合 —— 低端没有窄堆积。
2. **机制核对（不依赖检测器）**：这四个矩阵自己的最小值比**所在源文件
   全体骨架 × 配体的全局最小值**高出 +0.545 到 +1.256。
   animalACE2 文件的全局最小值正是 **5.000**（非结合变体被硬赋成这个值），
   而 BA2/bat 的 min = 5.915、Eta/bat = 5.736、BA2/cat = 5.545；
   PDCoV 文件全局 min = 4.155，而 gAPN 的 min = 5.411。
   **它们根本没有触到检测下限**，所以「下限堆积」在它们里面不存在。

**那 `w = 1.00` 的 27.8%–86.9% 是什么？** 标尺假象。这些矩阵的动态范围
本身就小：BA2/bat 的 `IQR/1.349 = 0.241`，于是 `w = 1.00` 相当于
**4.4 个鲁棒尺度**，一个覆盖 4.4σ 的窗口当然会吃掉 87% 的数据。
docs/19 §7 自己已经警告「`w = 1.00` 在 log10 Ka 上已接近一个整效应量级，
放宽窗口会吃进真信号，所以这是线索不是判定」—— 这次的判定确认
那四条线索**全部是假信号**，而 docs/19 的谨慎是对的。
BA2/bat 低端密度那个「min + 0.65 处的局部峰」是分布本体的众数
（这个矩阵的整体 sd 只有 0.225，min 到众数就是 ~3 个 sd），
不是堆积；密度在它左侧**单调上升**，没有堆积该有的「先峰后谷」。

**顺带的方法学结论**：这四个矩阵的问题不是截尾，而是**动态范围/信噪**。
Omicron_BA2 对 bat ACE2 结合弱，整个库的 log10 Ka 被压在 1.4 个单位里
（sd 0.225，而同骨架的 human_monomer 是 0.936）。
「低动态范围」与「下限截尾」是两件不同的事，本仓库此前把它们混在
一个数字里。这应该是一个单独的量，记在 §9。

## 5. 重算的共识统计

### 5.1 k = 2 的退化（必须先说，否则下面的数会被误读）

两组各取一个代表时：观测 λ = **[0.971, 0.907, 0.093]**，
无条件零分布 p95 = [0.821, 0.654, 0.495]，λ2 的条件零分布 p = 0.0000。
**这一格不能用**，三条理由：

1. k = 2 时 `P̄` 完全由**一个**配对决定，λ1、λ2 只是那一对
   cos θ1 = 0.942、cos θ2 = 0.814 的重写。「共识」没有共识含义。
2. 那一个配对恰好是 25 个跨家族配对里 cos θ2 最高的之一
   （0.814，而 25 对的中位是 0.327）。换代表会完全改变结论。
3. λ1 = 0.971 与 λ2 = 0.907 挨得太近，首特征向量不可辨识：
   换冠状病毒代表时 `|cos(u, u')|` = 1.000 / 0.962 / 0.924 /
   **0.547** / **0.533**（docs/13 三组时是 0.936–0.985）。

把 k = 2 的 p = 0.0000 当成「第二轴也普适」会是本文档最容易犯的错误。
**它不是证据，它是 k = 2 的算术。**

### 5.2 正确的两组构造：先家族内平均，再家族等权

投影算子取平均。家族权重仍是 1:1，但 u 由 9 个矩阵共同决定。
零分布用**同一个结构**生成（两组各 k 个 Haar 随机 2 维面，先家族内平均
再等权），4000 次。

| λ3 | 0.305 | 0.272 | 略超 |

**n = 5，不作为证据**，只作记录 —— 这个子集太小，而且它与上面
25 对的 cos θ2 中位（0.327）不一致，正说明它是选择效应。

**bootstrap 向下偏的声明照旧成立**（docs/13 §6.2）：按位点有放回重抽
使 bootstrap 中位 / 点估计 ≈ 0.65，所以 bootstrap 下界**不是**点估计的
置信下界。本节的判决一律走共识层面的 λ 与标定后的条件零分布。

## 7. 第二轴：两组证据下的判决

| 证据 | 结果 | 对「第二轴普适」的含义 |
|---|---|---|
| 两组家族平均的 λ2（§5.2） | 0.625，条件零分布 **p = 0.2765** | **不支持** |
| 25 个跨家族配对的 cos θ2（§5.5） | 中位 0.327，52% 超 p95 | **不支持**（抛硬币） |
| OMTKY3 一骨架 4 配体的第二轴（docs/13 §6.3） | 四个不同的第二轴，cos θ2 0.026–0.761 | **证伪「第二轴是氨基酸的性质」** |
| 冠状病毒家族内部 λ2 = 0.894、PR = 1.24 | p = 0.0000 | 家族内**确有**一条共享第二轴 |
| 可分辨全集 k = 9 的 λ2 = 0.652 | p = 0.0000 | 被家族内共享撑起来（冠状病毒占 5/9），**不是跨家族证据** |

**所以：docs/13 §0 保留的那个弱版本「第二轴受约束但由界面决定」，
在两组证据下连「受约束」也拿不出来。**
能说的只有两句：
1. 冠状病毒 RBD 家族内部有一条定义清晰的共享第二轴（平面 sp²/芳香
   vs β-分支），这是**家族效应**；
2. 跨这两组家族，第二方向既不相同，也没有证据说它被约束在低维里。

同时 PR 这一侧并没有说「各向同性」：可分辨全集 k = 9 的 PR = 2.26 对
零分布 6.27 [5.42, 7.03]，单尾 p = 0.0000。两件事都真：
**λ2 的跨家族共享不成立，而残差方向整体也不是各向同性。**
这不矛盾 —— PR 把 9 个方向一起看，其中 5 个是同一个病毒家族。

### 7.1 docs/13 §6.5 的措辞问题（docs/20 已指出，本文档改掉）

docs/13 §6.5 把 OMTKY3 × 4 蛋白酶的 PR 读成
**「几乎各向同性、勉强超出」**。这比数字支持的要弱：

- 单尾 p = **0.0045**（本文档重算；docs/13 记 0.0043），
  在任何常规水平下都**清楚地落在零分布之外**，不是「勉强」。
- 「各向同性」的基线不是 0。18 维里两条随机一维方向的 `|cos|`
  中位 = **0.165**、均值 0.191（解析 `E|cos| = sqrt(2/(πd)) = 0.188`，
  200000 次模拟，`numpy` 随机数，种子 1）。
  所以 OMTKY3 的 cos θ2 中位 0.291 本身就**高于**各向同性基线。
- docs/13 §6.4 自己的措辞**「不相同，但也不各向同性」**是准确的那一个。

§6.5 已改成与 §6.4 一致。
