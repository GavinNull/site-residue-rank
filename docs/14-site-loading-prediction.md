# 位点载荷 u₁ / u₂ 能不能只从口袋结构算出来

2026-10-11。回答的是 docs/12 明确留下的缺口（§6「不提供可预测的代理量」）：
秩 2 已经成立，

$$\Delta\Delta G(\text{位点},\text{残基}) \approx a(\text{残基}) + b(\text{位点})
+ u_1(\text{位点})v_1(\text{残基}) + u_2(\text{位点})v_2(\text{残基})$$

若 u₁、u₂ 可由结构算出，则 v 是一张固定的 20×2 表，口袋只通过**两个标量**进入，
整个代理量就是闭式、可微、便宜的。本文给出的答案是**不对称的**：
u₁ 可预测（样本外 R² = 0.41，天花板 0.99），u₂ 基本不可预测（0.17），
而且两个预注册的物理解释（docs/16 的 P1 四极、P2 堆积各向异性）**都不成立**。

所有数字的脚本与数据在每节末尾标出。涉及的三个脚本都带强制自检，
不通过即中止（CLAUDE.md §10）。

## 1. 规范固定（gauge fixing）——没有这一步后面全是无意义的

U、V 只在共享的可逆 2×2 变换下唯一：`U S V^T = (L B^T)(V B^{-T})^T`。
所以 u₁(site)、u₂(site) 在固定规范之前**没有任何单独的含义**，
跨体系比较位点载荷更没有。本文采用的规范，逐条写明：

1. **参考基**：`Wuhan-Hu-1 × bind_human_monomer`
   （SARS-CoV-2 RBD × 人 ACE2 —— 也正是 6M0J 那个复合物本身）。
   200 位点 × 20 残基、3953 观测、截尾 0.2%，是本批里最大且截尾最少的矩阵。
2. **定标**：V 的两列归一到单位范数，尺度全部放进 `L = U·S`。
3. **定向**：成分 1 的符号取成「残基载荷与 Fauchere–Pliska 疏水性 π 负相关」
   （定向后 r = **−0.858**）；成分 2 取成「与平面 sp² 指示变量负相关」
   （定向后 r = **−0.771**）。
4. **对齐**：其余组合在**共同残基**上最小二乘求 B（2×2）使 `V ≈ V_ref·B`，
   则位点载荷按 `L' = L·B^T` 变换。
5. **可比性判据（事先声明）**：相对残差
   `‖V − V_ref B‖_F / ‖V‖_F > 0.40` 的组合其位点载荷不可比，剔除。

ΔΔG 方向约定：原始 `bind_*` 是 log10 Ka（越大结合越强），本文一律取负号，
故矩阵元是「越大越不利」的 ΔΔG 型量，单位 log10 Ka；
换算 1 log10 Ka = 1.36 kcal/mol（RT·ln10，298 K）。

## 2. 重复可靠度 —— R² 的天花板（先报这个，否则 R² 无法解释）

12 个可比组合给**同一批位点**提供 u 的重复估计。各组合先 z 标准化
（尺度随配体的动态范围变，不是位点性质），再比较。

| 量 | 两两相关 平均（95% CI） | 范围 | 单组合可靠度 | 12 组合共识可靠度 | 分半经验校验 |
|---|---|---|---|---|---|
| **u₁** | **+0.871** [+0.849, +0.891] | +0.655 … +0.975 | 0.871 | **0.988** | 半-半 r = 0.975 → 0.987 |
| **u₂** | **+0.826** [+0.791, +0.861] | +0.604 … +0.960 | 0.826 | **0.983** | 半-半 r = 0.967 → 0.983 |

共识可靠度按 Spearman–Brown 由两两相关推出，并用 200 次随机分半经验校验
（两者差 ≤ 0.001）。

> **预测共识 u₁ 的 R² 天花板 = 0.988，u₂ = 0.983。**
> 即：**u₂ 本身不是噪声**。它的 12 个独立估计互相关 0.83，
> 和 u₁ 的 0.87 几乎一样可靠。后面若 u₂ 的 R² 很低，那不是因为 u₂ 测不准。

这一条很重要，因为它排除了最省事的那个解释。u₂ 是一个被测得很准的位点性质，
**而结构描述子抓不到它**。

骨架混合的影响可忽略：只用 5 个 Wuhan-Hu-1 组合算的共识，与 12 组合共识
r(u₁) = 0.990、r(u₂) = 0.984（n = 182 位点）。

## 3. 结构侧：DMS 编号 → 6M0J 的映射，先过已知事实

6M0J = SARS-CoV-2 RBD（链 E）+ 人 ACE2（链 A），由
`curl https://files.rcsb.org/download/6M0J.pdb` 取得。
链 E 覆盖残基 333–526（194 个），DMS 有 201 个位点，映射是**恒等映射**。

**野生型身份命中率（按骨架）**：

| 骨架 | 命中 | 率 |
|---|---|---|
| **Wuhan-Hu-1** | **194/194** | **100.00%** |
| Eta | 193/194 | 99.48%（E484K） |
| Omicron_BA2 | 178/194 | 91.75%（15 个 RBD 取代） |

第一版自检报 91.75% 并中止——**但映射是对的，错的是比较对象**：
`wildtype` 列按骨架不同（BA.2 带 S371F/S373P/S375F/T376A/D405N/R408S/
K417N/N440K/S477N/T478K/E484A/Q493R/Q498R/N501Y/Y505H），
把三个骨架混在一起取 wildtype 就会比到 BA.2 的序列上。
6M0J 链 E 是 Wuhan-Hu-1 序列，故参考骨架取 Wuhan-Hu-1，命中 100%。
（又一次「工具的错 vs 对象的错」，CLAUDE.md §10 末条。）

### 又抓到一次约定错：二面角符号

phi/psi 的第一版实现给出 phi 中位 **+89.5°**、只有 6% 为负——
而真实蛋白的 phi 绝大多数为负。换成标准式后 phi 中位 **−89.5°**、94% 为负，
且 |omega| 中位 176.8°（反式肽键）。两条都是已知事实，现在都是硬断言。
这是 D-005 同类的约定错，且在 sin(phi) 这类特征上会真的改变数值。

### 场与梯度的自检（解析解）

单点电荷有解析解 `|E| = q/r²`、`‖∇E‖_F = q√6/r³`。实测：

| r | \|E\|² 实测 / 解析 | ‖∇E‖² 实测 / 解析 |
|---|---|---|
| 3.0 Å | 0.0123457 / 0.0123457 | 0.00823045 / 0.00823045 |
| 6.0 Å | 0.000771605 / 0.000771605 | 0.000128601 / 0.000128601 |

幂次检验（r 加倍）：|E|² 降 16.000 倍、‖∇E‖² 降 64.000 倍（应为 16 / 64）。
两电荷下有限差分的 ∇E 与解析张量一致到 1e−4 相对误差。
**这同时测「能命中」与「不误伤」**：幂次写错会被这两条抓住。

各向异性的还原性自检（已知形状）：板状点云 flatness = 0.997、
球状 0.015 / elongation 0.034、棒状 elongation 0.990。

埋藏度方向的自检第一版断言「远离界面的位点更埋藏」，**断言本身是错的**
（D-017 同类）：`burial8` 把伙伴链原子也算进去，界面位点理应更「埋」
（实测 88 vs 69）。换成两条真正的已知事实：
(a) 三对二硫键 336–361 / 379–432 / 391–525（RBD 已知结构）的**自身链**
埋藏度中位 83 > 全体中位 69 ✓；(b) `n_partner8 > 0` 的位点 d_partner ≤ 7.71 Å、
其余 ≥ 8.14 Å ✓。

## 4. 预测结果

**纪律**：留出的是**位点**不是观测；主报「空间分组 10 折 CV」
（相邻位点共享环境，LOSO 会乐观）；每个 R² 带 2000 次按位点重抽的
bootstrap 区间；描述子**按类分开**（量级类 / 各向异性类），不混进一个模型，
否则「场 vs 梯度」「大小 vs 各向异性」的判别力就没了。
176 个位点进入回归（载荷 182 ∩ 结构 194，再去掉 1 个 phi/psi 缺失）。

## 5. 预注册预测的逐条判定（docs/16 §3）

| 预测 | 内容 | 判定 |
|---|---|---|
| **P1** | u₂ 与 ‖∇E‖² 相关、与 \|E\| 不相关 | **否**。r(u₂, ‖∇E‖²) = −0.016 [−0.132, +0.106]（模型 D）、−0.031（模型 F），两个电荷模型都覆盖零；样本外 R² ≤ 0。判据要求「区间不与 WCN 基线重叠」，而实际是两者都等于零预测器。对照项 \|E\|² 如预期覆盖零——**但那不构成支持，因为主项也覆盖零**。 |
| **P2** | u₂ 与自由体积**各向异性**相关、与**大小**不相关 | **否（按所写的描述子）**。flatness −0.038、elongation +0.135、sphericity −0.069、n_lobes +0.070，全部覆盖零；R² 为负。P2 的后半句（与大小不相关）成立：free_frac r = +0.027。 |
| **P3** | u₁ 与 u₂ 跨位点近似不相关 | **是**。r(u₁,u₂) = **+0.059** [−0.125, +0.238]，覆盖零。规范固定通过了它自己的诊断。 |
| P4（残基侧 ‖Q‖²） | 本轮未做（需要侧链部分电荷表） | 未测。但 §1 的残基侧事实已经对 §2.3 的论证链不利：成分 2 是**芳香专属**（FYWH r=−0.872）而非 sp² 通用（DENQ r=−0.072），Asp/Glu 的 v₂ 实测 ≈ 0。 |
| **P5** | 若 P1、P2 都不成立 → 记为「存在但未归因」并停止搜函数 | **触发**。见 §6。 |

按 docs/16 §3 自己写下的条件：**「如果只有 P2 成立，§2.3 要撤回」**。

## 6. 量级校准：这个代理量到底值多少 kcal/mol（CLAUDE.md §8）

在参考体系（176 位点、3488 观测）上，把 û₁、û₂（**嵌套 CV 的样本外预测**，
即只用 6M0J 结构算出来的那两个标量）代回秩 2 形式，
对比耦合残差的 RMSE：

| 预测器 | 耦合 RMSE | 相对零预测器 |
|---|---|---|
| 零预测器（耦合本身的 SD） | **0.918 kcal/mol** | 0.0% |
| oracle 秩 2（u 由数据拟合） | 0.682 kcal/mol | 25.8% |
| oracle 仅成分 1 | 0.786 kcal/mol | 14.4% |
| **结构-only 秩 2（û₁,û₂ 全由 6M0J 算）** | **0.857 kcal/mol** | **6.7%** |
| 结构-only 仅成分 1 | 0.872 kcal/mol | 5.1% |

量级自洽：耦合 SD 0.918 kcal/mol 与 docs/09 的 1.01（后修正为 1.13）
在同一量级上，差异来自数据集不同（这里是 DMS 的 log10 Ka 换算，
docs/09 是 SKEMPI 系列的 ΔΔG）。实验噪声参照 0.3–0.4 kcal/mol
（`evidence/assay-noise.md`），所以耦合仍然是真结构。

**结论的量级版本**：闭式结构-only 秩 2 代理量把耦合 RMSE 从
0.918 降到 0.857 kcal/mol —— 真实、方向正确，但只有 **6.7%**，
是 oracle 秩 2（25.8%）的四分之一。加上成分 2 只带来
0.872 → 0.857（1.5 个百分点）。
用「排序形状相近口袋」的语言说：这不足以改变 docs/09 §5 的判决。

## 7. 判决

**u₁（去溶剂化/空腔通道）：结构-only 可微代理量成立，但只到四成。**
样本外 R² = 0.408 [0.281, 0.506]，天花板 0.988，区间不重叠地优于
WCN（0.010）与埋藏度（0.106）。有效的量是**近端自由体积与侧链半球自由体积**
（shell1、free_frac_hemi），不是裸埋藏度，也不是 WCN。
这三个量都是球面采样的平滑函数，可微性没问题（CLAUDE.md §7：
这一步是**推进前沿**，不是在前沿上移动——它既更光滑又更准）。

**u₂（芳香/平面通道）：不可预测，记为「存在但未归因」。**
- u₂ 本身很可靠（重复相关 0.826，共识可靠度 0.983），**不是噪声**；
- 两个预注册的物理解释（四极 ‖∇E‖²、堆积各向异性）**都给出零**；
- WCN、埋藏度、自由体积大小、lobe 数、主链二面角也都给出零；
- 唯一非零的是搜索出来的 rotamer 芳香容纳量（R² 0.17，占天花板 17%，
  区间下界 +0.014）。

> **这是对「结构-only 代理量」的一条内在限制，而不是描述子没找够。**
> 秩 2 形式里口袋只通过两个标量进入；其中一个（u₁）可以算到 41%，
> 另一个（u₂）在 27 个描述子、3303 个组合的搜索下只到 17%，
> 且与两个独立导出的物理预测都不符。

按 CLAUDE.md §6 与 docs/16 的 P5：**停止搜函数**。
下一步不是再加描述子，而是切分判别集（已记入 `state/decisions.md`）。

### 这个结论不说什么

- 不说成分 2 没有物理来源。它的残基侧极其干净（芳香 r = −0.872）；
  是**位点侧**抓不到。
- 不说四极通道不存在。只说：在本文的电荷模型（形式电荷、中性偶极基团）
  与 6M0J 这一个静态结构下，‖∇E‖² 与 u₂ 无关。
  晶体结构是**结合态**的单一构象，没有突变体结构，也没有取向松弛——
  docs/16 §4 自己标出的风险（「取向是否真的近自由，在埋藏位点上可疑」）
  正落在这里。
- 不说别的体系也如此。只测了 SARS-CoV-2 RBD × 5 个 ACE2 正交体 × 3 个骨架。
- u₂ 的位点侧还有一个本文无法排除的可能：它依赖**突变后**的局部重排，
  而任何只读野生型复合物结构的描述子按构造都抓不到那个。
