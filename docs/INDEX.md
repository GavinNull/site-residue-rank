# 文档索引：哪些结论还成立，哪些被谁取代

**写于 2026-10-23。** 本仓库的文档是按时间顺序写下的**当时相信什么**的记录，主张在十几轮自我检验中被反复收紧。
**历史文档不被改写**（改掉它们会毁掉审计链），所以一个读者随手点开 docs/12 或 docs/13，
会读到后来已被撤回的数字和结论。这份索引的作用就是防止这件事：每份文档标明它现在的状态，
以及被谁取代。判定的依据是 `state/decisions.md` 里每条决策记录的「取代了什么」。

**当前唯一权威的表述是 [`48-paper-v2.md`](48-paper-v2.md)**（主论文），配套方法学稿是 [`32-methods-paper.md`](32-methods-paper.md)。

## 状态说明

| 标记 | 含义 |
|---|---|
| ✅ 当前 | 其结论在当前叙事里仍成立 |
| 🟡 数据/方法仍有效，结论句被取代 | 其中的**测量与程序**仍可用，但它写下的**判断**后来被推翻或收紧；读它须配合「取代者」 |

## 五、几条读这个仓库的人应当知道的事

1. **越晚的文档越可信，但不是单调的。** docs/44 取代了 docs/41 里的数字，docs/47 取代了 docs/26–27 里的读法；
   遇到冲突，以**决策日志里的取代关系**为准，不要以文档编号为准。
2. **「撤回」不等于「错了」。** 有些被撤回的是数字（−5.54%），有些是论断（恰好秩 2），
   还有些是**读法**（0.755 是「结合与折叠共用」还是「读出携带稳定性」）——数据没变，解读变了。
3. **预注册层的判决才是结论。** docs/46–47 的事后修订层（A1/A2/A3）是在看到前一道闸的结果之后写的，
   虽然都哈希锁定并标注了事后，**不被采纳**（D-096）。
4. **历史文档里的撤回数字是正当存在的**：执行撤回的文档必须引用它们才能论证为什么撤回。
   机械检查只扫前向主张文档，不扫历史文档，正是这个原因。
