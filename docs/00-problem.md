# 问题定义

## 要找的东西

标量 `S(P, L)`，P 为结合口袋，L 为配体，满足三条：

1. **判别力**：对「骨架与形状高度相似、差异集中在第一壳层残基身份」的口袋对，
   `sign(S_A - S_B) = sign(ΔG_A - ΔG_B)`
2. **精度要求低**：不要求数值接近 ΔG，只要求排序正确
3. **数学性质**：对原子坐标与部分电荷可微；计算成本远低于自由能计算

第 3 条里的「可微」是硬约束，它意味着 S 要被放进某个基于梯度的循环：
作为 loss 项训练/微调结构或生成模型，或直接对结构/序列做梯度优化
（口袋设计、定点突变打分）。FEP 不可微也不便宜，docking 不可微，所以才需要代理。

## 为什么现有的不够

形状互补、buried SASA、口袋指纹、粗粒度力场，对「形状相近、核心残基不同」
这类差异不敏感。真正的差别在几个关键残基的**具体相互作用性质**上：
氢键几何与方向性、电荷辅助氢键、阳离子-π、卤键、去溶剂化代价、残基极化率。
这些是物理有机化学的内容。

## 这件事对 AI 困难在哪（设计防护时的依据）

### 1. 奖励信号脏，而 agent 对脏信号没有免疫力
判别集只有几十到几百对，排序指标波动本身就有零点几量级。跑一百个候选
一定能找到几个看起来很好的——这不是作弊，是统计必然。危险在于 agent
不会自发意识到"提升小于噪声"，而会很自然地给出一段合理的物理解释来配合
那个数字。**生成解释是它最强的能力，在这里恰恰最危险。**
→ 防护：`CLAUDE.md §5` bootstrap 强制、`§6` 停止优化的触发条件、
`docs/03-validation.md` 标签置换对照。

### 2. 这个任务可能部分无解，而判断"无解"是 agent 最弱的能力
形状相近、残基不同的两个口袋，亲和力差异很大一部分不在焓，而在去溶剂化
代价和构象/水网络的熵。残基身份改变最直接的后果往往是改变口袋结构水的
位置与数量，一个水分子进出常值 1–2 kcal/mol，足以翻转排序。
而**所有便宜且可微的量描述的几乎都是焓和静电**。
→ 真实失败模式：做到 0.5 相关，剩下的被熵占住，再搜函数也上不去。
人类做到一半会开始怀疑，然后按"水网络是否变化"把判别集切一刀。
agent 的默认行为是继续优化当前指标。
→ 防护：`pairs/*.yaml` 的 `water` 必填字段、`CLAUDE.md §6`。

### 3. 量级直觉的缺失
LLM 知道阳离子-π 存在、知道物理起源、能写公式，但不知道在某个具体芳香笼里
它值 0.3 还是 3 kcal/mol，也不知道它和去溶剂化代价谁更大。
物理有机化学家的核心能力恰恰是这张校准过的量级表。
agent 生成的候选在"物理上说得通"层面全部合格，在"量级上重要"层面大部分
是垃圾，而它自己分不出来。
→ 防护：探针 `manifest.tsv` 的 `reference_magnitude`，用确定性引擎
给 agent 外挂一张量级表（`CLAUDE.md §8`）。
`docs/04-blind-protocol.md` 的 `magnitude_bin` 直接测量这个能力。

### 4. 可微性与判别力在物理上对立
真正区分两个口袋的事件常常是离散的：质子转移发生与否、侧链是否翻转、
一个水分子进还是出。这些是**开关**，不是连续函数。要求可微等于要求代理量
在开关附近光滑，而光滑化的代价就是抹掉判别力。
这不是工程难题，是任务内在的帕累托前沿。agent 会在两边反复横跳——
交替提出"更可微但更钝"与"更敏感但不可微"的候选，而没意识到自己
在前沿上来回走。识别"我在做取舍而不是在进步"需要跳出当前循环看全局。
→ 防护：`CLAUDE.md §7`。

### 5. 验证成本与生成成本严重不对称
提一个候选几分钟，认真验一个要几天（三级验证 + 分层 + bootstrap）。
agent 的优势是并行生成，而瓶颈在串行验证。
→ 具体病症：最后不是缺想法，是积压两百个未验证的想法，
然后开始用某种**本身未被验证过的**廉价预筛选去排序它们。
→ 防护：探针库（第 1 级）做成快筛，淘汰率高且判据干净；
`CLAUDE.md §5` 要求记录搜索了多少候选。

## 结论性判断

agent 能提供压倒性价值的环节是**建判别集 + 失败归因 + 盲预测**——
大规模判断任务，有确定性事实依据，错了能被查出来。
模块提出环节，agent 是高产但品味不稳的 brainstorm 伙伴；
决定哪三个值得花几天去验，这个动作短期内是人类决策点。
