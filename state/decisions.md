## D-001  重心压在判别层，不在生成层  [2026-10-03] [who: agent]
理由：候选代理量不缺（物理有机能写出几十个，加文献打分函数更多），
缺的是能判生死的判别集。生成完之后无法分辨真信号与小样本上的运气。
影响：系统的大部分代码是验证与统计，不是搜索。
推翻条件：若基线墙显示现有方法在判别集上已经很好，说明问题不在判别力
而在别处，重心要移。

## D-002  标签隔离做成机制，不靠自律  [2026-10-03] [who: agent]
理由：LLM 对任何给定排序都能编出专业且真实的物理解释——给 A>B 讲盐桥，
给 B>A 讲去溶剂化，两套都对，只是权重随结论调整。这种污染读起来和干净
论证完全一样，**且没有任何事后检验能查出来**（数值过拟合可用置换对照查，
论证污染不可查）。所以必须前置拦住。
影响：base64 存储 + labelstore 唯一入口 + SHA256 锁 + 泄露正则扫描。
推翻条件：无。这条是地基。

## D-003  尺度定在片段，全程不碰完整蛋白  [2026-10-03] [who: agent]
理由：(a) 要的量本来就是局域的；(b) 全蛋白 + 显式水 + 采样立刻把算力需求
推上去；(c) **这是一个额外检验**——若声称差异来自核心残基，就应该能在
核心残基尺度上算出来；若必须全蛋白才能复现差异，假设本身就错了。
影响：配体 + 第一壳层，侧链截到 Cβ/Cγ，加氢封端，冻骨架。几十到一两百原子。
推翻条件：若"无结构水变化"组的表现也上不去，需要重新考虑尺度。

## D-004  F00 (mixed) 保留为合法预测选项  [2026-10-03] [who: agent]
理由：它是测量"预测者是否知道自己不知道"的唯一手段。若 F00 组准确率
明显低于其他组，校准是真的；若和高置信组差不多，说明 F00 只是在偷懒，
整套因子归因要打折。
影响：F00 单独报告，不计入"可用因子"计数。
推翻条件：无。

## D-006  探针库优先于判别集建设  [2026-10-03] [who: agent]
理由：探针库是快变量（不依赖判别集，建成后每个候选过一遍几分钟），
判别集是慢变量。先让快的转起来。而且探针库建成后是可复用资产，

推翻条件：若探针签名在 xtb 下大面积不可判，说明探针设计有问题，
要回去重新设计而不是继续建新探针。

## D-012  C6 的规模要求改为参数计数导出，原规格少一到两个数量级  [2026-10-03] [who: agent]
理由：M5.4。原 C6「5×8、填充 40%」= 16 个观测，而秩 2 需要 34 个参数。
观测数少于参数数，无论估计器多好都定不出秩。
参数计数门槛比 BBP 可分辨性门槛紧 3–10 倍，是绑定约束。
合成模拟独立确认（20×20 填充 0.8 = 320 观测 → 秩 2 定对率 0.82，
门槛 387 刚好不够；秩 3 定对率 0.12，门槛 672 远不够）。
影响：判定 r=1 vs r>=2 需约 390 测点；分辨 r=2 vs 3 需约 670。
推翻条件：若实际 λ 谱比假设的陡（λ_2 远大于 λ_3），分辨 2 vs 3 可能更易。
但参数计数门槛不依赖 λ，故 390 这个数是稳健的。

## D-013  M5 的首要问题改为二元：r=1 还是 r>=2  [2026-10-03] [who: agent]
理由：D-012。秩 3 vs 2 需约 670 测点，从文献凑出来很可能不现实；
而二元问题恰好也是科学上更决定性的——r=1 意味着存在 Hammett 型
单参数律，代理量几乎直接写出来；r>=2 意味着必须有门控或多项结构。
影响：M5 的通过判据从「测出 r」改为「以足够置信度排除 r=1」。
推翻条件：若拿到 panel 型数据后测点数远超 670，可以回到原问题。

## D-014  估计器失败与现象无结构必须分开诊断  [2026-10-03] [who: agent]
理由：首轮 rank_power 显示秩 3 在任何规模下定对率 < 0.2，
看起来像「低秩结构不存在」。但无噪声完备矩阵诊断显示 ALS 精确还原秩 1/2/3,
故失败在定秩的选择程序与容量，不在信息量。
这与 D-005（验证器误报 vs 被验证对象有错）是同一类错误。
影响：任何「测不出结构」的结论，必须先过一次理想条件下的还原性诊断。
推翻条件：无。

## D-015  C6 判据改为无量纲比 rho >= 2.8；定秩必须 K 折 + 重启  [2026-10-03] [who: agent]
理由：K 折 + 重启的模拟显示控制变量是 rho = 观测数/参数数，不是绝对测点数。
rho >= 2.8 时 r=2 定对率 1.00；rho ~ 2.1-2.5 时只有 0.44-0.64。
同时单次留出严重欠功效（同 320 观测：单split 0.82 vs K折 1.00），
用错方法会把容量够的情形误判为「无低秩结构」。
影响：D-012 的「390 测点」修正为「rho >= 2.8，约 320 测点」；
rho 判据不依赖 lambda 与 sigma，故这一条是稳健的。
r=3 的要求同时含 BBP 余量，依赖 lambda_3/sigma，稳健性差得多
—— 这是把 M5 首要问题设为二元（D-013）的又一个理由。
推翻条件：若真实数据的主效应结构与合成模型差别很大（例如主效应近零），
rho 的标定值需重测。

## D-017  自测必须同时防「对检查器能力的过度宣称」  [2026-10-03] [who: agent]
理由：limit_checks 的自测抓到三类问题，第三类是
「一个植入的错误其实不是错误」——cos^2 角因子在扫描区间 [90,180] 内
行为正确，缺陷在 theta=0 而那不在物理范围内。
若不发现这点，会以为断言表能分辨 cos^2 与 cos^3，而它既不能也不需要。
影响：自测的三条判据固定为：参考实现全过、植入错误被抓、
正确项不被误伤；且植入的错误必须在**被扫描的物理区间内**真的错。
推翻条件：无。这是 D-007 的延伸。

## D-020  损失用逐对 σ，键在数据来源上，不在亲和力上  [2026-10-03] [who: agent]
理由：Kalliokoski 2013（n=16,844，已核原文）正面检验过异方差性，
结论是误差不依赖亲和力大小，也不依赖所测的任何配体性质。
但同实验室 0.23-0.41 vs 跨实验室 0.74-0.93 差 3-4 倍。
影响：`pairs/*.yaml` 新增必填 `provenance.same_source`。
不做「σ 随 ΔG 单调变化」的参数化——没有文献支持。
推翻条件：若发现本项目的数据在边界（接近检测限）聚集，再加一个边界项。

## D-021  不采用 AAindex 的 sigma_I；电子轴用 RCOOH pKa  [2026-10-03] [who: agent]
理由：M4-T1。`FAUJ880108`（流传最广的侧链 sigma_I）谱系上是小分子取代基表的
移植值，无任何侧链独立测量支撑。而 `FAUJ880113`（R-COOH 滴定 pKa）是
Hammett 原型意义上的真实测量，且本地实测显示它与其余实验标度近乎正交
（|r| <= 0.27），携带真正独立的信息。
影响：电子轴有了干净来源。代价是 Pro 缺值。
推翻条件：若取得 Charton 1981/1982 原文并确认移植有独立依据，可重新考虑。

## D-022  Pro 排除出判别集  [2026-10-03] [who: agent]

## D-024  位点载荷规范固定的做法与可比性阈值  [2026-10-11] [who: agent]
理由：秩 2 分解只在共享可逆 2x2 变换下唯一，u1/u2 在固定规范前无单独含义。
采用：参考基 = Wuhan-Hu-1 x bind_human_monomer（最大、截尾最少，也正是 6M0J）；
V 列归一、尺度入 L；成分1 定向为与疏水性负相关、成分2 与平面 sp² 负相关；
其余组合在共同残基上最小二乘求 2x2 变换并对位点载荷施加其转置。
可比性阈值**事先声明**为相对残差 0.40（理想条件下该残差的底是 0.01–0.07，
已由自检给出）。15 个组合里 12 个可比，被剔除的 3 个正是奇异值最小的 3 个。
影响：任何跨体系比较位点载荷的分析都必须先走这一步并报残差。
推翻条件：若找到比最小二乘更合适的对齐（如带不确定度加权的 Procrustes），可替换，
但必须重报残差与被剔除的组合。

## D-026  OMTKY3 扩样本在数据上做不到，且加 k 也买不到分辨率  [2026-10-11] [who: agent]
理由：docs/20。完整未过滤的 `cache/skempi_v2.csv` 穷尽普查（7085 行、
5059 单点突变、按被突变链归骨架）显示 OMTKY3 只有 **4 个**蛋白酶伙伴，
与 `skempi_thr4.csv` 保留的完全相同 —— thr4 的 ≥4 取代/位点过滤**没有**
丢掉任何伙伴。名字串命中的另外 16 个 PDB 代码全是 SGPB×OMTKY3 的不同晶体
结构（各 1 行），不新增伙伴。k ≥ 4 的骨架在整个 SKEMPI v2 里只有 OMTKY3。
更重要的是 PR 功效诊断（`analysis/omtky3_pr_power.py`）：80% 功效所需的
第二轴共享度 mean|cos| 从 k=4 的 0.64 只降到 k=10 的 0.48、k=14 的 0.46。
采用：Q-005「把 k 提到 8–10 会让 PR 检验功效显著上升」**这个前提不成立**，

是 PR 统计量本身在共享度 0.3–0.5 这一段钝。
影响：不再把「找更多蛋白酶」当作 docs/13 §6.3 的升级路径。能动的是换统计量
或切分判别集，两者都是 §9 的人类决策点，不自行决定。本次**一个参数都没动**
（可分辨性门 0.60、截尾窗口 0.25、PR 零分布口径全部原样）。
