## D-001  重心压在判别层，不在生成层  [2026-10-03] [who: agent]
理由：候选代理量不缺（物理有机能写出几十个，加文献打分函数更多），
缺的是能判生死的判别集。生成完之后无法分辨真信号与小样本上的运气。
影响：系统的大部分代码是验证与统计，不是搜索。
推翻条件：若基线墙显示现有方法在判别集上已经很好，说明问题不在判别力
而在别处，重心要移。

## D-002  标签隔离做成机制，不靠自律  [2026-10-03] [who: agent]
理由：LLM 对任何给定排序都能编出专业且真实的物理解释——给 A>B 讲盐桥，
给 B>A 讲去溶剂化，两套都对，只是权重随结论调整。这种污染读起来和干净
论证完全一样，**且没有任何事后检验能查出来**（数值过拟合可用置换对照查，
论证污染不可查）。所以必须前置拦住。
影响：base64 存储 + labelstore 唯一入口 + SHA256 锁 + 泄露正则扫描。
推翻条件：无。这条是地基。

## D-003  尺度定在片段，全程不碰完整蛋白  [2026-10-03] [who: agent]
理由：(a) 要的量本来就是局域的；(b) 全蛋白 + 显式水 + 采样立刻把算力需求
推上去；(c) **这是一个额外检验**——若声称差异来自核心残基，就应该能在
核心残基尺度上算出来；若必须全蛋白才能复现差异，假设本身就错了。
影响：配体 + 第一壳层，侧链截到 Cβ/Cγ，加氢封端，冻骨架。几十到一两百原子。
推翻条件：若"无结构水变化"组的表现也上不去，需要重新考虑尺度。

## D-004  F00 (mixed) 保留为合法预测选项  [2026-10-03] [who: agent]
理由：它是测量"预测者是否知道自己不知道"的唯一手段。若 F00 组准确率
明显低于其他组，校准是真的；若和高置信组差不多，说明 F00 只是在偷懒，
整套因子归因要打折。
影响：F00 单独报告，不计入"可用因子"计数。
推翻条件：无。

## D-005  探针几何自检前置于任何电子结构计算  [2026-10-03] [who: agent]
理由：首次运行命中 36/60，包含三类真实几何错误（见 JOURNAL 2026-10-03）。
坏构型会让 xtb 悄悄收敛到无意义结构，而扫描曲线看起来仍然平滑。
影响：`analysis/check_probes.py` 是 G0 的第一步，不是可选项。
推翻条件：无。

## D-006  探针库优先于判别集建设  [2026-10-03] [who: agent]
理由：探针库是快变量（不依赖判别集，建成后每个候选过一遍几分钟），
判别集是慢变量。先让快的转起来。而且探针库建成后是可复用资产，
比判别集稳定。
影响：G0 与 G1 并行，G0 先动。
推翻条件：若探针签名在 xtb 下大面积不可判，说明探针设计有问题，
要回去重新设计而不是继续建新探针。

## D-007  护栏必须自测，且测"不误伤"与测"能命中"同等重要  [2026-10-03] [who: agent]
理由：泄露扫描若误伤骨架 RMSD、口袋体积、接触距离这类合法结构事实，
会迫使人把它们从 `pairs/` 里删掉，反而削弱判别集。
一个过度敏感的护栏最终会被绕过或关掉。
影响：改动 `check_repo.py` 的正则后必须重跑含合法数值的对抗样例。
推翻条件：无。

## D-009  G1 规格从「100 个散对」改为「有意安排的不完整矩阵」  [2026-10-03] [who: agent]
理由：M1.2 的不可识别性——若所有对共享同一配体，ψ_k(L) 为常数，
则 a(P) 与耦合项数学上不可分辨，收多少散对都无法确定耦合结构。
秩只在矩阵结构里可见。
影响：新增判据 C6（矩阵覆盖）；家族选择的标准从「数据好」变为
「有矩阵结构」；散对降级为 `subset: scatter`，可用于 G2/G3 不进 M5。
推翻条件：若最终形式被证明秩为 0（纯可加），矩阵结构就不必要了。
但 M1.1 的目标正是先排除这种情况。

## D-010  排序损失的温度不调参，等于 √2·σ_exp  [2026-10-03] [who: agent]
理由：M2.3。实验误差宽度已知时，probit 链接是正确的似然，
不是机器学习的方便选择。顺带把「剔除 |ΔΔG| < 0.5 的对」的硬截断
变成软权重（该对似然贡献自然趋近 0.5）。
影响：σ_exp 必须有文献来源（任务 M2-T1），不能拍。
推翻条件：若某 assay 的误差分布明显非高斯，probit 形式要改。

## D-011  适用域判据改为理论量，water 字段降为独立核对  [2026-10-03] [who: agent]
理由：M3.3 给出 β·Var/2 ≪ |⟨ΔH⟩| 作为线性响应成立的条件，
这是推导出来的，而原计划的 `water` 分层是人工标注。
影响：两者互为验证——若理论判据标记的失效集与 `water: changed`
高度重合，互相确认；若不重合，其中一个是错的，这本身是结果。
推翻条件：若 Var 本身需要采样才能估（见 Q-002），
这条的「便宜」前提不成立，要退回人工分层。
