# Gate 状态

状态值：`not_started` | `in_progress` | `passed` | `failed` | `blocked`

| Gate | 内容 | 状态 | 通过判据 |
|---|---|---|---|
| G0 | 探针库 + 数值稳定性流程 | `not_started` | 4 个探针可跑，xtb 接口通过 `tools/*.validation.md` |
| G1 | 判别集前 100 对 | `not_started` | 100 对 `status: ready`，泄露扫描 0 命中 |
| G2 | 基线墙 + 失败分类表 | `not_started` | ≥3 个基线跑完，带区间；失败案例按差异类型分类 |
| G3 | **盲预测 gate** | `not_started` | 见 `docs/04-blind-protocol.md` 三条预注册门槛 |
| G4 | 存活因子 → 可微量 | `blocked` | 依赖 G3 |
| G5 | 0–3 级验证 + 三组对照 | `blocked` | 依赖 G4 |
| G6 | holdout 单次开封 | `blocked` | 人类决策点 |

## 当前阻塞

**G0 与 G1 可并行。** G0 是快变量（不依赖判别集，建成后每个候选过一遍只要几分钟），
G1 是慢变量。**先让快的转起来。**

G0 的实际阻塞点：xtb 是否已安装。检查：
```bash
which xtb || echo "未安装"
```

G1 的实际阻塞点：**数据来源需要人类决定**。见下。

## 需要人类输入的事项（agent 不自行决定）

### [待定] 1. 判别集的数据来源优先级
`docs/02-pair-criteria.md` 列了四类来源。工作量与可靠性递增：
- SKEMPI 2.0 / PDBbind 突变子集：批量，但多为蛋白-蛋白界面，需筛小配体
- BindingDB 同配体多靶点：量大，但 assay 异质，C3 难满足
- 激酶选择性谱：天然满足"形状像残基不像"，但多为 IC50（C3 排除 IC50）
- 原始文献定点突变表：最可靠，需逐篇读

建议：主集走原始文献，先锁定 1–2 个家族以控制读文献的范围。
**需要你定：哪个家族。** 这决定了后续所有工作的边界。

### [待定] 2. 结构来源统一方案（C4）
三选一，不可混：
- (a) 全部用晶体复合物 —— 最真，但有结构质量与亲和力相关的伪影风险
- (b) 全部统一 docking —— 消除伪影，但引入 docking 误差
- (c) 一侧晶体做模板，另一侧同源建模 —— **C4 明确禁止**

建议 (b) 作主集，(a) 作为对照子集并行建，两者表现对比本身就是一个结果。

### [待定] 3. 可微内层技术路线
- 解析梯度（半经验量自带）：零训练成本，优先
- 神经近似拟合 xtb 量：更快，但需生成几万片段构型并训练

建议先走解析梯度，只在速度确实不够时再训网络。
