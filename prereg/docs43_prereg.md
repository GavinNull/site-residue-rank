我读过现有代码后的核对（不是假设）：docs/41 的 `independence_audit.recovery()` **确实**对 S1 的 15 个矩阵植入过秩 1、

已知的数（来自缓存，不是本次新测）：Eta/deer 的 CV trim95 曲线约 2.81 / 2.63 / 2.48 / 2.61（秩 0–3），

## 2. 噪声与信噪比：定义与估计方法（先于数）

### 2.1 s、σ、cso 的定义（与 docs/42 §3 同口径）
- **s**：双向中心化后的交互项在**观测格子**上的元素级 RMS。
- **σ**：各向同性噪声 SD（格子层面；本数据里每格 = 两次重复的均值，见 §2.2）。
- **cso**：真实矩阵 `rank_core.residual(M, mask)[mask].std()`（观测格子上的双向中心化残差 SD）。
- 合成矩阵的 cso² 满足 `cso² = a·s² + b·σ²`；a、b 对**每个矩阵、每种载荷模式**用 8 次独立抽样数值测定（§4.2 自检其线性）。
  **禁止** 用 `sqrt(coup_obs² − σ²)` 反推真实耦合强度（D-042/D-055）。这里是**正向**匹配：先固定 σ 再解 s，
  使合成 cso = 真实 cso；若 `cso² − b·σ² ≤ 0` 则该 σ 不相容，路径在此截断并记录。
- **不使用** bootstrap SE 作噪声模型（D-028）。

### 2.2 测量噪声 σ_meas（有重复列的矩阵）
已验证的事实（预先登记前已核对）：animalACE2、PDCoV 文件里 `bind_X` = `X_rep1` 与 `X_rep2` 的均值（最大偏差 1e-5）；
只有一个重复的格子 `bind_X` 等于该重复；CR9114 的 `minus_delta_log_Kd` 同样是两重复均值（中位偏差 5.6e-4）。所以：
- 两个重复独立（不同文库/不同测定批）时，`d = rep1 − rep2` 的 SD = √2 · σ_单重复。
- **格子噪声（两重复均值）= SD(d)/2**；只有一个重复的格子 = SD(d)/√2。
- `σ_meas² = σ_单²·(f2/2 + f1)`，f2、f1 为该矩阵观测格子中两重复/一重复格子的比例，σ_单 = SD(d)/√2（d 取该矩阵观测格子里的两重复格子，**标准 SD**）。
- 稳健版（只报告，不进判决）：σ_单 = 1.4826·MAD(d)/√2。
- 注：docs/12 §2、`censor_recheck.attach_snr` 的 `rep_noise` 是**单重复**噪声；用在每格都是两重复均值的矩阵上，**高估格子噪声 √2**，使其「信噪比」偏低 √2。本次改正。
- **σ_meas 是下界**：只含两次重复之间不一致的部分；两次重复共享的系统误差（同一突变背景、同一展示/分选批次的共同偏差）不在其中。

### 2.3 σ 的上端：σ_fit1 / σ_fit2
`σ_fitk` = 对真实矩阵做秩 k 拟合（`rank_core.fit_loadings(rank=k, restarts=4, seed=11)` 于全部观测格子，
先全矩阵双向中心化）后的样本内残差 SD，自由度校正：`sqrt(SSE / (n − dof))`，`dof = (nr+nc−1) + k(nr+nc−k)`
（与 `independence_audit._plant` 同式）。它是真实噪声的**上界**（残差里还含未被秩 k 表达的结构）。

### 2.4 无重复列的矩阵
- S1 human_monomer：σ 下端 = 同骨架 {deer, hamster, bat, cat} 四个矩阵 σ_meas 的中位数（迁移，**不是测量**），矩阵标 T。
- OMTKY3 pooled：σ 下端 = 0.35（文献同源锚点），标 L。
- 若某矩阵 σ 下端 ≥ σ_fit1（路径为空），该矩阵标「无法评估」并停（不硬推）。

### 2.5 σ 路径（核心设计）
真实噪声 σ_true 满足 `σ_meas ≤ σ_true ≤ σ_fitk`（下界：重复噪声是总噪声的一部分；上界：拟合残差含全部噪声）。
**数据不能在这个区间里挑点**（总方差可识别，信号/噪声的分配不可识别——D-042/D-055 的同一件事）。因此：
`σ_p, p=1..7` = 在 [σ_lo, σ_hi] 上等比取 7 点，σ_lo = σ_meas（或迁移/文献锚点），σ_hi = σ_fit1（秩 1 世界）或 σ_fit2（秩 2 世界）；
每点 s_p 由 §2.1 的正向匹配解出。**每个矩阵报告 s/σ 的两个端点值，并标其相对工作窗口 [2,3) 的位置**
（窗口取 docs/42 §3.1：[2,3) 内 P(检出2|真2)=0.91、P(检出2|真1)=0.09；≥3 为过冲区；<2 为欠功效区）。

## 4. 植入世界

### 4.1 世界的构成
`Y = r_i + c_j + I_ij + ε_ij`，仅在真实 mask 上观测。r、c = `center_fit(M, mask)`（真实主效应）；
`I` = 秩 k 交互，缩放到观测格子元素级 RMS = s；ε 见下；Y 截断到真实观测值域 [min, max]（模拟滴定/检测边界，报告被截断比例）。
- **载荷模式 real**（主）：k=1 取真实矩阵秩 1 拟合的 UVᵀ，k=2 取秩 2 拟合的 UVᵀ（真实位点集中度、真实谱）。
- **载荷模式 rand**（次）：位点/残基载荷为随机、双向中心化、正交的高斯方向，谱 k=1:(1)，k=2:(1, 0.5)（docs/42 §3）。
- **噪声 gauss**（主）：ε ~ N(0, σ²)。
- **噪声 wild**（次，只在路径端点 p=1，且仅有重复列的矩阵）：ε_ij = ±d_ij/2（d_ij 为该格子真实的重复差、符号随机翻转；
  一重复格子取同矩阵两重复差池中随机抽取的 ±d/√2）。保留真实的逐格异方差与重尾。
- 世界 k=0（结构缺失对照）：`Y = r + c + N(0, σ0²)`，`σ0 = cso/√b0`（b0 为 k=0 时 cso²/σ²，数值测定），即与真实总残差同量级的纯噪声。

### 4.2 世界的网格与重复数（R = 40）
| 世界 | 点 | 载荷 | 重复 |
|---|---|---|---|
| k=0 | σ0（1 点） | — | 40 |
| k=1（FR2 的主检验） | p=1..7 | real | 各 40 |
| k=1 | p=1,4,7 | rand | 各 40 |
| k=2 | p=1..7（σ_hi=σ_fit2） | real | 各 40 |
| k=2 | p=1,4,7 | rand | 各 40 |
| k=1, k=2 | p=1（wild 噪声） | real | 各 40 |

每个矩阵 ≈ 40×(1+7+3+7+3+2) = 920 次检出。每个重复独立抽噪声（real 载荷下交互固定；rand 载荷下载荷也重抽）。

### 4.3 工具自检（先于一切结论；任一不过即中止）
1. `rank_core.selfcheck()`（C1–C8，含 C6b 已知偏高偏差复现）；`subspace_selftest.py`、`censor_density_check.py`、`gate_harness_check.py`（`cache/gate_harness_check.json` `ok = true`）。
2. **复现性（已知事实，不是自洽）**：对 15 个 animalACE2 矩阵，本模块重算的 3 种子 trim95 曲线（秩 0–3）必须与 `cache/censor_recheck.json` 的 `trim_curves` 逐位一致（|Δ| < 1e-9）。
3. **重复噪声估计器**：(a) 合成已知 σ 的两重复（含一重复比例、重尾），恢复值与真值差 < 5%（正向），(b) 两重复完全相同 → σ=0；两重复独立同分布但均值不同 → 不受主效应影响（不误伤），(c) 对真实文件断言「bind = 重复均值」成立，(d) Eta/deer 的 σ_单 应与 `censor_recheck` 的 `rep_noise`（0.2817）在 5% 内（它们不同的是格子集合，不是公式）。
4. **正向匹配**：`cso² = a s² + b σ²` 的线性：在一个独立的 (s, σ) 上，预测 cso 与合成 cso 的相对差 < 4%。
5. **「已知 σ 的格子噪声」**：合成 mask 用真实 mask、噪声取 `wild`，合成「重复差」的 SD 与真实一致（重尾保真）。

## 7. 判决规则（Step 5；矩阵层 → 体系层）

对每个有 σ 下端的矩阵，在 k=1 / real / gauss 的 7 点路径上：
- `FR2_p` = P(检出≥2 | 真秩 1)；报 Wilson 95% 区间。
- `q_p` = 合成秩 0 CV trim95 / 真实秩 0 CV trim95（重复中位）。**相容点**：0.8 ≤ q_p ≤ 1.25（该世界复现了真实数据的 CV 误差量级，CLAUDE.md §8）。
- 同路径 k=2 报 `H_p` = P(检出=2 | 真秩 2)，k=0 报 P(检出=0)。

**矩阵判决**（互斥，按序判）：
1. **INFLATED**（头条在该矩阵上被抬高）：存在相容点 p 使 FR2_p ≥ 0.50 且 Wilson 下界 > 0.30。
2. **ROBUST**（对过冲稳健）：全部 7 点 FR2_p 的 Wilson 上界 ≤ 0.20（即 40 次里 ≤ 3 次）。
3. **CONDITIONAL**：所有**相容点**的 Wilson 上界 ≤ 0.20，但存在不相容点 FR2_p 的 Wilson 上界 > 0.20
   （意即：假如未被重复解释的残差方差是噪声，则无过冲；假如它是高信噪比下不可学的结构，过冲会出现——数据区分不了）。
4. **CANNOT_ASSESS**：其余（含路径截断/无相容点）。
迁移/文献锚点的矩阵（T、L）加后缀，如 `ROBUST(T)`；不计入体系层表决。

**体系层**：S1 取 12 个测量矩阵，某一类 ≥ 9/12 则 S1 = 该类，否则 MIXED（报分布）；S2、S5、S3 各 1 个矩阵，取其矩阵判决。
**主张层**：只有当 S1 与其余有测量 σ 的体系（S2、S5）都 ROBUST 时，才可写「已排除过冲」；
任何 INFLATED → 头条该体系降级；CONDITIONAL / CANNOT_ASSESS → 写成「在 [σ_meas, σ_fit] 的哪一段会/不会出现过冲」，不写「已排除」。
**关于「最关键的量」**：每个矩阵报告 FR2 在 p=1（σ_meas，最高 SNR）与 p=7（σ_fit1，最低 SNR）与最近相容点三个值。

## 8. 次要：数据内去除成分的消融（不进判决）
对每个有测量 σ 的矩阵：A1 = 真实数据去掉秩 2 拟合曲面的第二奇异成分；A2 = 去掉两个成分。
用 20 个 CV 切分种子（11..30）各做一次均值曲线检出（每个切分种子单独一条曲线，不再 3 种子平均）。只描述，不进判决，
理由：这是真实数据上的消融，不是已知真值的植入，不能区分「成分 2 是真交互」与「成分 2 是过冲产物」。

## 9. Step 6：校正（只在需要时；候选与判据先于任何真实矩阵的使用）

候选**恰好三个**，规格如下（不再增减；若我事后想试第四个，只能写 postmortem，不得进判决）：
- **K1 joint-offset**：每折在训练格子上联合拟合 `Y ≈ r_i + c_j + U Vᵀ`（ALS，r、c 作为不受岭惩罚的偏置列与因子一起交替更新；
  岭仅作用于 U、V，ridge=0.1；欠定行/列保护同 `als_guarded`）。不再单独先中心化。主效应因此不再「吸收」耦合。
- **K2 tolerance-rule**：取现行曲线，选满足 `t_r ≤ (1+δ)·min_r t_r` 的**最小** r，δ = 0.02（固定）。
- **K3 sequential-bootstrap**：r = 1,2,3 依次检验 H0「真秩 r−1」：以真实矩阵全矩阵秩 (r−1) 拟合曲面 + 位点内置换的拟合残差
  生成 B = 20 个代理，同一程序（**单种子 3**，K=5，同 CV 参数）算 `g_{r-1→r}`；观测 g > 20 个代理的最大值才接受 r；
  遇首个不接受即停，检出秩 = 最后接受的 r。（代理世界继承真实几何与程序，因而**包含**程序自己的过冲偏差。）

**在合成数据上先测**（植入网格 GC）：几何 G4，载荷 rand，k ∈ {0,1,2}，s/σ ∈ {1, 1.5, 2.5, 4, 6, 9}（σ = 该几何 σ_fit1），R = 30；
K3 因代价只在 {gAPN, OMTKY3 pooled} × s/σ ∈ {1.5, 2.5, 4, 9}、R = 16 上测。基线（现行程序）同网格并列报告。
**通过判据（按 s/σ 水平合并 4 个几何，K3 合并 2 个几何）：**
(a) P(检出≥2|k=1) ≤ 0.15 对**每个**s/σ 水平；(b) P(检出=2|k=2) ≥ 0.70 对 s/σ ∈ {2.5, 4, 6, 9}（K3：{2.5, 4, 9}）；(c) P(检出=0|k=0) ≥ 0.90 对每个水平。
**三条全过才算「恢复了正确的秩」。**

**应用规则**：仅当至少一个有测量 σ 的矩阵判决 ∈ {INFLATED, CONDITIONAL, CANNOT_ASSESS} **且**至少一个候选通过 GC 时，
才把**通过的候选**用于真实矩阵（用 §3 同一口径）重新定秩，并与现行程序的秩并列。未通过的候选不得用于真实数据。
