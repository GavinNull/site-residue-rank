## 3. 每个量怎么重算（固定）

### (a) RBD×ACE2 面板（B，15 个子集）
- 各矩阵的秩间增益 g_ab = (t_a − t_b)/t_a，t = 种子平均逐格误差的 trim95；a,b ∈ {(0,1), (1,2), (2,3), (0,2), (0,3)}。
  面板汇总 = 15 个矩阵增益的**中位数**（docs/41 口径）。「最优秩相对可加模型」g0* 定义为每次重抽内 max(g01, g02, g03) 的中位（含选择乐观，两臂相同）；g02 另列。
- 区间 (i)「位点重抽」= 位点联合重抽 2000 次，`independence_audit.site_boot_gains`，seed 41，百分位 95%。
- 区间 (ii)「骨架+配体+位点同时重抽」= 在 (i) 的每次重抽上再对 3 个骨架水平和 5 个配体水平有放回重抽（`np.random.default_rng(99)`，
  按 g12、g23、g02、g01、g03 的顺序消耗），取 15 个增益（重抽后）的中位。
- 每个子集自己的区间 = 单矩阵位点重抽 2000 次，seed = 1500 + crc32(name) % 1000（docs/41 T1 同法）。
  对每一腿计数：区间下界 > 0 的子集数 / 跨 0 / 上界 < 0。
- **老臂复现门槛**：现行程序臂必须逐位复现 docs/41 的面板区间 [g12 位点: +0.8%, +7.3%；联合 −1.6%, +9.4%；g23: −8.8%, −4.2% / −11.1%, −2.1%；g02: +7.8%, +15.9% / +3.1%, +19.1%]
  与「5 上 / 9 跨 / 1 下」（`cache/independence_audit.json`）。不复现则中止，K1 臂不得使用。
- 逐格口径与头条口径的点估计并列报告（docs/41 §8 已说明二者不混用）。

### (b) 34 个单元的检出秩与截尾分层
- 每单元：现行与 K1 的头条检出秩（及 S-mode、S-cell），Gen-3 截尾 g3 = `censor_density.censor_fraction_density(raw)`，**喂原始值（含下限堆积）**（D-029）；
  与 `cache/censor_gen3_final.json` 的 g3 逐单元核对（|Δ| < 1e-9），不符则以重算值为准并在文档记录。
- 分层：按检出秩 0/1/2/3 分组，报每组 n 与 g3 中位（附单元重抽 4000 次的 95% 区间，seed 20261017）；
  g3 对检出秩的 Spearman 与 Pearson（4000 次重抽，seed 20261017）；5 个截尾区间 × 检出秩交叉表（docs/41 T8 同法）；
  现行秩 → K1 秩的改判交叉表；「g3 < 10% 的 21 个组合里秩 2 的占比」。
  次要：秩 0 对秩 ≥ 1 两组的 g3 中位之差及单元重抽区间。
- 34 个单元全部属于 S1（同一实验室、同一平台、同一家族），不是 34 个独立观测；任何区间只含单元抽样。

### (c) Figure 1

### (d) 独立体系表（C）
- 每个矩阵：恢复性诊断（`independence_audit._plant` 同法：矩阵自己的 mask 与样本内拟合残差 σ，植入秩 2 / 1 / 0 各 8 次，种子 1000 + 17t + k，CV 种子 3），
  **用 K1**，max_rank=3。有功效 = P(检出=2|植入 2) ≥ 0.75 且 P(检出=0|植入 0) ≥ 0.75；另报 P(检出≥2|植入 1)。
  现行程序臂的功效取 docs/41 发表值（`cache/independence_audit.json`）。
- 体系层 = 有功效矩阵的增益中位数，位点联合重抽 2000 次，seed = 500 + 体系号（S1→501，S2→502，S3→503，S4→504）。
- 体系状态（各腿用该体系自己的区间，位点重抽）：
  `SUPPORTS_2OVER1` 若 g12 下界 > 0；`SUPPORTS_LE1` 若 g12 上界 < 0；否则 `INDETERMINATE_1v2`；无有功效矩阵 → `UNINFORMATIVE`（不外推旧值）。
  `INTERACTION` 若 g01 下界 > 0；`RANK3_WORSE` 若 g23 上界 < 0。
- **不报 p 值**：投票体系 n < 7 时（docs/41 W1 门槛）一律不报；只报最小可达 p（`independence_stats.min_attainable_p`）。

### (e) 内部极小
- 面板与每个体系：`interior_min_supported` = g12 下界 > 0 **且** g23 上界 < 0（docs/41 同定义）；另报弱形式「g23 上界 < 0」（秩 3 劣于最优者，不要求 2 优于 1）。
- 无功效的体系不报，写「无法判定」。

## 4. 措辞规则（先于结果；措辞由规则决定）

**R1「秩 2 优于秩 1」**（面板，K1）：
- g12 位点区间下界 > 0 **且**联合区间下界 > 0 → 可写「秩 2 优于秩 1」；
- 仅位点区间下界 > 0、联合区间含 0 → 只可写「仅在只重抽位点时」；不得把「最优秩是 2」写成主张；
- 位点区间含 0 → **不得**写「交互项是秩 2」「最优秩是 2」「秩 2 优于秩 1」，**不得**在摘要/标题/图题把秩 2 作为结论。
  可写：「交互存在（g01）」「秩 3 过拟合（g23）」「秩 1 与秩 2 在 K1 下不能区分」，
  以及**描述性**的「X/17 个矩阵的 argmin 是秩 2」，且必须同句说明这些 argmin 落在近乎平坦的曲线上、1→2 区间含 0。
  此时「恰好两个成分」不再被主张；「第二成分是否存在」不得用秩选择作证据。
- 上界 < 0 → 可写「秩 1 优于秩 2」。
**R1b 恢复性**：若 K1 对 S1 多数矩阵的 P(检出=2|植入 2) < 0.75，则「不能区分」可能是功效所限而非证据，文本必须这样写（CLAUDE.md §10.3）。
**R2「交互存在」**：g01 的位点区间与联合区间下界都 > 0 → 可写。**R3「秩 3 过拟合」**：g23 的位点区间与联合区间上界都 < 0 → 可写。
**R4 体系表**：每行只写该体系自己的状态与区间；秩 2 的「支持体系数」= SUPPORTS_2OVER1 的体系数，不是 INTERACTION 的数；两者并列，不得混。
**R5 截尾分层**：
- 「单调分层存活」要求：K1 头条口径下 n ≥ 3 的检出秩组，g3 中位随检出秩下降（…r=2, r=1, r=0）**不减**；**且**相关（Spearman）95% 区间上界 < 0。
- 两者都成立 → 可保留「按检出秩分层、单调」的说法，但数字必须换成 K1 的（含每组 n），并写明秩 1/秩 2 之间的界线在 S1 内不可分辨（若 R1 走第三分支），
  因而稳妥的锚点是「秩 0 对秩 ≥ 1」。
- 秩 0/1/2 的单调序列被打破但相关区间仍 < 0 → 删除三层中位的陈述，只保留相关与「秩 0 对秩 ≥ 1」的两组比较。
- 相关区间含 0 → 撤回「截尾预测检出秩」。
- 任何情形都**不引用切点**（D-029）；任何情形都标明 34 个单元同属 S1。
**R6 Figure 1**：图题与断言只编码该规则下为真的事实。判据：低截尾层中位曲线 argmin 为 2 **且** m3 > m2 → 可保持「内部极小在秩 2」，
但若 (m1 − m2) 的单元重抽区间含 0，图题必须加「秩 1 与秩 2 之差不能与零区分」；argmin 为 1 → 图题改为「最小值在秩 1–2」，断言改编码 argmin ∈ {1, 2} 且 m3 > min(m1, m2) 并写注释说明原因；
高截尾层 argmin 不在 2 的断言保留与否由数据决定。**不改断言来让它通过；改断言必须同时改主张，并在注释里记原因。**
**R7 R1 以外的联动**：R1 走第三分支时，docs/35 里凡把「秩 2」作为 K1 之下的事实的句子须改；凡现行程序下算出的数字须加标签或替换（docs/44 列清单）。
