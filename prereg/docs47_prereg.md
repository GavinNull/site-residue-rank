## 2. 校正（交互层；公共掩码 K = 结合观测 ∧ 表达量观测）

Rb、Re = 分别在 K 上双向去均值（`subspace_lib.dc_fast`）。**未校正参照 = 同一掩码 K 上的未校正结合矩阵**（不是全掩码，K 比结合掩码少约 0.1%–6%）。
- **(i-a) 主：全局斜率**。β = ΣRb·Re / ΣRe²（过原点，在 K 上）；Mb' = Mb − β·Re（只去掉表达量的**交互层**，结合自己的主效应保留）。假设：表达量对结合的影响在交互层是线性、残基与位点同一斜率；不假设主效应层与交互层同斜率。
- **(i-b) 次：逐残基斜率** β_j = Σ_i Rb_ij Re_ij / Σ_i Re_ij²（该列观测 < 20 格用全局 β）。
- **(ii) 次：子空间投影**。V_e = 表达量矩阵（K 上）的残基载荷子空间，秩规则：**docs/46 判为二维可复现的源（WH1_v1、WH1_v2、Eta）取 2，否则（BA2、PDCoV）取 1**（规则取自已见的 docs/46 数）。每个位点把 Rb 的该行观测格对 V_e 在这些列上的限制作最小二乘回归（无截距）并取残差（位点观测 < 8 格则丢该位点）。**位点分半分析中 V_e 由另一半位点估计（交叉拟合），以免表达量与结合共享位点噪声泄入**；(i) 的 β 在每一半内部估计。
(ii) 的**机械界**：若表达量第一轴与折叠轴对齐，则 (ii) 校正后的结合轴按构造正交于 V_e，其与折叠轴的 |cos| 有上界 √(1−cos²(V_e1,折叠)) —— **所以 (ii) 对 Q3 无信息，只用于 Q2(a)(b)；Q3 只用 (i)。**

## 3. 双向对照世界（先于任何真实结论；用 docs/46 的残差重采样 RR 世界）

结合侧：docs/45 的 7 点噪声路径（点 0、3、6）；`D.make_world46(g, "RR", …)` 的构造（r+c+I+σ/σ_fit·行内置换残差），**只用 A1 判据下忠实的矩阵**（排除 WH1/bat、Eta/bat、BA2/human_monomer 对应的 RR 不忠实；BA2/bat 无路径）。不用 `coup_sd_true = sqrt(coup_sd_obs²−σ²)`、不用 bootstrap SE、不挑单个 σ。表达量侧：**协变量 = 真实表达量矩阵本身**（避开表达量几何上 RR/REF 不忠实的问题；其结构 P_e = 秩 2 EM/ALS 拟合，其噪声 D_e = 真实残差 − P_e）。SAME-EXP 配对的结合几何为 omicron 文件的 `bind`，其路径用重复差估计的 σ_meas。
世界（全部在同一 (矩阵,点,重复) 上共用随机数种子命名空间 `ec47`）：
- **BS**（γ=0，ρ=0）：结合 = r_b + c_b + I_b + 噪声。I_b = 真实结合秩 2 拟合的位点载荷 U_b，残基基替换为**与 V_e 正交的随机中心化二帧**（独立于表达量）。这是「纯结合特异」。
- **GAM(γ)**，γ ∈ {0.25, 0.5, 1, 2}：BS 加 γ·P_e，P_e 重标到 rms 等于 I_b 的 rms（γ = 振幅比）。命中方向。
- **PURE(γ=2)**：只有 γ·P_e，无结合特异结构（秩 0 的结合特异部分）。校正后不应再检出交互。
- **CORR(ρ)**，ρ ∈ {0.08, 0.30}：BS 加噪声 = ρ·(σ_b/σ_e)·D_e + √(1−ρ²)·RR 噪声。ρ=0.08 是按重复差估计的上界（|ρ̂| ≤ 0.08；报告其估计不确定性：重复编号与文库的对应未文档化，故 0.30 为压力档，不为估计值）。假警报方向。
- **PAR-RES**：结合特异结构的第一轴 = V_e1，第二轴随机；位点载荷独立（残基方向共享，格子层不相关）。
- **PAR-CELL**：结合 = BS + 0.5·（U_e1 s_e1 V_e1ᵀ，重标到 0.5×I_b 的 rms）= 稳定性介导的**真**结合效应。**这与 GAM 在结构上不可区分**（任何格子层的校正都会把它去掉）；报告它是为了诚实：校正无法分辨「混杂」与「稳定性介导的真生物学」。
统计量（每实例；EM 与 K1 两个抽取器）：第一轴（秩 1）对真值 V_b1、对真表达量轴 V_e1、对观测表达量轴的 |cos|；位点分半（S=5）第一轴自复现；秩 2 子空间对 V_b 的主角余弦；K1 的 g01、g12（3 个 CV 种子）。重复 R=36。
**门（在真实结论之前，对每个校正分别判）**，在忠实可评估矩阵 × 点 {0,3,6} 的中位上：
- HIT-1（去掉）：GAM(1)、GAM(2) 下校正后 |cos(轴, V_e1)| ≤ 0.443（d=20 Haar p95）且比未校正低 ≥ 0.25；
- HIT-2（保留）：GAM(1)、GAM(2) 下校正后 |cos(轴, V_b1)| ≥ 0.85 × 同矩阵同点 BS 下校正后的值；
- HIT-3（残余交互）：K1 g01 > 0.02 的比例，BS 下校正后 ≥ 0.8·（BS 未校正的比例）；PURE(2) 下校正后 ≤ 0.10 而未校正 ≥ 0.80；
- FA-1（不制造）：BS/CORR(0.08) 下校正后 |cos(轴, 观测表达量轴)| ≤ 未校正 + 0.05；
- FA-2（不误伤）：BS/CORR(0.08) 下校正后 |cos(轴, V_b1)| 比未校正低 ≤ 0.05；
- FA-3：BS/CORR(0.08) 下表观表达量份额 rms(β̂Re)/rms(Rb) 的 p95 ≤ 0.10。
CORR(0.30)、PAR-RES、PAR-CELL **只报告，不入门**，但 PAR-RES 下 (i) 的保留（降 ≤ 0.05）若不成立，在结论里明说。
**牙齿（§10.2 双向，先于门）**：NOOP（不做校正）必须在 HIT-1 失败；DESTROY（把结合自己的第一轴投影掉）必须在 HIT-2/FA-2 失败；逐点解析自检见脚本 T1–T7。

## 4. 真实数据的统计与规则

**可复现门（D-036，先于比较）**：每个方向（每个结合矩阵的第一轴、每个表达量源的第一轴、折叠轴）的位点不相交分半第一轴 |cos|（真实 250 个分半），须高于该比较自己 d 的随机 p95（d=20：0.443）；不过者**不参与比较**。第二轴按 docs/46。
**Q1**：结合第一轴 × 表达量第一轴；结合第一轴 × 折叠；表达量第一轴 × 折叠（20 维、公共残基、去均值，零分布取该比较自己的 d）；同源/跨源分开报；折叠侧：u_fold 与 144 域逐域（中位）两种口径；另报轴层面的偏相关 (c_bf − c_be c_ef)/√((1−c_be²)(1−c_ef²))（符号对齐后）。
**Q2**：校正后（三种）每个矩阵：(a) K1 g01、(b) g12、g23（3 个 CV 种子 {11,12,13}，位点 bootstrap 2000）、(c) 第一轴 × 折叠、(d) 位点分半第一轴自复现。**Q2(a) 判据**：单矩阵 g01 的位点区间下界 > 0；单位层：该单位内 ≥ 一半的合格矩阵满足。
**Q3 统计量**：c(m, 校正) = |cos(轴_m, u_fold)|（共识口径，主）与对 144 域 |cos| 的中位（like-for-like，须同结论）。单位值 = 该单位合格 SAME-LIB 矩阵的中位。δ0 = max(0.05, 干净世界 BS/CORR(0.08) 下 (i-a) 造成的 |cos(轴,V_b1)| 下降的 p95)（由门阶段给出，写入脚本输出，不在看真实数据后调）。
- 该单位**塌缩**：c_cor ≤ 0.443 且 c_unc − c_cor > δ0；
- **完整存活**：c_unc − c_cor ≤ δ0；
- 否则**部分存活**。
**判决**（先过门）：
- **A（介导）**：门通过 ∧ ≥ 2/3 单位塌缩 ∧ SAME-EXP 层不与 SAME-LIB 层相反；
- **B（相对独立）**：门通过 ∧ ≥ 2/3 单位完整存活 ∧ Q2(a) 在 ≥ 2/3 单位成立 ∧ 校正后第一轴自复现 > 0.443 且 ≥ 0.8×未校正；
- **C（不能评估/不能信/中间）**：门不过，或其余一切（含「部分存活」、两层相反、单位不一致、校正后方向不可复现）。「部分存活」归 C 并显式标注 C-部分。
(ii) 与 (i-b) 的结论与主校正不一致时，**把不一致本身作为发现报告**，不改判决。
