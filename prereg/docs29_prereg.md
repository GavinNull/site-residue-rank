  普适轴 u，\|cos\| 中位 **0.755**（域级 bootstrap [0.720, 0.775]）、
  136/144 = 94.4% 超各自 p95、符号检验 p = 2.9e-165、共识层 0.845、
  ρ ≈ 0.78 [0.75, 0.80]。
- **系统内配对，n = 1**（docs/28 §8.2）：GRB2-SH3 ddPCA，ΔΔG 层配对 mask，

  \|cos(折叠轴, 结合轴)\| = **0.016**，位点内置换零分布中位 0.155、p = 0.945。
  docs/28 的功效说明：若两轴相同应见 ≈ √(0.522×0.481) = 0.50。

## 1. 口径声明（一次说清，之后不混引）

- **配对 mask 一律用 docs/28 的交集口径**（`analysis/ddpca_paired.py`：
  两边非 NA、两边 bootstrap SE ≤ 0.5、两边 \|ΔΔG\| ≤ 10，再要求每行 ≥ 4 格），
  即 GRB2-SH3 **619 / 1064 = 41.8% 缺失**。
  docs/15 §3/§4.2 的 595 / 44.1% **不与本文档的数混引**。
  本文档会尝试归因这处差异（§2.H0），但归因失败不影响任何判决。
- 所有零分布在该比较**自己的 d** 上生成；bootstrap 在**域/系统**层，
  位点层重抽只作为已知偏低的下界记录，不当置信区间。
- 任何方向在参与对齐主张前必须过 **D-036**（互斥两半），
  `stab_boot` 不得代替（D-052）。
- 不使用 ddPCA bootstrap SE 作噪声模型（D-028）；
  不使用体外总 RMSE（D-042/D-055）；不复活 `coup_sd_true` 作判据（D-055）。

## 2. 候选解释、各自的判别观测量、以及什么结果支持谁

### H0（口径核对，不是解释）配对 mask 计数差异的归因
观测量：用 `analysis/folding_vs_binding.py` 的 mask 构造在当前数据上重算
GRB2-SH3 / PSD95-PDZ3 / GB1 的配对格数，与 619 / 1087 / 908（docs/28）
和 595 / 1029 / 901（docs/15）对读。
- 若重算给出 docs/15 的数 → 差异归因于 **docs/15 多一条过滤或行阈值不同**，
  开放项关闭。
- 若重算给出 docs/28 的数 → docs/15 那一版的口径仍追不回来，开放项维持。

### H1 信息性缺失（informative missingness）
机制：docs/15 §3.1 已建立配对 mask 是信息性缺失（systematically 切掉
去稳定尾巴）；41.8% 缺失可能把 0.016 做成一个选择效应产物。
观测量（按顺序，顺序本身是判据的一部分）：
1. **先**在完全观测子矩阵（paired coverage 完整的位点×残基块）自己的几何上
   做 §10.3 还原诊断：植入秩 1 真方向，走与真实数据**完全相同**的流程。
2. **再**在该子矩阵上重算 \|cos(折叠轴, 结合轴)\| 与它自己的位点内置换零分布。
预先写定的判读：
- **支持 H1**：子矩阵的还原 \|cos\| 中位 ≥ 0.80（即**有功效**），
  且子矩阵的实测 \|cos\| 超它自己的置换零分布 p95。
- **否证 H1**：子矩阵还原 ≥ 0.80 而实测 \|cos\| 仍落在置换零分布中位附近
  （≤ p95）。此时「缺失驱动 0.016」被排除。
- **不可判定**：子矩阵还原 < 0.50。此时「仍是 0.016」只说明子矩阵没功效，
  **不得**读成支持任一方。这就是为什么还原诊断必须先做。

### H2 闸边缘功效 / 衰减（attenuation）
机制：GRB2/binding 过 D-036 只有 +0.027 余量（0.472 对 0.445，docs/28 §6.3），
配对 mask 下 0.481。勉强过闸的方向有被重压低的相关上限。
观测量：
1. 衰减校正值 **0.016 / √(0.522 × 0.481)**，并给区间
   （对两个 split-half 分布重抽 2000 次，传播到比值）。
2. **ρ 扫描（这才是功效的正确检验）**：在配对 mask 自己的几何 / 缺失模式 /
   主效应尺度 / σ 下，把结合矩阵的真方向植入为
   `ρ·(折叠轴) + √(1−ρ²)·(与之正交的随机方向)`，走相同流程，
   报每个 ρ 的观测 \|cos\| 分布与检出率（超自身置换 p95）。
预先写定的判读，并**预先声明我预期 H2 走不通**：
乘以 1/√(0.522×0.481) ≈ 2.0 只能把 0.016 抬到 ≈ 0.032，
**衰减校正这条路在算术上不可能化解 0.016 对 0.50 的矛盾**；
docs/28 拿未校正的 0.016 比未校正的期望 0.50 **是同口径的正确比较**。
所以 H2 只能通过 ρ 扫描成立：
- **支持 H2**：检出率 ≥ 80% 的最小 ρ ≥ 0.78（即这个检验看不见 ρ ≈ 0.78），
  或 ρ = 0.78 这一格的观测 \|cos\| 95% 区间**包含** 0.016。
- **否证 H2**：ρ = 0.78 这一格的区间**不含** 0.016，且检出率 ≥ 80% 的最小
  ρ ≤ 0.60。此时阴性有功效。

### H3 结合表型不是结合 / mochi 解卷**过度校正**
机制：binding-PCA 的 fitness 按构造同时依赖折叠与结合（docs/28 §8.2 限定 2：
两 assay 的残基**主效应** \|cos\| = 0.770 / 0.883）。
mochi 的三态解卷若**过度**扣除共享的折叠成分，残下的 binding ΔΔG
就会**按构造**与折叠近似正交，0.016 便是解卷的产物而不是物理事实。
观测量（三条，必须一起读）：
1. **主效应层的落差**：ΔΔG 层两表型的残基主效应 \|cos\|（含**带符号**的 cos），
   与 fitness 层的 0.770 对读。
2. **格子层的带符号相关**：配对 mask 上
   r(折叠交互残差, 结合交互残差)（Pearson，带符号），
   与位点内置换零分布对读。
3. **三角化（最关键）**：在配对 mask 上同时测
   \|cos(折叠轴_paired, u)\|、\|cos(结合轴_paired, u)\|、
   \|cos(折叠轴_paired, 折叠轴_full)\|，其中 u = binding 共识普适轴
   （`cache/generic_folding_axis.json` 的同一个 u），零分布在同一 d 上。
预先写定的判读：
- **支持 H3（过度校正）**：ΔΔG 层主效应的**带符号** cos 为负，
  **且**格子层带符号 r 显著为负（低于置换零分布的 5% 分位）。
- **支持「这个体系本来就没有共享成分」而不是过度校正**：
  带符号 cos 与 r 都 ≈ 0（落在置换零分布中位附近），不为负。
- **支持「结合臂根本没在测 u」（H6，下）**：
  \|cos(折叠轴_paired, u)\| ≳ 0.6 而 \|cos(结合轴_paired, u)\| 落在碰巧水平。

### H4 GRB2-SH3 真的不一样（SH3 折叠 / 结合模式落在 docs/27 的 7% 尾巴里）
观测量：
1. ddPCA 的 GRB2-SH3 野生型序列与 Tsuboyama 144 个域的野生型序列做
   局部比对（Smith–Waterman + BLOSUM62，矩阵与打分函数带已知事实自检），
   报最高同一性。
2. 用 SH3 参考面板（多条已知 SH3 序列）识别 144 里的 SH3 折叠成员，
   报它们各自的 \|cos(折叠第一轴, u)\|，与 144 的分布（中位 0.755、
   四分位 [0.645, 0.822]、低尾 10 个 < 0.45）对读。
3. 若 Tsuboyama 含 GRB2-SH3 本体（同一性 ≥ 90%），直接比较
   \|cos(Tsuboyama 该域折叠轴, ddPCA GRB2-SH3 折叠轴)\|。
预先写定的判读：
- **支持 H4**：SH3 组的 \|cos\| 中位 < 0.45（落在那条 7% 尾巴里）。
- **否证 H4**：SH3 组的 \|cos\| 中位 ≥ 0.645（144 的四分位下界），
  即 SH3 折叠在折叠—结合一致性上是**正常**的。
- 若含本体且两平台折叠轴 \|cos\| ≥ 0.6 → ddPCA 的折叠轴**不**古怪，
  矛盾不能归到「这个域的折叠轴测错了」。
  若 < 0.45 → ddPCA 的 GRB2-SH3 折叠轴本身有问题，这会同时削弱
  docs/26 §7 的 0.842。

### H5 跨数据集一致性是共同偏倚（另一侧的零假设）
docs/26 已排除「一般取代破坏性」（五条无配体标度 r² 0.001–0.192，
15 标度置换天花板 p95 = 0.593，无一越过，且有决定性的不对称）。
排除之后**仍然在台上的共同偏倚候选**，以及可测的那几条：
1. **流程诱导方向**（两侧用同一套 `extract_subspace` / `als_guarded` /
   双向中心化）。**可测**：用 144 个域各自的几何 / 缺失模式填**纯噪声**
   （不植入任何结构），走相同流程取第一轴，测它与 u 的 \|cos\| 分布。
   支持 H5 的签名：中位显著高于各自 d 的 Haar 中位，超 p95 比例 ≫ 5%。
   否证：中位 ≈ Haar 中位、超 p95 ≈ 5%。
2. **缺失模式 / 观测量的残基偏倚**（两个平台都对某些残基系统性少测）。
   **可测**：测 \|cos(u, 逐残基缺失率向量)\| 与
   \|cos(折叠共识轴, 逐残基 n_obs 向量)\|。
   支持 H5：≥ 0.6。否证：落在 d 的 Haar p95 以下。
3. **「都是同一条物理机制（埋藏疏水核心）」**。这不是偏倚，这正是待检验的
   假设本身；本设计**不能**把它与「共享真方向」分开，预先声明为不可分辨项。
4. **残基标度的有限字母表**（d = 19–20 的方向空间里，任何两条"化学上合理"
   的方向都天然有正相关）。**可测**：这正是 Haar 零分布控制的对象，
   已在 docs/27 逐域控制（p95 ≈ 0.443），不新增测量；但要在正文说明
   它控制的是随机方向，不控制"两条都偏向疏水性"这类结构化偏倚
   —— 后者由候选 1/2 与 docs/26 的五条标度共同覆盖。

### H6（本文档新增）层级错配：配对比较的"结合臂"与 n = 144 的"结合轴"不是同一个对象
机制：n = 144 比的是 folding 交互轴 vs **直接 Kd 测定**（Starr/OMTKY3）
建出的 binding 共识轴 u；配对比的是 folding 交互轴 vs **mochi 解卷出来的**
binding ΔΔG 交互轴。若后者不复现 u，两个结果就不是互相矛盾，而是两个对象。
观测量：与 H3 第 3 条同一组三角化。
判读：
- **支持 H6**：\|cos(结合轴_paired, u)\| 落在碰巧水平，
  而 \|cos(折叠轴_paired, u)\| 超 p95。
- H6 与 H3 共用观测量，**区分它们的是 H3 第 2 条**：
  带符号 r 显著为负 → H3（过度校正，真有共享成分被扣掉）；
  带符号 r ≈ 0 → H6（结合臂只是没有可辨识的方向，不是被扣掉的）。
