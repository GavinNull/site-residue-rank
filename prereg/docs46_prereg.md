（对任务书「植入秩 1 K1 拟合」的偏离，如实记录：我用 docs/43/45 一直在用的标准拟合 P_k，不用 `als_joint` 的 K1 拟合，使本轮与 docs/45 之间**只有噪声模型/截断一项变化**。）

- **G（无截断高斯，主）**：Y = r + c + I(k, s) + N(0, σ²)，**不截断**（`Geometry.make(..., clip=False)`）。
- **RR（残差重采样，次）**：Y = r + c + I(k, s) + (σ/σ_fit(k))·E，E = 把矩阵自己的秩 k 拟合残差 D_k = `RC.residual(M, mask)` − P_k 在**每个位点（行）内**对观测格子随机置换。
  边缘分布（重尾、异方差、类截尾堆积）按构造等于真实残差；σ = σ_fit(k) 端 RR 的尺度因子为 1。不截断。
- **R0（无结构）**：G-R0：Y = r + c + N(0, σ0²)（`sigma0()`），不截断；RR-R0：Y = r + c + 整个残差 Rf 在行内置换，不截断。
- **主/次**：G 是主（与 docs/43/45 的世界只差 clip 一项，改动最小）；RR 是次。逐矩阵两者若不一致，**那本身是发现**，如实并列。

## 3. 保真判据（世界使用前必须先过；固定的数）

对每个 (矩阵, 世界, 路径点)，取 20 个新鲜世界实例（种子 `d46`），记真实矩阵的观测值域 [lo, hi]、总双向去均值残差 SD = cso，
R = `RC.residual(Y, mask)` 在观测格上的值。三个统计量取 20 个实例的均值：

- **F1 值域越界**：观测格子里 Y ≤ lo 或 Y ≥ hi（「在边界或之外」）的比例。**判据 F1 ≤ 1.0%。**
  （真实矩阵只有约 0.1% 在边界；同样大小的忠实矩阵期望 ≈ 2/n ≈ 0.06%；要抓的缺陷是 5–23%。1% 取在其间。）
- **F2 分布距离**：R 的经验分位函数与真实 R 的 Wasserstein-1 距离 / cso（同 mask，格数相同，排序后逐位比较）。**判据 F2 ≤ 0.10。**
- **F3 分位偏差**：max over q ∈ {0.01, 0.05, 0.25, 0.5, 0.75, 0.95, 0.99} 的 |Q_world(q) − Q_real(q)| / cso。**判据 F3 ≤ 0.40。**

一个 (矩阵, 世界) 称「忠实」当且仅当 F1、F2、F3 在它的**全部 14 个路径点**上同时通过。任何一个点不过，该矩阵在该世界下记 **F（对照不忠实）**，
不进该世界的体系层计数；**不换成别的世界来凑**。

**检验的牙齿（工具自检，先于一切真实分半；任一不过即中止，不得放宽判据）：**

- FT1 命中：旧的截断世界必须被抓住。在 14 个路径矩阵 × 14 个点上计算 clip=True 世界的 F1；**至少 4 个 S1 矩阵至少有一个点的 F1 > 5%**
  （docs/45 报告的 5–23% 应当被复现，作者记得 WH1/hamster 8.5–17%、BA2/deer 16–23%），且这些点在 F1 判据下判 F。逐矩阵逐点的表要原样报告。
- FT2 不误伤：旧截断世界在**真正没有格子被截断**（被截比例 < 0.5%）的点上必须通过 F1。
- FT3 已知忠实的参照：RR 世界在 σ = σ_fit(k) 端（尺度因子 1，真实残差行内置换，不截断）**必须在全部 15 个路径矩阵上通过 F1–F3**。
  若不通过，说明判据本身与「已知忠实」不符（过严），**中止并交人，不放宽**。
- FT4 对别的缺陷也有牙齿：G 世界的中点路径点，把双向中心化部分（交互 + 噪声）整体放大 1.25 倍（方差失配 25%），
  必须在 ≥ 90% 的路径矩阵上被 F2 或 F3 判 F。这同时声明判据的分辨率：约 20% 的 SD 失配可抓，5% 抓不到。
- FT5 不对称性：G 世界在 σ0 的无结构点上不应因判据本身而系统失败——这一项只报告，不作门。

### 6.4 比较与植入对照（只在 G-E 过的表达量源上）

比较量 C：结合矩阵的二维残基子空间与表达量矩阵的二维残基子空间的主角余弦 cos θ₁、**cos θ₂**，经 `subspace_lib.align`（共同残基、再中心化），
**零分布在该比较自己的 d（= n_res）上**：Haar（`haar_pair_null(d, rank=2)`）与 N-perm（表达量矩阵位点内残基置换）。
计算两种：(i) **位点不相交（主）**：结合取半 A、表达量取半 B（与反向），300 个随机分半，取 cos θ₂ 中位；(ii) 共享位点、全数据（次，仅描述）。EM 与 K1 都做。
附：表达量二维子空间换成三维（rank=3）的一次敏感性（零分布用 (2,3) 对的 Haar，d 同）。

**植入对照（先自检、再看真实）**：对每个配对，在两个矩阵各自的几何（Geometry 与路径）上，同时植入结合与表达量两个矩阵（独立噪声，无截断高斯，路径点 {0, 3, 6}，两矩阵同索引）：
- **SHARED**：表达量的交互 = U_e S_e V_bᵀ（表达量自己的位点载荷与幅度，残基基换成结合的 V_b）；
- **PARTIAL**：只有第一轴共享（V = [v_b1, 与之正交且中心化的随机向量]）——对应「第一轴与稳定性共用」已知的情形；
- **INDEP**：V = 随机、中心化、正交的 2 维基。
每世界 R_B = 40 复现 × S_B = 6 个分半。**门 G-B1（命中）**：SHARED 的复现中位（cos θ₂）在每个路径点都 > 同点 PARTIAL 的 p95；
**门 G-B2（不误伤）**：INDEP 世界里 cos θ₂ 超过 N-perm p95 的比例 ≤ 0.10。门不过的配对：**无法评估**。

**分类（逐配对，EM/K1 各自）**：x = 真实 cos θ₂ 中位。
p_sh = max over 路径点 (1 + #{y_SHARED ≤ x})/(R_B+1)；p_pa = max over 点 (1 + #{y_PARTIAL ≥ x})/(R_B+1)。
- **COINCIDES（与表达量交互子空间重合）**：p_sh > 0.05 且 p_pa ≤ 0.05。
- **DISTINCT（第二方向不在表达量子空间里）**：p_sh ≤ 0.05。
- **INDETERMINATE**：其余。
体系层（S1 跨源，通过门的配对）：COINCIDES ≥ 2/3 → 「第二轴像表达量/稳定性结构」；DISTINCT ≥ 2/3 → 「与表达量交互子空间不同（证据，非证明）」；否则混合/未决。两抽取器必须一致，否则 CANNOT BE ASSESSED。配对不独立（同一表达量源服务 5 个配体），**以表达量源（骨架）为单位**再报一遍。

### 6.5 次要（描述，不进分类）

- 残基**主效应**：表达量的列主效应（20 维，中心化）落在结合二维子空间里的投影范数（对 Haar 1 维对 2 维、d 同），并对结合自己的列主效应做同一量（docs/45 §7 的复现）。
- CR9114 签名检查：结合子空间与 `expr_rep1`、`expr_rep2` 分别的 cos θ₂，两个重复若一个对齐一个不对齐，则报告为不可复现的信号。

### 6.6 Part B 的限定（先写下）

- 即便第二方向不在表达量二维子空间里，也**不等于**结合特异：可以落在表达量的更高维子空间、或别的残基层面系统结构（文库组成、酵母展示的残基偏好）里。
- 表达量与结合来自两次实验，共享文库条码构成；这不是同一实验的两个读出。
- 分选读出有各自的动态范围压缩（BA2 的表达量范围窄），表达量矩阵的噪声路径同样来自重复差，不使用 σ 减法。
