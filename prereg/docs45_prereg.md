## 1. 问题与它能回答什么、不能回答什么

问题：docs/14 的 u₂ 复现信度 0.983 来自 12 个共享同样 201 个位点、同一变体库、几乎相同序列的组合，共享位点噪声会抬高它。**不共享位点时**，残基侧的第二成分子空间还能复现吗？

做法：对每个矩阵把位点随机分成不相交的两半，各自独立抽取秩 2 的残基载荷子空间（20 维一侧，规范无关），用主角余弦 cos θ₁、cos θ₂ 比较。**cos θ₂ 是第二成分的复现性。**

**这个设计能排除的**：位点共享带来的噪声重复（两半没有共同位点，也没有共同的格子噪声）。

**这个设计排除不了的（必须写进结论）**：任何**残基层面的系统结构**会在两个位点半里同样出现——泛化的取代耐受性、表达效应、文库组成偏倚、测量方法的残基偏好。所以阳性结果的读法只能是「存在可复现的、不由共享位点噪声造成的残基层面结构」，**不是**「存在结合特异的第二成分」。docs/26 排除了泛化取代破坏性对**第一**轴的解释；第二轴是另一个问题，本分析不回答它。

## 2. 范围与分析单位

- **主分析单位：独立体系 S1（RBD × ACE2）。** 15 个矩阵是同一体系内的**不独立重复**（docs/41：交互残差平均相关 0.61–0.72；共享位点、文库）。矩阵层统计量只用于描述与按规则计数，**不当作 15 个独立证据**。
- 真实矩阵：S1 的 15 个 animalACE2 矩阵（3 骨架 × 5 配体）；S2 gAPN（114 位点）单列。
- **有噪声路径（可做植入世界对照、进入判决）的矩阵 = docs/43 的路径矩阵**：S1 的 14 个（15 个去掉 Omicron_BA2/bat：其 σ_meas 0.223 > σ_fit1 0.157，路径为空，docs/43 判「无法评估并停」）；以及 gAPN。其中 3 个 human_monomer 的 σ_meas 是迁移值（标 T），照 docs/43 沿用。
- Omicron_BA2/bat：只报真实分半分布，**不进判决、无植入对照，标 CANNOT_ASSESS**。
- **不可评估（事先声明，不强行推）**：OMTKY3（约 10 个位点，5+5 无法支撑 2 维子空间）、4-4-20（20 位点）。CR9114 已按 D-091 移出体系表，不在范围。pAPN/hAPN 因截尾/无功效不在范围（docs/44）。sarbecovirus 单元无重复噪声列，不在范围。
- 判决只对 S1（14 个路径矩阵）下；gAPN 只作为第二个体系的并列参照，不与 S1 合并计数。

## 3. 分半设计

- 位点（行）随机分成两个不相交的集合，各 ⌊nr/2⌋ 个位点（奇数时丢 1 个）。**断言两半的位点索引不相交**（自检项）。
- 真实矩阵：S_real = 200 个随机分半，种子固定。
- 植入世界：每个复现 S_w = 8 个随机分半；R = 60 个复现（新鲜噪声）。
- 二级（描述）：连续分半——按数值位置分成 N 端半与 C 端半（相邻位点共享结构环境，随机分半可能乐观），每矩阵 1 个。
- 二级（描述）：跨组合比较的 2×2 设计（见 §6）。

## 4. 子空间抽取（两种，**都报告，不挑有利的**）

- **E-EM（主，docs/13 所用）**：`subspace_lib.extract_subspace(M, mask, rank=2, method="emsvd")`，其内置的 MIN_PER_ROW=4、MIN_PER_COL=6 保护照用。
- **E-K1（第二）**：与 `rank_k1.cv_rank_k1` 同一联合拟合 `rank_k1.als_joint`（秩 2、ridge=0.1、iters=150、2 次重启按**训练**误差择优），对返回的完整预测 P 做双向去均值（全矩阵）后取 SVD 的前 2 个右奇异向量作为残基基。行/列保护与 E-EM 相同（先丢观测 <4 的行、<6 的列）。动机：定秩时的「主效应吸收」偏差也可能扭曲抽取。
- 比较：`subspace_lib.align`（共同残基、再中心化、再正交化；cos 降序排列，cos θ₁ ≥ cos θ₂）。记录其返回的 `n_res` = d。
- 候选自由参数：**0**（两个抽取器的所有参数在此固定，不调）。

## 5. 零分布（在**该比较自己的环境维数 d** 上，d = `align` 返回的 n_res）

- N-Haar：`subspace_lib.haar_pair_null(d, rank=2, n=4000)`。
- N-perm：对真实矩阵做位点内残基置换（`subspace_lib.permute_within_sites`），再走**同一**分半+抽取流程；每矩阵 50 个置换矩阵 × 8 个分半 = 400 对。
- 同一矩阵的 d 可能因保护丢列而变化，N-Haar 按每个比较的 d 分别取（缓存按 d）。
- **注意**：N-perm 同时摧毁了残基主效应与一切残基层面的系统结构，所以它**不是**「无第二成分」的合适零假设——它只是「无任何位点×残基耦合」的零。真正的「没有第二成分但有第一成分与主效应」的对照是 §7 的秩 1 世界。

## 6. 跨组合比较（Step 5：与 docs/14 的 0.983 同口径对照）

对 docs/14 的 12 个可比组合（从 `cache/site_loadings.json` 取 `comparable`），用 E-EM 与 E-K1 各自抽取，计算 cos θ₂（以及 cos θ₁）：

| 记号 | 比较 | 位点 | 含义 |
|---|---|---|---|
| A | 不同组合 X、Y，全部共同位点，各自全数据抽取 | 共享 | 残基子空间层面的共享位点复现（与 u₂ 信度 0.983 同家族，非同量） |
| B | X 的位点半 H₁ 与 Y 的**同一** H₁ | 共享（半大小） | 把样本量降到分半大小的共享位点对照 |
| C | X 的 H₁ 与 Y 的 H₂ | **不相交** | 跨组合 + 不共享位点 |
| D | X 的 H₁ 与 X 的 H₂（同一组合） | **不相交** | 即 §3 的真实分半 |

- 位点半对每对组合取 8 个随机分半后取中位。B 与 C 的差是**位点共享本身**的效应（半大小、同样的两个组合）；A 与 B 的差是样本量效应。
- 汇总：对 66 个组合对（12 取 2）报中位与 2000 次 bootstrap（对组合对重抽，描述性，**组合对不独立**，区间应视为偏窄）。另按骨架对分层：WH1–Eta、WH1–BA2、Eta–BA2（BA.2 与其余各差 16 处位点；WH1–BA2 是最不相似的一对），以及同骨架不同配体、同配体不同骨架。**WH1–BA2 另报一版：剔除两者 wildtype 不同的位点后再做 B/C**。这能且只能说明：序列差异位点不是复现的来源；它**不能**说明系统独立（骨架仍共享 185 个位点的野生型、同一文库、同一实验室）。
- 比值与差：报 ρ = median(C)/median(B)，以及在 cos² 尺度上的同一比值（cos² = 第二方向共享的方差比例）。**事先规定的读法**：ρ(cos²) ≥ 0.8 → 「位点共享几乎没有贡献」；0.5 < ρ < 0.8 → 「部分」；ρ ≤ 0.5 → 「0.983 的大半来自位点共享」。该读法**同时**要求 §8 的判决，不单独成立。

## 7. 植入世界（两个方向都测；在每个矩阵**自己的**几何上）

几何 = `overshoot_lib.Geometry`（实际 mask、主效应 r/c、截断范围、真实载荷拟合）。不使用 `coup_sd_true = sqrt(coup_sd_obs² − σ²)`；不使用 bootstrap SE；不挑单个 σ。

噪声路径沿用 docs/43 的 7 个等比点 σ ∈ [σ_meas, σ_fit(k)]，每点的 s 由 cso 正向匹配解出（`cache/overshoot_noise.json` 的 `path_k1` / `path_k2`），**每个点都报告**。

| 世界 | 构造 | 路径 |
|---|---|---|
| R1 秩 1 世界（**最重要的对照**：第二成分不存在时 cos θ₂ 多大） | r + c + 真实秩 1 交互 + 高斯噪声 | `path_k1`（7 点） |
| R2 秩 2 世界（命中方向） | r + c + 真实秩 2 交互 + 高斯噪声 | `path_k2`（7 点） |
| R0 无结构世界 | r + c + 与真实总残差同量级的高斯噪声（`sigma0()`） | 单点 |
| R1P / R2P 变体 | 秩 1（秩 2）真实交互 + **真实残余在位点内置换**（保留真实重尾与异方差，摧毁残基结构），不加高斯噪声 | σ_fit 端（1 点） |
| R2λ 剂量 | 取真实秩 2 拟合 P 的 SVD，第二项乘 λ ∈ {0, 0.25, 0.5, 1, 2}，其余同 R2 | `path_k2` 的中点（第 4 点）；用于量「最小可检出的第二成分方差占比」 |

每个 (矩阵, 世界, 噪声点)：R = 60 个新鲜复现 × 8 个分半；两种抽取器各自算。记录每个复现的分半 cos θ₁、cos θ₂ 中位。

**注意 R1 世界的陷阱**：强第一成分 + 弱第二成分时，抽取出的第二方向可能吸收第一成分残余或主效应泄漏，使 cos θ₂ 在**没有第二成分**时也偏高。R1 世界正是用来量这个的；不预设它小。

## 8. 工具门（硬门；不过则判决为 CANNOT_ASSESS，不管真实数据怎样）

主脚本入口强制运行（CLAUDE.md §10）：

- **T1 已知事实**：`subspace_lib.haar_pair_null(20)` 的 Σcos² 均值应为 4/19 = 0.2105（±0.01）。
- **T2 理想条件还原**（既测命中也测不误伤）：在 2 个真实几何上植入无噪声秩 2（真实载荷、真实 mask）：两种抽取器的分半 cos θ₂ 中位 ≥ 0.98；植入**无噪声秩 1**：cos θ₁ ≥ 0.98。
- **T3 不误伤**：R0 无结构世界在 2 个几何上，分半 cos θ₂ 中位不超过同几何 N-perm 的 p95。
- **T4 分半不泄露**：两半的位点索引不相交（断言）；改变一个位点的所有数值，只改变包含它的那一半的子空间（另一半的基逐位不变）。
- `analysis/subspace_selftest.py`、`analysis/censor_density_check.py`、`analysis/gate_harness_check.py`（`cache/gate_harness_check.json` 的 ok = true 为前提）、`rank_core.selfcheck()`、`rank_k1.selfcheck()` 全过。

**H1（假警报门）**：R0 世界中，各矩阵的分半 cos θ₂ 超过该矩阵 N-perm p95 的比例，跨路径矩阵的汇总 ≤ 0.10。
**H2（命中门）**：对每个路径矩阵，若在 R2 路径上**至少一个点**满足「R2 世界复现中位的中位数 > 同点 R1 世界复现中位的 p95」，则该矩阵「可分辨」，否则标 U（该矩阵无功效，不进判决）。要求可分辨的矩阵 ≥ 2/3；不满足则整体 CANNOT_ASSESS。
H1 或 H2 不过：不解释真实结果，写 CANNOT_ASSESS。

## 9. 判决规则（数值，先于数据）

每个矩阵 m、每个抽取器 e：

- x_real(m,e) = 真实 200 个随机分半的 cos θ₂ 的中位。
- 对 R1 路径的每个点 p：y₁(p) = 60 个复现各自的分半中位；
  pos1(m,e) = max_p (1 + #{y₁(p) ≥ x_real}) / (R+1)（**对数据最有利的 R1 点**取最大 = 保守）。
- 对 R2 路径的每个点 p：pos2(m,e) = max_p (1 + #{y₂(p) ≤ x_real}) / (R+1)。
- 分类：
  - **R**：pos1 ≤ 0.05（真实 cos θ₂ 超过秩 1 世界在**每个**噪声点的复现分布）。若同时 pos2 ≤ 0.05，加注「弱于按拟合幅度植入的秩 2 世界」。
  - **N**：pos1 > 0.05 且 pos2 ≤ 0.05（与秩 1 世界相容，且排除了按拟合幅度植入的秩 2 世界）。
  - **I**：二者都不能排除（有功效但不能判）。
  - **U**：该矩阵在 H2 下不可分辨。
- 体系层（S1，14 个路径矩阵里的可分辨者，记 n_a）：
  - **REPRODUCIBLE_e**：R 类 ≥ 2/3·n_a。
  - **NOT_REPRODUCIBLE_e**：N 类 ≥ 2/3·n_a。
  - 否则 **UNDECIDED_e**。
- **总判决**：两个抽取器都 REPRODUCIBLE → **REPRODUCIBLE**；都 NOT → **NOT REPRODUCIBLE**；其余（含两抽取器不一致、UNDECIDED）→ **CANNOT BE ASSESSED（抽取依赖/未决）**。H1/H2 不过 → CANNOT BE ASSESSED。
- REPRODUCIBLE 的措辞边界：「存在可复现的、不由共享位点噪声造成的残基层面结构」，**不得**写「存在结合特异的第二成分」。
- 另报（不改变判决）：同一规则对 cos θ₁ 的分类（第一成分对照：它应该是 R）；真实 cos θ₂ 与 R2 世界中位之差；二级连续分半的方向是否一致。

## 10. 第二成分占多少方差（Step 6）

- 标准拟合（docs/14 同口径：`site_loadings.fit_rank2` 的双向去均值 + `als_guarded` 秩 2，ridge=0.05，restarts=6，iters=400）与 K1 拟合（`als_joint` 秩 2，ridge=0.1，iters=150，2 次重启，全数据）。
- 对拟合的交互 P 做 SVD，两个秩 1 项在**观测格子**上的平方和，给出：(a) 第二项占两项之和的比例 share₂ = ‖c₂‖²/(‖c₁‖²+‖c₂‖²)；(b) 第二项占去均值残差总方差（观测格）的比例。
- **校准**：同一估计器用于 R1 世界（得到「没有第二成分时拟合也会给出的占比」）与 R2λ 世界（植入占比已知，核对是否被还原）。真实占比只有相对于 R1 世界的虚假占比才可读。
- 并列报告 docs/44 的留出增益 g12（+1.3% [−1.4%, +4.7%]）；那是留出量，这里是拟合量，**不互换**。

## 11. 统计纪律

- 所有区间 bootstrap ≥ 2000 次。真实矩阵层：对 200 个分半重抽得中位的区间（只刻画分半蒙特卡罗与位点抽样的离散，**不**刻画体系间变异）；体系层：对矩阵重抽（描述性，矩阵不独立，偏窄）。
- 与基线比较的是区间/分布重叠，不是均值大小。不对位点做 bootstrap 抽取子空间（docs/13：会把对齐拉低到点估计的 ~0.65）。
- 不拿分半 cos θ₂ 去和全数据基准比较；比较一律在同一半大小、同一 d 的植入世界或零分布内。
- 记录搜索量：2 个抽取器、7 个噪声点 × 2 条路径、4 种世界类型、1 个二级连续分半；候选的自由参数 0 个。标签置换对照（N-perm）在实际候选量级下做（每矩阵 50 个置换）。
- 停止规则（§6）：本分析不调参；若三个抽取器变体都给同一区间则不再扩展；任何新抽取器视为新候选并记入搜索量。
- 人类决策点不自行决定：认定模块「成立」并转向写作；判别集纳入判据的改动。本分析只给出判决与措辞建议。
