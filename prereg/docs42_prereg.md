## 2. 定秩程序 P*（固定，不得调参）

`rank_core.cv_rank_noleak(M, mask, max_rank=3, K=5, restarts=3, seed=3,
iters=250, ridge=0.1)`；中心化只在每折训练集内部（`center_fit`），ALS 为
`als_guarded` 的向量化等价实现（`rank_core` C8 自检与之逐元素核对）。
指标 = **trim95 RMSE**（裁掉最差 5% 的留出格子）；**检出秩 = trim95 的 argmin，
秩 ∈ {0,1,2,3}，并列取小**。分割种子固定为 3；真实数据上另报种子 13、23
作稳健性（次要，不参与判决）。
增益：g01 = (t0−t1)/t0，g12 = (t1−t2)/t1，g23 = (t2−t3)/t2（t = trim95）。
**「恰好两个」的内部极小腿 = t3 > t2，即 g23 < 0。**
**已知方向性偏差（rank_core C6b）**：高 SNR 下检出秩偏高。因此锚点 A
（σ = 0.112，SNR 很高）下检出的秩 2 有可能实为秩 1，检出的秩 3 有可能实为秩 2；
本偏差由功效分析的混淆矩阵直接度量，不另做修正。

## 3. 功效分析（Step 2，在任何真实秩之前）

对每个 U 中的域，在**它自己的**几何（位点、残基集、缺失模式、本域实测主效应 r、c）
上合成：`M = r_i + c_j + 交互(秩 k, 强度 s) + N(0, σ²)`，未观测格子不参与。
交互项 = 双向中心化、列正交的 Φ（位点）与 Ψ（残基）随机取，奇异值谱
`SPEC = {1:(1), 2:(1, 0.5), 3:(1, 0.5, 0.25)}`（元素级 RMS 的相对权重，
对应 binding 侧设计点 λ2/λ1 ≈ 0.53），总元素级 RMS = s。
残基方向**随机**，不取自该域真实拟合（不偷看结构）。

**三个 σ 锚点（docs/27 §4.2，一律各报一次）**：
A = 0.112（技术重复下界）；C = 该域 `sigma_C`（逐域反解，中位 0.45；
注意 σ_C 是以秩 1 合成匹配可复现度反解的，带有秩 1 假设，随数声明）；B = 0.70（体外上界）。

**交互强度 s 的情景（D-028 / D-042 / D-055 的约束如何处理）**：
`coup_sd_true = sqrt(coup_sd_obs² − σ²)` 不是可判定量，**不作任何纳入或排除的判据**。
这里只用它**定义情景**，并做两处修正：(i) 用 κ（iid 单位噪声经同一 mask 与同一
双向中心化后留在观测格子上的方差比，由模拟得到，不是解析近似）代替 1，即
`s_a² = cso² − κσ_a²`，这吸收了中心化的自由度损失；(ii) 当 `s_a < 0.25·cso`
（情景与实测残差不相容）时，**不判该域无信号**，而是改用**上限情景**
`s = cso`（把全部实测残差都当交互，对该 σ 是最慷慨的假设）并标 `ceiling`。
锚点 B 预期绝大多数域落入 `ceiling`；`ceiling` 情景给出的是**该 σ 下可能达到的
最大功效**，用于界定上界，**不用于纳入**（见 §4）。
**秩 0 世界用方差匹配的零假设**：`σ0² = σ_a² + s²/κ`（同样的总残差方差，
全部为各向同性噪声）。
每个 (域, 锚点, 真实秩 ∈ {0,1,2,3}) 格 **NSIM = 40** 次独立合成，各自走 P*。
补充（次要，不参与纳入）：(a) 在 σ_C 上 s ∈ {0.15, 0.25, 0.35, 0.50, 0.70}
对真实秩 1、2 各 30 次，给出「最小可检出强度」；(b) 谱等权 (1,1) 的秩 2，
三个锚点各 30 次。**搜索量：每域 12×40 + 10×30 + 3×30 = 870 次 P* 调用。**

**输出**：每个 (域, 锚点) 的 4×4 混淆矩阵 P(检出 j | 真实 k)；检出 2 的灵敏度
`sens = P(检出2|真实2)`；特异度 `fp1 = P(检出2|真实1)`、`fp0 = P(检出2|真实0)`。
同时存 trim95 曲线（相对 t0 归一）以便真实曲线与合成曲线做量级对照（§8）。

## 4. 纳入规则（pre-registered threshold）

一个域在锚点 a **被纳入秩计数**，当且仅当 **全部**满足：
1. 情景类别 = `consistent`（`ceiling` 不纳入）；
2. `sens ≥ 0.80`；
3. `fp1 ≤ 0.20` 且 `fp0 ≤ 0.20`。
（40 次下 sens 的二项标准误 ≈ 0.06；0.70 / 0.90 作敏感性另报。）
**簇被纳入 = 该簇至少一个域被纳入。** 同时另报「上限情景」下满足 2、3 的域/簇数
（`ceiling-admitted`），仅用于界定上界。

## 5. 停止规则（先于任何真实秩）

- 若某锚点下被纳入的**簇数 < 20**，该锚点**不做真实数据定秩、不出判决**；
  报告写「该锚点下本数据无法决定折叠秩」，并给出功效上界（§3 的 `ceiling`
  与 σ_C 上的 s 网格）。
- 若**三个锚点都 < 20**，整件事**停在 Step 2**：不跑 Step 3–6，交付功效结果与上界。
- 真实数据定秩脚本 `foldrank_ranks.py` 在功效结果文件不存在、锁不上、或
  没有任何锚点 ≥ 20 簇时**拒绝运行**。只对「在 ≥1 个 ≥ 20 簇的锚点下被纳入」
  的域计算真实秩。

## 6. 真实数据的统计（只在 §5 放行后；以簇为单位；逐锚点分别做）

按簇代表（§1）取检出秩。
1. **检出秩的簇间分布**（0/1/2/3 的计数）。
2. **精确符号检验（报告用）**：在检出秩 ∈ {1,2} 的簇里，检出 2 对检出 1，
   二项 p（双侧，H0: 0.5）。**不作判决依据**，因为检出误差不对称，0.5 不是
   任何一个纯世界的零假设。
3. **校准检验（判决依据）**：对每个纯世界 w ∈ {0,1,2,3}，用每个被纳入簇代表的
   混淆矩阵行 P(检出 j | 真实 w)（Jeffreys 平滑 (n_jk+0.5)/(40+2)）
   在该世界下蒙特卡洛 20000 次重生成「检出秩向量」，以对数似然
   为统计量，得单尾 `p_w = P(logL_sim ≤ logL_obs)`。
   世界 w「被拒」⇔ `p_w < 0.05`（w=1 与 w=2 为主对比；w=0、3 次要，
   不做多重校正，随数带着）。同时报 `Λ12 = L_2/L_1` 及其 MC 校准。
4. **簇自助（2000 次起，取 4000）**：簇层中位 g01、g12、g23 的 95% 区间；
   `g23 < 0` 的簇占比。
5. **域层同样的量**（次要，标明域层）。
6. 报告有效样本量（被纳入簇数）、域数、功效 `sens` 的簇间中位。

## 7. 判决规则（事先写定；逐锚点；不得事后改）

- **「折叠是秩 2」**：世界 1 被拒（`p_1 < 0.05`），世界 2 未被拒（`p_2 ≥ 0.05`），
  g12 的簇自助中位 95% 区间下界 > 0，**且**内部极小腿成立（世界 3 被拒
  `p_3 < 0.05` 且 g23 中位的区间上界 < 0）。缺最后一条则只能写「秩 ≥ 2 受支持，
  『恰好两个』未证实」。
- **「折叠是秩 1」**：世界 2 被拒，世界 1 未被拒，且 g01 区间下界 > 0。
  若 g01 区间含 0 则写「秩 ≤ 1」。
- **「折叠是秩 0」**：世界 0 未被拒，世界 1、2 被拒（极少预期）。
- **「异质」**：世界 1 与世界 2 都被拒 → 簇间不是单一秩，不得合并成一个数。
- **「不可判定」**：世界 1 与世界 2 都未被拒；或被纳入簇 < 20；或锚点间判决
  矛盾（以最保守者为总判决，并列出各锚点结果）。
- 总判决 = 三个锚点中**有判决资格者**（≥ 20 簇）的一致结论；不一致写
  「依赖 σ 的取值」，不选一个。

## 8. 对照与解释顺序

解释次序（本身是判据的一部分）：①工具自检 → ②功效与纳入数（Step 2）→
③停止规则 → ④检出秩的簇分布与校准检验 → ⑤g12 / g23 → ⑥`f_out` 协变 →
⑦与 binding 的配对解读 → ⑧（仅当判决为秩 2）第二轴。

- **(a) 截尾协变**：每簇代表的 `f_out`（`cache/tsuboyama_censor.json`，直接计数）
  对 **g12**（连续量，主）与检出秩（次）的 Spearman ρ，簇自助 95% 区间；
  另按 `f_out` 三分位分层报检出秩分布。`f_out` 全体 < 10.9%（过闸判据），
  动态范围变化窄，这一点随数声明：协变弱不等于「与动态范围无关」。
- **(b) 量级校准（§8）**：每个锚点上，合成 rank-k 世界的 t0、(t1/t0, t2/t0, t3/t0)
  与真实曲线并排报；绝对量级对不上就标不通过。同时报合成情景下实现的
  双向中心化残差 SD 对实测 cso 的比（应≈1）。
- **(c) 与 binding 的配对解读**：只写文字，不另算（docs/29 与 docs/27 §6.3 的
  限定原样带上）。
- **(d) 第二轴（仅判决为秩 2 时）**：对被纳入且检出秩 2 的簇代表，用
  `extract_subspace(rank=2)` 取 span，逐方向的位点对半可复现（D-036）先报，
  再报跨簇的第二轴稳定性；不得把 k=90 的 λ2 检验结果外推到 k_eff=2（docs/34）。

## 10. 事先声明的局限（随结论一起报告）

- 合成噪声是各向同性高斯；真实噪声依赖 ΔG（动态范围边缘更大）。
- 合成数据的缺失与数值无关；真实缺失是**信息性**的（越界被扣留，docs/27 §3）。
  这使合成功效偏乐观。
- 交互谱 (1, 0.5, 0.25) 与随机残基方向是假设；真实交互可能有重尾位点载荷。
- σ_C 内含秩 1 假设；锚点 A 下 C6b 的偏高偏差最强。
- 纳入按 cso（实测残差 SD）定情景，cso 与总交互量相关；它不含秩信息，但不是独立于
  信号强度。
- 判别集已经历 D-036 的「第一轴可复现」筛选。
