## 2. 诊断：这是工具（判据）的错，不是被检查对象的错（CLAUDE.md §10，分开记录）

F1 数的是「观测格里在值域端点**或之外**的比例」。真实矩阵的值域是它自己的极值，所以真实矩阵的 F1 恒为 ≈ 2/n；
但任何「可加噪声 + 结构」的世界（包括边缘分布与真实残差完全相同的 REF）都会让一部分格子超出真实矩阵的**极值**——
最可能的原因（**未单独检验**）是真实数据里结构大的格子残差小（接近仪器上下限的格子有饱和式的非独立性），把残差在行内打乱就破坏了这一依赖。
**结果：F1 抓不住「截断堆积」特有的缺陷，反而抓住了「任何可加世界都有的越界」。** FT3 的设计目的正是发现这种错配，它做到了。

要抓的缺陷（docs/45 §4.3）是**堆积在端点上的格子**（截断是非线性，两半同样地读成第二方向），不是「值超过真实极值」本身。
越界的格子在可加线性世界里不产生残基层面的非线性，只是尾部比真实宽。

## 3. 修订（事后，A1）

只改 F1 一项，机制导出，F2/F3 与其余一切不变：

- **F1a（堆积于端点）**：观测格子里恰在值域端点（|Y − lo| < 1e-9 或 |Y − hi| < 1e-9）的比例。判据 **F1a ≤ 1.0%**。
  （真实 ≈ 0.06%；旧截断世界 5%–23%。）对不截断的世界它恒 ≈ 0，**它只负责检验「截断堆积」这一个缺陷，不声称检验别的**。
- **F1b（越界）**：观测格子里严格在 [lo, hi] 之外的比例。**只报告，不设判据**，并并列该矩阵 REF 的 F1b 作为「任何可加世界的下限」。
- F2 ≤ 0.10、F3 ≤ 0.40 不变（REF 满足它们：F2 ≤ 0.076、F3 ≤ 0.378，所以这两个判据有已知忠实的参照撑腰）。
- 「忠实」= F1a、F2、F3 在全部 14 个路径点上同时通过（全有或全无不变）。
- 修订后的牙齿：AFT1（旧截断世界在 ≥ 4 个 S1 矩阵上至少一点 F1a > 5% 且被判 F）、AFT2（被截比例 < 0.5% 的点 F1a 不误判）、
  AFT3（REF 在 15 × 2 上全过修订判据）、AFT4（方差放大 1.25 倍在 ≥ 90% 矩阵上被 F2/F3 抓住）。**任一不过即中止。**
- 其余（世界构造、路径、harness、门 H1/H2、分类规则、体系裁决、世界裁决、种子、S_real = 300）**逐字不变**。

## 4. 披露：这份修订是在看到什么之后写的

写下它之前，我已看到锁定判据下 G、RR、GCLIP、REF 四类世界逐矩阵逐点的 F1/F2/F3（上述汇总），**包括 G 世界在大量路径点上 F2/F3 不过**
（F2 最大 0.23、F3 最大 0.9——高斯世界的低噪声端，放大了的结构把值分布的形状改了）。这意味着：
(i) 修订的 F1 → F1a 是由 REF 失败的**机制**推出的，不是为了让某个世界过；
(ii) 但我**知道**这个改动不会让 G 变得忠实（G 的问题在 F2/F3），而会让 RR 在大部分矩阵上变得忠实——所以读者应当把「RR 成为实际可用的对照」
当作**修订后观察到的**事实，而不是预先登记的预期；
(iii) 我**没有**看过任何世界的复现统计量（cos θ₂）、任何新种子下的真实分半、任何表达量统计量。
