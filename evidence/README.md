## 两份调研的共同教训

两份报告都把「已核到原文表/图号」与「仅摘要/二手引用」分开标注，
并明确列出查不到的东西。这一点必须保持——
`assay-noise.md` 第 6 节那个 ABRF-MIRG'02 的 ±0.22 是 SD 还是 SEM 的问题，
是**三倍以上**的差别（σ_ΔG 0.13 vs 0.45），如果被当成已证实数字写进方法学，
会悄悄污染温度参数。

反面例子也记下来了：原以为 SAMPL / D3R 文献会给 σ_exp 的独立测定值，
实际是空的——它们要么引 Kramer/Brown，要么只给预测端 RMSE。
**这条线索不要写进引用。**
