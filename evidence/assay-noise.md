# 实验误差宽度 σ_exp（任务 M2-T1）

## 为什么这个数非拍不可地重要

`docs/05-mathematical-structure.md` M2.3：排序损失的温度 = √2·σ_exp，
**不调参**。所以这个数直接进损失函数，必须有来源。

同时它决定了：
- `docs/02-pair-criteria.md` C3 的可分辨阈值（原写 0.5 kcal/mol）
- 那个阈值从硬截断改为软权重后的权重形状
- `analysis/rank_power.py` 的 SIGMA_EXP，进而影响 C6 的矩阵规模要求

一个拍出来的 σ_exp 会悄悄污染上面全部三处。

## 要收集什么

不是「ITC 的精度是多少」这种笼统说法，而是**重复性误差的分布**：

| 字段 | 说明 |
|---|---|
| assay 类型 | ITC / SPR / 竞争结合，分开记 |
| 误差类型 | 同一实验室重复 vs 跨实验室重复 —— 两者差别很大 |
| 报告形式 | 标准差？标准误？置信区间？n 是多少 |
| 是 Kd 的误差还是 ΔG 的误差 | Kd 的相对误差 → ΔG 的绝对误差需 RT·ln 换算 |
| 是否依赖亲和力大小 | 弱结合与强结合的误差通常不同 |
| DOI | |

最后两栏是关键。若误差依赖亲和力大小，则 σ_exp 不是常数，
M2.3 的 probit 形式要改成异方差版本。

## 已知的坑

- 文献报道的误差常是**拟合误差**（曲线拟合的形式标准误），
  不是**重复性误差**。前者系统性偏小，常小一个量级。
  只有重复性误差才是 M2.3 要的那个。
- 跨实验室重复性比同实验室差很多。判别集若跨篇拼接
  （C6 的矩阵几乎必然跨篇），要用跨实验室的那个数。
- ΔΔG 的误差不是单个 ΔG 误差，若两个测量独立则是 √2 倍。
  注意不要和 M2.3 里的 √2 重复计数。
