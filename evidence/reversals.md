# 选择性反转案例（证伪 M1.1：代理量的可加性）

## 要证伪什么

若 S(P,L) = a(P) + b(L)（无耦合项），则两个口袋的排序与配体无关。
**找到一个确凿反转即完成证伪**，耦合项必须存在，问题只剩秩是多少。

## 纳入要求

一个案例 = 两个口袋 A、B + 两个配体 L1、L2，满足
`A 对 L1 更强` 且 `B 对 L2 更强`，且四个数值可比
（同 assay 类型、同 metric、|差值| ≥ 0.5 kcal/mol 当量）。

**注意**：本文件按设计**包含方向性结论**，这是它的目的。
故它不在 `pairs/` 下，不受泄露扫描管辖。但凡进入判别集的体系，
其 `pair_id` 不得出现在这里——否则等于给盲预测开后门。
→ `analysis/check_repo.py` 应增加这条交叉检查（待实现）。
