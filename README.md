# site-residue-rank

**酵母展示深度突变扫描的结合读出里，低秩交互结构与表达量及折叠的残基方向无法分开。一项警示性发现。**

在 SARS-CoV-2 RBD 酵母展示数据里，位点×残基交互项的低秩结构，与同一批变体库的**表达量**读出、
以及折叠稳定性交互项的第一轴，是同一个方向（两两 0.95–0.99，每个方向自身可复现）。
结合分数**没有对展示量归一**（上游代码）。现有数据**无法区分**「结合与折叠共用一条残基方向」
与「结合读出携带稳定性/展示结构」。这是对所有把 DMS 结合分数当作结合 ΔΔG 去做低秩分解的分析
（包括假设交互是秩 1 的工具）的警告。

**状态：草稿，未经同行评审。主张经过多轮收紧，且仍在收紧。** 这个仓库最初的问题是「找结合亲和力的
廉价可微代理量」；经过十余轮自我检验，它变成了一个不同的、更窄的问题。**早期版本里的若干主张已撤回**
（见下文「撤回清单」），仓库的提交历史里能看到它们。

## 主要结果（预先登记层的判决；事后修订**不**被采纳，见 D-096）

- **交互项非零且低秩，但「恰好秩 2」没有被站住。** 主证据是一个 RBD × ACE2 面板
  （15 个子集，**彼此不独立**）。用去偏的定秩程序（现行程序在高信噪比下会把真秩 1 抬成秩 2，
  已量化并修正）：秩 0→1 +6.6% [+4.2%, +9.7%]；秩 3 劣于秩 2（−11.6% [−15.4%, −8.7%]）；
  **秩 1→2 仅 +1.3% [−1.4%, +4.7%]，区间含 0**——秩 1 与秩 2 不能区分。
  没有任何一个独立体系支持「秩 2 优于秩 1」。
- **结合、表达量与折叠的第一轴无法分开。** RBD 酵母展示数据里三者两两 0.95–0.99（同源、同文库、
  跨骨架、跨家族无差别）。144 个独立天然结构域上，结合普适轴与折叠的夹角余弦中位在当前 8 成员证据集下
  为 0.807（9 成员口径为 0.755）；但 RBD 家族自己的共识轴对折叠是 0.983，较低的值**似乎**来自家族等权
  纳入的 OMTKY3——这是推断，没有做把 OMTKY3 单独拿掉的受控计算。OMTKY3（体外，唯一不经展示量的体系，
  每个酶约 10 个位点）的第一轴自身不过可复现闸。
- **用同批表达量校正后**（对照世界中通过的 WH1、Eta 骨架，**属事后层、不入结论**）去掉 30%–59% 的交互方差，
  剩余在留出预测里没有可检出的增益。**但校正也会删掉与稳定性相关的真结合生物学**，所以剩余不能解读为
  「结合特异」，也不能解读为「没有结合信号」。预先登记的判决是「无法评估」。
- **第二成分**位点互不相交时可复现（第二主角余弦中位约 0.72–0.77），但预先登记的判决是「无法评估」；
  它在 WH1 与 Eta 骨架上与同批表达量的交互子空间不可区分；可复现部分只占交互方差的约 2–12%；
  在体系之间不一致（跨家族 0.105）。
- **第一成分的位点载荷能从单个野生型结构预测**（样本外 R² = 0.408，优于加权接触数基线 0.010），
  **应读作「这个方向可预测」，而不是「结合的这一成分可预测」**——既然该方向与表达量/折叠无法分开，
  它可能只是埋藏结构在预测稳定性方向。

## 它的局限（和结论一样重要）

- 能把读出与生物学分开的只有**不经展示量的体系**，而手上只有 OMTKY3。MaveDB 全量枚举没有带滴定读出的
  同骨架多配体体系。**要解决这个问题需要一类目前不存在的数据**：同骨架、多配体、不经展示、
  滴定范围覆盖全部变体、两种表型各自独立测量。
- 跨家族的结合侧证据只有**两个家族、8 个矩阵**，且质量不对等。
- 「结合」指**直接测量**的亲和力，不包括三状态模型反解出的结合自由能（D-063）。
- 独立的表达量来源只有约 2–3 个（WH1_v1 与 WH1_v2 是同一骨架）。

# 项目背景：最初的问题与盲法协议

寻找一个**结合亲和力的可微代理量**，要求它对「形状相近、核心残基不同」的口袋对给出正确排序。

## 一句话问题陈述

给定一对口袋 (P_A, P_B) 与同一配体 L，在 P_A、P_B 骨架与形状高度相似、
差异集中在第一壳层残基身份的条件下，构造标量 S(P, L) 使得
`sign(S_A - S_B) = sign(ΔG_A - ΔG_B)`，且 S 对原子坐标与部分电荷可微，
计算成本远低于自由能计算。
