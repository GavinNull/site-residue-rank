# site-residue-rank

**蛋白–配体结合自由能的位点×残基交互项：它的秩是多少，以及两个成分各是什么。**
第一个成分跨蛋白家族普适、并与蛋白折叠共用；第二个成分（若存在）是界面自己的属性。
**状态：草稿，且主张在持续收紧中。** 「恰好秩 2」没有被站住——去偏后秩 2 对秩 1 的优势不能与零区分，见下文与 `docs/41`、`docs/43`。

这是一个把「结合亲和力的廉价可微代理量」这个工程问题，推进成一个定量科学发现的研究仓库。
全部分析、决策记录与失败记录都在里面。

## 主要结果

- **交互项是低秩的，但「恰好秩 2」没有被站住。** 主证据是一个 RBD × ACE2 面板（15 个子集，
  **彼此不独立**）。去偏后（定秩程序在高信噪比下会把真秩 1 抬成秩 2，已量化并修正）：
  秩 0→1 +6.6% [+4.0%, +9.7%]、秩 3 劣于秩 2（−11.6% [−15.3%, −8.9%]）都稳；
  但**秩 1→2 仅 +1.3% [−1.4%, +4.4%]，区间含 0**——秩 2 是点估计的最优，不能与秩 1 区分。
  独立体系只有几个，故不报符号检验 p 值。早期版本报告的 p = 0.00049（把相关子集当独立样本）
  与「−5.54%」（无法复现）均已撤回，见 `docs/41`、`docs/43`。
- **第一成分跨家族普适，并与折叠共用。** 144 个独立天然结构域上夹角余弦中位 0.755
  [0.720, 0.775]，共享程度 ρ ≈ 0.78。化学上同时载有体积/埋藏面积与疏水性两类信息。
- **第二成分不普适。** 若完全共享本管线会测到 0.90/0.82，实测 0.105/0.146。
- **对代理量设计的推论是个坏消息。** 第一成分的位点载荷能从单个野生型结构算出
  （样本外 R² = 0.408，显著优于加权接触数基线 0.010）；第二成分算不出来，
  而判别口袋的信号恰在第二成分上。

## 它的局限（和结论一样重要）

- 跨家族的**结合侧证据只有两个家族、8 个矩阵**，且质量不对等；外部数据库也已穷尽
  （MaveDB 全量枚举，无滴定读出的第三家族）。
- 「结合」指**直接测量**的亲和力，不包括三状态模型反解出的结合自由能；
  这条带有明确的否证条件，见主论文 §7.3。
- 这些是**草稿**，未经同行评审。数字出处逐条记录在 `docs/12`–`docs/40`。

# 项目背景：最初的问题与盲法协议

寻找一个**结合亲和力的可微代理量**，要求它对「形状相近、核心残基不同」的口袋对给出正确排序。

## 一句话问题陈述

给定一对口袋 (P_A, P_B) 与同一配体 L，在 P_A、P_B 骨架与形状高度相似、
差异集中在第一壳层残基身份的条件下，构造标量 S(P, L) 使得
`sign(S_A - S_B) = sign(ΔG_A - ΔG_B)`，且 S 对原子坐标与部分电荷可微，
计算成本远低于自由能计算。

## 执行顺序（不可跳步）

```
G0  探针库 + 数值稳定性流程        不依赖判别集，先转起来
G1  判别集前 100 对（标签隔离）
G2  基线墙：现有方法在 G1 上的失败分类表

```

G3 不过，后面不建。见 [state/gates.md](state/gates.md)。
