# pocket-surrogate

寻找一个**结合亲和力的可微代理量**，要求它对「形状相近、核心残基不同」的口袋对给出正确排序。

## 一句话问题陈述

给定一对口袋 (P_A, P_B) 与同一配体 L，在 P_A、P_B 骨架与形状高度相似、
差异集中在第一壳层残基身份的条件下，构造标量 S(P, L) 使得
`sign(S_A - S_B) = sign(ΔG_A - ΔG_B)`，且 S 对原子坐标与部分电荷可微，
计算成本远低于自由能计算。

## 项目结构

| 路径 | 内容 |
|---|---|
| `docs/` | 问题定义、设计、纳入判据、验证协议、盲测协议 |
| `schema/` | 口袋对 / 预测 / 因子词表的硬格式定义 |
| `pairs/` | 判别集，**一对一文件，不含标签** |
| `labels/` | 实验 ΔΔG，混淆存储，仅由打分脚本读取 |
| `probes/` | 一级机理探针的理想化体系（与判别集解耦，可复用） |
| `predictions/` | 盲预测记录，一旦写入即锁定 |
| `analysis/` | 确定性打分与统计脚本 |
| `tools/` | 描述子 / xtb 接口 |
| `state/` | gate 状态、决策日志 |
| `JOURNAL.md` | 时间序，只追加 |

## 执行顺序（不可跳步）

```
G0  探针库 + 数值稳定性流程        不依赖判别集，先转起来
G1  判别集前 100 对（标签隔离）
G2  基线墙：现有方法在 G1 上的失败分类表
G3  盲预测 gate：方向准确率 / 因子分层 / 置信度校准
G4  存活因子 → 可微量实例化
G5  0–3 级验证 + 三组对照
G6  holdout 单次开封
```

G3 不过，后面不建。见 [state/gates.md](state/gates.md)。
