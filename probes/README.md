# 探针库

**快变量。** 不依赖判别集，建成后每个候选量过一遍只要几分钟。
故优先于判别集建成（见 `state/decisions.md` D-006）。

## 用途：第 1 级机理测试

不用任何实验数据。每个候选代理量在提出时必须附一条 `falsifiable_claim`，
这里把它做成扫描，检验**它是否在做它声称在做的事**。

通过判据是**定性的符号与单调性**，不是数值。
一个声称对残基电性敏感的量，若对 Hammett 序列无响应，
它在判别集上的任何相关性都是伪的。

附加判据是**量级**：各 `manifest.tsv` 的 `reference_magnitude` 给了参考值。
"物理上说得通"不是通过判据；量级对不上就是不通过（`CLAUDE.md §8`）。

## 重新生成与自检

```bash
python3 tools/make_probes.py && python3 analysis/check_probes.py
```

几何自检必须在任何电子结构计算之前跑。坏构型会让 xtb 悄悄收敛到
无意义结构，而扫描曲线看起来仍然"平滑"。首次运行曾命中 36/60，
三类真实错误，见 `JOURNAL.md` 2026-10-03。
